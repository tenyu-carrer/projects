これから「天祐自動化」の一環として、このWindows PCに OpenClaw（オープンソースのAIエージェント）を導入して、使える状態にするところまで全部お願いします。必要なソフトのインストールや設定も含めて、あなたが進めてください。

## 天祐自動化の前提
- 天祐（career-design）の日々の業務を自動化する取り組み。
- 最初のテーマは WordPress（https://career-design.co.jp）への毎日の記事投稿の自動化。
- 投稿は WordPress REST API + アプリケーションパスワードで行う方針。
- パスワードやAPIキーは .env や OpenClaw の設定にだけ保存し、Gitにコミットしない。チャットに貼られても、コードに直書きしない。
- もし C:\ のどこかに tenyu-carrer/projects リポジトリがあれば、その CLAUDE.md も読んで前提に加えて。

## やってほしいこと（順番に）
1. 最初に公式ドキュメント（https://docs.openclaw.ai/install と https://docs.openclaw.ai/platforms/windows）を読み、最新の正しい手順を確認する。記憶ではなくドキュメントを優先して。
2. 今のPCの状態を確認する：Windowsのバージョン、Node.js（22以上が必要）、Git、WSL2 の有無。
3. 足りないものをインストールする（winget が使えれば winget で。例：Node.js LTS、Git）。
   - 管理者権限が必要な操作や、PCの設定を変える操作（ExecutionPolicy の変更、WSL2 の有効化、再起動など）は、実行前に「何をなぜやるか」を一言説明して、私の OK を取ってから進めて。
4. 公式手順どおりに OpenClaw をインストールする。
   - 公式は Windows では WSL2 を推奨している。ネイティブ PowerShell と WSL2 のどちらで入れるべきか、理由をつけておすすめを教えて、私が選んでから進めて。
5. 初期設定（オンボーディング）を行う。
   - AIのAPIキーを聞かれたら、そこで止まって私に入力を頼んで（私がキーボードで直接入力する）。
   - ゲートウェイ（OpenClawの常駐サーバー）は自分のPCからだけアクセスできる設定（localhost）にして、外部公開はしない。
6. 動作確認：状態確認コマンド（status / doctor など）を実行し、ダッシュボードを開いて、簡単な質問に OpenClaw が答えることを確認する。
7. 最後に、次の内容をまとめて `C:\Users\<自分>\openclaw-メモ.md` に保存する：
   - 入れたもの・バージョン・インストール場所
   - OpenClaw の起動・停止・状態確認のコマンド
   - 困ったときの確認手順
   - 天祐自動化（WordPress 毎日投稿）に OpenClaw をどう使うかの次の一歩の提案（1〜3個）

## 進め方のルール
- 日本語で、専門用語には一言説明をつけて。
- 1ステップ終わるごとに「今どこまで終わったか」を短く報告して。
- エラーが出たら自分で原因を調べて直して。直せないときだけ私に聞いて。
- 私の許可なく、OpenClaw に メール・SNS・WordPress など外部サービスへの書き込み権限はまだ渡さないで（導入と動作確認まで）。

## 補足

- 途中で PC の再起動が必要になることがあります（WSL2 を入れた場合など）。再起動した後は、PowerShell で `claude` を開いて **「OpenClaw の導入の続きをお願い。openclaw-メモ.md とさっきの手順の続きから」** と言えば再開できます。
- API キー（Anthropic など）は、事前に用意しておくとスムーズです。
