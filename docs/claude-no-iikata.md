# PowerShell の Claude への言い方 早見表

プロジェクトの前提（目的・サイト・ルール）は `CLAUDE.md` に書いてあり、
Claude Code は起動時に自動で読みます。だから **毎回の説明は一言でOK**。

## 1. 始め方

```powershell
cd C:\path\to\projects   # このリポジトリのフォルダ
claude
```

## 2. 最初のひとこと（コピペ用）

```
天祐自動化の続きをやりたい。CLAUDE.md の進捗メモを見て、次にやることを教えて。
```

## 3. よく使う言い方

| やりたいこと | 言い方 |
| --- | --- |
| 続きから再開 | `天祐自動化の続き。進捗メモの次の項目を進めて` |
| 状況確認 | `今どこまでできてる？CLAUDE.md とコードを見てまとめて` |
| 下書き投稿テスト | `WordPress に「テスト」という下書きを1件投稿して確認して` |
| 記事を作る | `今日の記事を下書きで作って。テーマは〇〇` |
| 毎日自動にする | `投稿スクリプトをタスク スケジューラで毎朝9時に動かす設定を教えて` |
| エラー時 | `このエラーを直して：（エラー文を貼る）` |
| 終わるとき | `今日の作業を CLAUDE.md の進捗メモに反映して、コミットして` |

## 4. コツ

- パスワードはチャットに貼らず、`.env` に自分で書く（書き方は Claude に聞けばOK）。
- 最後に必ず「進捗メモに反映して」と言うと、次回もすぐ続きから始められる。
- 前提が変わったら `CLAUDE.md を更新して：〇〇になった` と伝える。
