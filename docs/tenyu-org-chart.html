Threadsの夜投稿が出ない原因 解決済み・10/1 本番反映（PR #164）

夜の予約タスクは21:00に動いているのに、受け取り側のVercelが「夜枠は19:30」のままになっていて、21:01以降に届いた投稿を「時間外」として断っています。

ずれている2つの設定

ChatGPT予約タスク「Threads夜投稿」：毎日 21:00（9/27に再開）

Vercel api/threads/slot.js の夜枠：19:30、前後90分だけ受付

受付は18:00〜21:00ちょうどまで。ChatGPTが文章を作って送ると数分かかるので、ほぼ毎回21:01以降に届きます。

実際の判定（同じ計算式で再現）
届いた時刻19:30との差結果
21:0090分受付
21:0191分403 時間外
21:0595分403 時間外
12:15（昼）15分受付
気づかれなかった理由

12時の監査報告は「Threadsは対象外」（9/28オーナー決定）。07:45の集計は朝なので夜の失敗が載りません。夜の失敗を見る係がいませんでした。

直し方（1行）

slot.js の夜枠を 21:00（昼も実際の 12:15）に合わせる。Cronも経路も増やさずに直ります。二重投稿防止の仕組みはそのまま効きます。

VercelのログはこのClaudeの接続では読めなかった（権限エラー）ため、「403が実際に返っている」ことはログでは未確認です。修正後の21:00に投稿IDと公開URLが出れば確定です。ChatGPT側のタスクが再び無効になっていないかも、あわせて画面で確認してください。

24時間の流れ 日本時間

定期で動くのは、ChatGPT予約タスク（記事・Threads文面）、Vercel Cron（Instagram投稿・07:45集計）、GCP Cloud Scheduler（WordPress）、Claude Routine（確認・監査・補充）、OpenClaw（24時間PCの見張り）の5種類です。
