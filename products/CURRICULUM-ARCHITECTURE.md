# 天祐AIスキル商品180｜全体カリキュラム設計

## 結論：番号は維持し、学習順を別に持つ

001〜180の番号は、商品台帳・UTAGE・URL・売上履歴を結ぶ固定IDなので変更しない。現行順は「売り場の棚」としては分かりやすい。一方、初心者の学習順としては、権利・検品・AIの基本や、販売前に必要な市場設計が後ろにある。

そのため、次の二つを併用する。

- **商品番号順**：制作・管理・一覧表示。001から10個ずつ品質を上げる。
- **推奨学習ルート**：受講者の目的別。番号をまたいで前提から順に案内する。

## 共通の「0章」

全180商品に共通で、最初に短い基礎講座を表示する。

1. AIは間違えるため、事実・数字・固有名詞を人が確認する。
2. 入力してよい情報と、個人情報・機密情報を分ける。
3. 著作権・商標・肖像権・素材ライセンスを確認する。
4. プロンプトは目的・対象・素材・制約・出力形式の順で書く。
5. 「生成した」で終わらず、実際の利用環境で開いて検品する。

## 各20商品内の役割

- 先頭1〜5商品：入口。初心者が完成経験を得る。
- 中盤6〜15商品：表現・制作能力を広げる。
- 後半16〜20商品：量産、販売、運用、事業化へつなぐ。
- 順番に依存しない商品には「単独受講可」を表示する。
- 前提が必要な商品には、前提商品と不足時の補講を表示する。

## 180商品完成時の提供形

1. 商品一覧：目的、難易度、時間、前提、成果物、状態で検索。
2. 学習ダッシュボード：9スクールと6推奨ルート。
3. 商品ページ：A無料、B完成品、C道具、D講座の違いを明示。
4. 教材ページ：画面順の手順、見本、プロンプト、課題、検品。
5. 購入制御：UTAGE決済と商品IDを結び、購入商品のみ表示。
6. 更新管理：公式仕様・規約の確認日、教材版、変更履歴を表示。

## 制作順

品質を落とさないため、10商品ずつ制作し、各バッチで次を行う。

1. 目的と前提の確認。
2. 公式情報の調査。
3. A〜Dの設計。
4. D講座とC道具を先に制作。
5. B完成品とA無料体験を制作。
6. 素材・リンク・表示・文章を検査。
7. ローカルWebへ追加。
8. オーナー確認後に次の10商品へ進む。
