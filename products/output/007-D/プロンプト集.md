# 007-D 実務プロンプト集｜AIイラスト

## 1. 基本イラスト
```text
用途：【】主役：【】動作：【】場所・時間：【】
画風：【一般的な媒体・線・質感】配色：【】光：【】
構図・視点：【】比率：【】余白：【】
文字・ロゴ・透かし・不要物：【避けるもの】
既存作品・作家・ブランドの模倣をしない。入力にない製品情報を作らない。
```

## 2. 一点修正
```text
【変更する要素一つ】だけを調整し、【固定する主役・配色・画風・構図】を維持。
新たな文字、人物、物体、ロゴを追加しない。
```

## 3. 余白を残す
```text
用途：【】主役：【】画風：【】色：【】比率：【】
後から見出しを置ける空白を確保。画像内に文字・記号・疑似文字・ロゴを描かない。
```

## 4. 教材の概念図
```text
対象：【】目的：【】正確な要素：【一次資料から列挙】
読む順：【】図の構成：【】
正確性を確認できない情報は追加せず、後から文字を配置するため文字なしで作る。
単なる概念図なら概念図と明記。出典を図の近くに記載する余白を残す。
```

## 5. 生成物の点検支援
```text
用途：【】必要要素：【】避ける要素：【】実際に確認できる画像特徴：【】
形の不自然さ、文字混入、用途不一致、誤認、余白、画面端の問題を列挙。
画像を見ていない場合は見たふりをしない。画像だけで断定できない点は現物確認と記す。
```

## 6. プロンプトの簡潔化
```text
この指示文を、意味の矛盾を減らし主役・動作・場所・画風・構図・避ける物に整理。
【元の文】
条件を勝手に追加せず、不明点は質問。既存作家・作品の模倣を提案しない。
```

## 7. 履歴のまとめ
```text
用途：【】生成サービスと設定：【】各回のプロンプトと変更点：【】
選んだ候補の理由、残った欠点、利用条件の確認状況、出力・検品結果を表に整理。
未確認事項を完了扱いにしない。
```
