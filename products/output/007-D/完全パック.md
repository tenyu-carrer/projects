# 007-D 完全パック｜AIでイラストを作る方法

> 対象：画像生成が初めての人／完成物：用途に合うイラスト1点、再現用プロンプト、出力・権利確認記録／目安：60〜120分
>
> この教材の作例は架空の児童書風イラストです。AI画像の独自性・正確さ・商用利用の適否・他者の権利を侵害しないことは保証しない。公開・販売前に利用サービスの最新規約と素材条件を確認し、人が内容を点検してください。

## ゴール

思いつきを長い形容詞の列にするのではなく、目的・主役・動作・場所・構図・光・色・比率に分けて説明し、生成結果を一度に一つの変更で改善します。最後は用途に合うサイズで書き出し、文字・手指・境界・不自然な形・誤解を招く内容を点検し、プロンプトと修正履歴を保存します。

生成画像は実在の出来事の証拠や、正確な製品仕様・医療情報の代わりにはなりません。人物・場所・商品などを写実的に生成して、実際に存在した・起きたと誤認させないようにしてください。個人情報、機密素材、本人の同意がない人物画像を入力しないでください。

## 先に決めること

- 用途：挿絵、SNS、教材、サムネイルなど
- 掲載先の縦横比・最小サイズ・余白・背景
- 見る人と、画像を見た後に理解してほしいこと
- 主役、動作、場所、季節・時刻
- 画風・色・光・構図
- 入れてはいけない文字、ロゴ、人物、物体、表現
- 利用する生成サービス、プラン、規約確認先、確認日

複数の画像生成サービスを使う場合、同じプロンプトでも出力・権利条件・保存方法が異なることがあります。使うサービスごとに結果と条件を確認し、サービス名と日付を記録してください。

## A｜無料：10分で3要素を試す

最初の試作では主役・動作・場所だけに絞ります。例：「雨上がりの小さな本屋の前で、黒猫が赤い傘をたたんでいる」。次に画風・色・光・構図・比率・避けたいものを加え、どの指示が結果を変えたか比較します。

1. 主役を一つ決める（1分）。
2. 主役が何をしているか具体的な動詞で書く（2分）。
3. 場所・時間を書く（2分）。
4. 「文字なし、ロゴなし」など避けたい物を一つ加える（2分）。
5. 生成して、主役・動作・場所が伝わるか確認（3分）。

**合格**：画像の用途と主役が明確で、実在人物・既存作品の模倣を狙わず、見た人に誤認させる内容がないこと。

## B｜完成見本の読み解き

### 架空の作例プロンプト

「雨上がりの小さな本屋の前で、黒猫が赤い傘を閉じている。温かみのある児童書の手描きイラスト。濃紺と橙を基調に、路面に柔らかい反射光。主役が全身見える正方形構図。文字・ロゴ・余分な人物なし。」

これは既存の児童書作品や作家の絵柄を模倣する指示ではありません。店・猫・出来事は架空で、商品・場所・実際の体験を記録した写真ではありません。

### なぜこの指示が扱いやすいか

- **主役**が黒猫一つなので、視線の中心が明確。
- **動作**を「傘を閉じる」としたため、静止した猫ではなく場面が生まれる。
- **場所と状態**（雨上がりの本屋）で背景の役割を限定。
- **画風・色・光**は雰囲気を揃える指示で、特定の作家・作品名に依存しない。
- **構図**と「全身見える」で、切れや極端な寄りを避けたい意図を伝える。
- **避ける物**を明記して、不要なロゴ・人物・文字の混入を減らす。

出力が指示通りでない場合、全部を書き換えず、主役の位置、色、背景のどれか一つを変更して比較します。

## C｜プロンプト設計と改善

### 基本テンプレート

```text
用途：【挿絵／教材／投稿など】
主役：【一人・一つ】　動作：【具体的な動詞】
場所・時間：【】
画風・素材感：【】　配色：【】　光・雰囲気：【】
構図・視点：【全身／寄り／俯瞰など】　比率：【】
文字：【必要な正確な文字／文字なし】
入れないもの：【ロゴ、余分な人物、透かし等】
正確さが必要な要素：【参照する一次資料または専門家確認】
```

### 1. 物語の一場面

```text
児童向けの挿絵。架空の黒猫が雨上がりの小さな本屋の前で傘を閉じている。
手描き風の温かなイラスト、濃紺と橙、路面に柔らかな反射光。
猫の全身が見える、主役を中央寄りに置く正方形構図。
文字・ロゴ・実在ブランド・余分な人物なし。既存作品や作家の模倣なし。
```

### 2. 教材用の概念図

```text
対象：【初心者】目的：【手順を理解する】
図に含める要素：【順序と各要素の関係を列挙】
図解として簡潔に、読む順番を矢印で示す。文字は後から編集する前提で画像内文字を生成しない。
誤りの可能性がある箇所：【】は公式資料で確認してから作図する。
装飾や実在企業ロゴなし。正確さを確認できない場合は概念図と明記。
```

### 3. 1点だけ修正する依頼

```text
この案の【残したい点】を保ち、【変更する点ひとつ】だけを直してください。
主役、配色、画風、構図、光は変更しないでください。
新しい物体、文字、人物、ロゴ、透かしを追加しないでください。
```

### 4. 画像内文字を避ける依頼

```text
見出しを後から載せる余白を残したイラストを作成してください。
画像内には文字、疑似文字、数字、ロゴ、署名、透かしを描かない。
主役：【】場所：【】画風：【】色：【】構図：【】比率：【】
```

### 5. 出力の自己点検を助ける依頼

```text
以下の画像の説明または目視した特徴を、用途と照らして点検してください。
用途：【】必要要素：【】避ける要素：【】実際に見えた内容：【】
指示への適合、手指・顔・物体の形、文字やロゴの混入、背景の破綻、誤認リスクを項目別に列挙。
画像自体を見ていない場合は見たふりをしない。画像の説明だけから断定できない点は「現物で要確認」とする。
```

AIを使ってプロンプトを書き直しても、生成物の正確さ・独自性・権利適合は保証されません。画像生成サービスのAI利用規約、入力データの扱い、共有・商用利用条件を確認します。

## D｜Canvaで生成・編集・保存する流れ

### Step 1：新しいデザインを用途サイズで作る

Canvaで用途に合った新規デザインを選びます。投稿・印刷・動画サムネイル等は寸法・縦横比が違うため、掲載先の最新仕様から始めます。表紙や広告では、後からタイトルを載せる余白をあらかじめ決めます。

### Step 2：Magic Mediaの現在の入口を確認

Canva公式ヘルプの現行案内では、編集画面のサイドパネルから「Magic Media」を選び、見当たらない場合は「アプリ」から検索します。「画像」タブで説明を入力し、スタイル・レイアウトを選んで生成します。画面表示・機能・プラン・利用上限は変更される可能性があるため、表示が違えば公式ヘルプを確認し、利用中アカウントで使える機能だけを案内してください。

### Step 3：最初は短い指示から生成

テンプレートの「主役・動作・場所・画風・色・構図・比率・避ける物」に沿って入力します。指示が長く矛盾すると結果が不安定になることがあります。特定作家の名前、存命アーティストの固有スタイル、既存キャラクター・ブランドを模倣する指示は避けます。ロゴや細かい文字は、後からCanvaのテキスト機能で正確に配置します。

### Step 4：候補を目的に合わせて選ぶ

最も派手な画像ではなく、用途、主役、必要な余白、色、画角が合う案を選びます。候補ごとに何が良く、何を直したいかメモします。顔・手・道具などを拡大して不自然な形や余分な物がないか確認。生成画像で実際の人物・店舗・商品を写した証拠のように見せないようにします。

### Step 5：一度に一つだけ修正する

「画風・人物・色・背景を全部変えて」ではなく、「背景の雨を弱める。猫と配色、構図はそのまま」のように、一要素を指定します。生成ごとにプロンプト、時刻、サービスの設定、選んだ候補を保存します。再生成で同一人物や同じ構図が維持されるとは限らないため、キャラクター一貫性が必須の案件は、サービス機能と利用規約を確認し、手動調整を想定します。

### Step 6：Canva上で仕上げる

画像をデザインに追加し、トリミング、余白、配置、文字の重なりを確認します。画像内生成文字は正確でない可能性があるため、タイトルや説明文は別テキストとして入力・校正します。教材図・商品写真・広告など、正確さが必要な要素は一次資料・実物・専門家による確認なしに断定表示しません。

### Step 7：権利・プライバシー・利用条件を確認

使った生成サービスの現行AI利用条件、コンテンツライセンス、入力データ設定を確認します。他人の写真・作品を参照に使う場合は、著作権、肖像、契約、サービス規約、本人同意の適用を確認します。権利者の許可が不明な素材は使いません。顧客の顔や機密資料を参照にアップロードする場合は、本人の同意と組織ルールを先に確認します。

### Step 8：用途に合う形式で書き出し

ダウンロード時に、配布先のピクセル寸法・形式・容量・背景透明の要否を確認します。Canvaの一部出力機能はプランやアカウント設定により異なることがあります。書き出したファイルをCanva以外のビューアでも開き、端の切れ、解像感、色、透明背景、文字を点検します。印刷用途は画面プレビューだけでは十分でないため、印刷会社の仕様と必要な校正を確認します。

### Step 9：履歴と承認を保存

プロンプト、生成設定、出力ファイル名、使用素材、規約確認日、修正履歴、確認者、最終用途を記録します。AI生成であることを明示すべき場面では、配布先・サービス・法令等の要件に合わせて表示します。販売や広告に使う前に、誤認、権利、事実、ブランド、個人情報のチェックを終えます。

## つまずき対応：よくある12ケース

1. **思った主役が出ない**：主役と動作を先頭に書き、背景・装飾の指示を減らす。
2. **画像内の文字が崩れる**：文字生成を避け、余白を作ってCanvaのテキストで入力する。
3. **手や顔が不自然**：拡大確認し、構図を簡素化して再生成。違和感が残る画像は使わない。
4. **指示が効かない**：一度に変更する要素を一つにし、残す部分と変える部分を明記。
5. **毎回人物が変わる**：同一人物の再現が必要か先に判断。外見条件を固定しても完全一致は保証されないと理解する。
6. **画面にMagic Mediaがない**：公式ヘルプを確認し、アプリ検索・アカウントの機能提供状況を調べる。UI名称を固定教材だけで断定しない。
7. **候補がどれも似ている**：動詞、視点、距離、場所のうち一つを変えて、比較条件を記録。
8. **画風が他者に似すぎる**：作家名や作品名を外し、媒体・線・色・構図など一般的特徴で独自に組み直す。
9. **実物と違う商品画像になる**：AI生成を商品仕様の証拠にしない。実物写真・確認済み情報を使う。
10. **利用規約が分からない**：現行のAI利用規約・素材条件を確認し、判断できるまで商用公開を保留。
11. **画像がぼける／切れる**：出力寸法、元画像解像度、トリミング、掲載先圧縮を順に確認し、別ビューアで再試験。
12. **誤情報を図にしてしまった**：根拠資料へ戻って修正。確認できない図は「概念図」と明記するか掲載しない。

## 受講ワーク：候補比較と再現性

最初の生成で完成させようとせず、候補を2〜4点見比べます。候補Aは主役がよい、候補Bは色がよいなど、評価を要素ごとに分けると、修正指示を絞りやすくなります。次の表は「好み」と「用途適合」を区別する記録です。たとえば、色が美しくても、文字を置く余白がない、主役が小さすぎる、暗い背景で沈むなら用途には合っていない可能性があります。

| 観点 | 候補A | 候補B | 採用案／修正 |
|---|---|---|---|
| 用途と掲載先に合う比率 |  |  |  |
| 主役と動作がすぐ分かる |  |  |  |
| 必要な余白がある |  |  |  |
| 色と光が目的に合う |  |  |  |
| 不自然な形・不要物がない |  |  |  |
| 誤認や権利上の懸念がないか人が確認 |  |  |  |

作業時間や生成回数の上限があるときは、最初に優先順位をつけます。1回目に構図、2回目に色、3回目に細部の順で直すなど、比較の軸を決めます。生成サービスの設定・モデル・スタイル・縦横比を変えた場合は、同じプロンプトでも結果が変わるため、設定名もメモします。過去の候補を再現できない場合に備え、採用した画像と編集可能なデザイン、書き出しファイルを別々に保管します。

連続した挿絵やキャラクターを作る場合は、設定を固定しても同一性が保証されるわけではありません。目・毛色・服・持ち物など、物語上必須の特徴をキャラクターシートに書き、各ページの生成後に照合します。場面が変わることで衣装や持ち物が勝手に変化していたら、修正するか、手動で編集します。実在の人物をモデルにする場合は、本人の同意、利用目的、公開先を確認し、同意が明確でない顔写真は入力しないでください。
