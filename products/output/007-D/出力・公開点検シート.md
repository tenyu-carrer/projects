# 007 出力・公開点検シート

## 入力・生成
- [ ] 用途・縦横比・掲載先を決めた
- [ ] 利用サービス・プラン・AI規約を確認
- [ ] 個人情報・秘密情報を不用意に入力していない
- [ ] 参照画像の出典・許可・利用範囲を確認
- [ ] 作家・既存作品・ブランドの模倣を指示していない

## 画像
- [ ] 主役・動作・必要要素がある

- [ ] 説明図の事実を一次資料で検証した
- [ ] 不要な文字・ロゴ・透かしがない
