# 009-B セット見本の読み解き｜架空キャラクター

## 架空のキャラクター設定
- 丸いラッコ、茶色の体、クリーム色の口元
- 青い小さなスカーフ、右頬の点を各画像で共通化
- 大きく表情を変えるが、輪郭と色は固定

この例は架空の設計案であり、類似調査済み、商標確認済み、販売済みのキャラクターではありません。

| 場面 | 動作 | 文言 | 点検すること |
|---|---|---|---|
| 挨拶 | 手を上げる | おはよう | 小さくても手が見える |
| 返事 | うなずく | 了解！ | 表情が返事と一致 |
| 感謝 | 頭を下げる | ありがとう | 文字を体に重ねない |
| 依頼 | 両手を合わせる | お願いします | 手の輪郭が読める |
| 確認 | メモを見る | 確認します | 小物が主役を邪魔しない |
| 労い | お茶を持つ | おつかれさま | 湯気や色が淡すぎない |
| 保留 | 手のひらを見せる | 少し待って | 動作と文言が同じ意味 |
| 別れ | 手を振る | またね | 輪郭が切れない |

審査提出前に、現行公式ガイドの個数・画像サイズ・容量・形式・禁止事項を確認。販売結果は保証されません。
