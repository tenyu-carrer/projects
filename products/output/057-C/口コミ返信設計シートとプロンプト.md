# 057-C｜口コミ返信 設計シートとプロンプト

**状態：再利用用初稿／返信は必ず人が読んでから出す**

## 設計欄

- 返信する場所（Googleビジネスプロフィール、予約サイト、SNSのコメントなど）：
- 返信する人と、最後に確認する人：
- 返信の調子（ていねい・親しみ・短め）と、使わない言葉：
- 返信の目安の日数（例：3日以内）：
- 返信に書かないこと（名前・来店日・金額・病気やけがの話など）：
- 厳しい口コミのとき、店の外で話を聞く窓口（電話・メール）：

```text
口コミ【】を読んで、種類（うれしい・要望まじり・厳しい・事実と違う・規約に反しそう）と、書いた人が伝えたい要点を3つ以内でまとめて。推測で決めつけないで。
```
```text
口コミ【】への返信案を2つ作って。お礼→要点への返事→次につなげるひと言の順に、3〜4文で。名前・来店日・金額・品物の詳しいことは書かないで。
```
```text
厳しい口コミ【】への返信案を作って。まず不快な思いをさせたことにおわびし、言い訳や反論はせず、改善することと、店の連絡先【】で詳しく話を聞けることを書いて。事実の確認がまだのことは認めたり否定したりしないで。
```
```text
事実と違う内容をふくむ口コミ【】への返信案を作って。相手を責めず、こちらで確認できている事実【】だけを短く書いて。確認できていないことは書かないで。
```
```text
返信案【】を点検して。個人情報、言い訳、決めつけ、同じ言い回しのくり返し、約束できないこと（必ず・絶対など）がないか、直した案と一緒に出して。
```
```text
これまでの返信【】を並べて、同じ書き出しや同じ締めが続いていないか見て。言い回しを変えた案を3つ出して。
```
```text
1か月の口コミ【要点の一覧】から、多かった要望を3つまとめて。店で改善できることと、すぐには難しいことに分けて。
```
```text
口コミにお礼を伝える店内の案内文を作って。「よければ感想を書いてください」と伝えるだけにし、割引や景品と引き換えにしない文にして。
```

返信は、お店の顔になる文章です。AIの案はそのまま貼らず、必ず人が読んで、自分の言葉に直してから出します。
