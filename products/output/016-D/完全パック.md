# 016-D｜AIでバナー・サムネイルを作る方法

**状態：初稿／練習素材付き。公開・販売完成品ではありません**  
対象：初めて画像を作る人｜所要：約3〜5時間｜更新確認：2026-10-23  
題材：架空の「週末のコーヒー時間」動画。売上・再生数・クリック率を保証しません。

## 1｜この講座で身につけること

この講座は、AIに「おしゃれな画像を作って」と頼むだけの内容ではありません。誰に何を伝えるかを決め、掲載場所の条件を確認し、ラフを比較して、画像と文字を別々に整え、縮小しても読めるかを検品し、権利と承認を記録する一連の仕事を練習します。最終成果物は、①目的を書いたブリーフ、②比較できるレイアウト3案、③採用案と不採用理由、④公開前チェック記録です。

広告・サムネイルは小さな画面で一瞬見られるため、情報を詰め込み過ぎると伝わりません。また、目立つ表現が実際の内容と違えば、クリックを誘うだけで信頼を失います。数字や成果を根拠なく加えず、コンテンツの中身を正確に表すことを第一にします。

## 2｜作り始める前の5つの確認

1. **何に使うのか**：動画一覧、ブログ記事、SNS広告、イベント告知など、掲載場所を特定します。
2. **誰が見るのか**：年齢だけでなく、見る状況・知識・困りごとを具体化します。
3. **何を約束できるか**：実際にコンテンツで扱うことと、扱わないことを区別します。
4. **何を使えるのか**：写真、イラスト、フォント、ロゴの出典と許可を確認します。
5. **どんな仕様か**：サイズ、縦横比、容量、文字やロゴの扱いを掲載先の公式ヘルプで確認し、確認日を記録します。仕様は変わるため、古い教材記載だけで決めません。

不明点がある場合、画像生成に進む前に質問をまとめます。例：「この画像はどのページに表示されますか」「スマートフォン表示で残す文字はどれですか」「商品写真は加工してよい範囲を確認済みですか」。依頼者の回答がないまま、仮の条件を確定したものとして納品しないでください。

## 3｜完成見本を読む

添付の `016-banner-layout-study.png` は、架空のコーヒー時間を題材にした横長レイアウトの研究素材です。上段は右にカップを置き、左側を大きく空けた構成。下段左は左下に植物と色面、下段右は右下に植物と色面がある構成です。文字、商品名、ロゴ、広告効果は含みません。デザインの余白や視線誘導を比較するための見本であり、完成広告ではありません。

見本を100%表示で眺めるだけでなく、実際の利用サイズを想定して縮小します。小さくしたときも、主役の輪郭と文字を置く余地が分かるかを確認します。画像が美しくても、コピーが背景に埋もれる、主役が切れる、スマートフォン上で文字が読めないなら、構成を変えます。見本から色や配置をそのまま複製する必要はなく、自分の題材の内容と素材へ置き換えて初めて制作になります。

### 見本の比較メモ

| 観点 | 上段・右に主役 | 下段左 | 下段右 |
|---|---|---|---|
| 主役 | 右側のカップ | 左下の植物と色面 | 右下の植物と色面 |
| 文字の余白 | 左側の大きな空間 | 上部〜中央 | 左上〜中央 |
| 向いている題材の例 | 見出しが長めの案 | 左に情報を置く案 | 左側に短い見出しを置く案 |
| 気をつける点 | 余白に文字を詰めない | 小さな植物が主役と競合しないか | 右下の要素と掲載UIが重ならないか |

表は構成を考えるヒントであり、媒体上の安全領域を示すものではありません。プロフィール画像・再生時間・ボタン等が重なる位置は公開先ごとに異なるため、実際の公式仕様と表示プレビューを確認します。

## 4｜伝える内容を一文にする

制作前に次の形で書きます。「【誰】が【どんな状況】で見て、【何を得られる内容】だと分かる」。例：「休日の朝をゆっくり過ごしたい人が、手持ちの道具でコーヒーを淹れる動画だと分かる」。ここで「必ずプロの味」「人生が変わる」のような講座にない成果を足さないようにします。

その一文から、最も大切な情報をひとつ選び見出しにします。見出しを大きくするほど読者への約束も強くなるため、動画や記事の実内容で裏付けられる範囲か確認します。補足情報、日付、発信者名などを全て同じ強さで並べず、優先順位を決めます。短い言葉にできない場合、画像に文字を足す前に、企画の焦点を絞ります。

## 5｜AIで背景案を出し、文字は後から組む

生成AIは背景や雰囲気案の試作に便利ですが、文字、ロゴ、商品形状、手指、パッケージ表示などを正確に再現できるとは限りません。文字入り完成画像を一度に作らせず、背景素材とコピー案を別工程にします。実商品の正確さが必要なら、許可された元写真を編集可能な状態で配置し、生成画像で商品を描き直さない方法を使います。

### 背景案プロンプト（コピーして編集）

```text
目的：掲載先【媒体・場所】の【対象者】向けサムネイルの背景案を3種類。
動画の実際の内容：【内容】。主役：【自作または使用許諾済みの題材】。
横縦比・サイズ：【公式仕様を確認して記入】。構図：【主役位置】。
見出しを後から置く空間：【位置】。色：【色と理由】。雰囲気：【具体語】。
文字・ロゴ・透かし・実在ブランドに似た表現を生成しない。
事実にない商品、数値、効果、人物を足さない。
主役の形・色を別物に描き変えない。これは構成案であり、出力後に人が素材・内容・権利を検品する。
案ごとに構図の違いを説明する。
```

### コピー案プロンプト（コピーして編集）

```text
次の内容だけを根拠に、短いサムネイル見出しを5案作ってください。
対象者：【】 実際の内容：【】 伝えてよい価値：【】扱わない内容：【】
各案について、内容との一致、誤解されそうな点、より正確にする修正案を添えてください。
根拠のない数字、成果保証、過度な不安喚起、断定的な効果表現は使わない。
語句の最終確認と公開判断は人が行う。
```

### 画像・コピーを組み合わせる手順

1. AIが出した背景案を3案保存し、同じサイズで並べます。
2. 内容に最も合う構図を選び、選ばなかった案の理由も一行で記録します。
3. 文字はCanvaなどの編集可能なテキストとして配置し、画像に描かれた文字を採用しません。
4. 見出し、補足、発信者情報の順に強弱を付け、余白を確保します。
5. 文字のコントラスト、行間、端の余白を確認します。色だけで意味を区別しないようにします。
6. 縮小表示とスマートフォン実機で、主役・見出し・ボタンやUIとの重なりを確認します。
7. 元画像、編集ファイル、書き出し画像を異なるファイル名で保存します。

## 6｜レイアウトの基本を実例で練習

### 主役は一つに絞る
カップ、豆、ミル、人物、文字など、目立つ要素が増えるほど視線が散ります。最初のラフでは主役を一つ決め、他の要素は補助として控えめにします。複数商品が主役である場合は、同じ大きさで並べる意図があるかを依頼者と確認します。

### 文字の余白を確保する
模様の上に文字を置く場合は、読みづらさを拡大して確認します。背景に帯を重ねる、文字の背後を暗くする、配置場所を移すなどの手段を比較します。影や縁取りを足せば解決とは限りません。細い文字、長文、小さな注記は縮小時に消えやすいため、内容を分けるか配置を再検討します。

### 視線の流れを作る
見る人の視線が「主役→見出し→必要な補足」へ進むかを確認します。矢印や丸囲みを多用するのでなく、位置、サイズ、余白、明暗差で順序を作ります。主役と見出しが互いに競い合う場合、片方を小さくする、位置をずらす、コピーを短くするなど、最小の変更から試します。

### 色と可読性
色の印象だけでなく、文字と背景の明暗差を確認します。赤と緑など色味の違いだけに依存すると、見分けにくい人がいます。文字を実際の掲載サイズで確認し、重要情報は形やラベルでも区別します。サービスのアクセシビリティ指針がある場合は、最新の公式資料を確認します。

## 7｜段階別課題

**練習1：観察（20分）** 付属のレイアウト研究素材から一案を選び、主役・文字の余白・縮小時の弱点を記録します。画像の中に完成コピーを書き込まず、紙や別レイヤーにラフを作ります。

**練習2：架空コンテンツ案（60分）** 自分で架空の短い動画内容を設定し、対象者、内容、見出し、禁止表現をブリーフへ記入。AIで背景案を3つ作り、内容との一致と権利・利用条件を確認し、ひとつを採用します。架空企画であることを作品内または説明文に示します。

**練習3：実際の自分のコンテンツ（90分）** 自分が権利を持つ写真または利用許可を得た素材で、公開先の仕様を調べて制作。PCとスマートフォンで表示を確認し、第三者1人に「何の内容に見えるか」「読めない文字はないか」を尋ねます。誤解があれば、見出しや構成を直し再確認します。

## 8｜よくある失敗と修正の考え方

1. **主役が不明**：目立つ要素を一つに絞り、残りを補助へ。
2. **文字が読めない**：背景の余白を作り、短いコピーにして縮小。
3. **AI文字が崩れる**：文字を画像から外し、編集可能なテキストに置換。
4. **商品が実物と違う**：元写真を使い、形・色・ラベルを照合。
5. **内容を誇張している**：動画・記事にない約束を削る。
6. **見出しが端で切れる**：公式の表示UI・安全領域を再確認。
7. **素材の権利が不明**：出典・契約確認まで公開停止。
8. **既存ロゴに似る**：固有名詞・ロゴを避け、独自形状へ。
9. **派手でも目立たない**：強調する要素を一つに整理。
10. **書き出しがぼやける**：仕様を再確認し、元サイズから出力。
11. **スマホで見えない**：実機または縮小プレビューで修正。
12. **案の差がない**：主役位置・余白方向・色を変えて比較。

対処後は採用案と不採用理由を記録し、変更前の版を残します。

| 症状 | 起こりやすい原因 | まず試すこと |
|---|---|---|
| 何の画像か分からない | 主役が複数、内容が抽象的 | 内容を一文に戻して主役を一つに絞る |
| 文字が読めない | 背景と同化、文字が細かい | 余白を広げ、短文化し縮小確認 |
| AI文字が崩れる | 画像内文字を生成した | 文字を削り、編集可能テキストで組む |
| 商品が実物と違う | AIが再構成した | 元写真を保持する編集に切替、色・形を照合 |
| クリックを誘うが中身と違う | 成果や内容を誇張 | 動画・記事と一文ずつ照合し、約束を修正 |
| 見出しが端で切れる | 安全領域・端の余白不足 | 掲載先の表示UIを調べ、内側へ移動 |
| 写真の権利が不明 | 出典・許可の記録漏れ | 公開停止。出典・契約・許諾を確認 |
| ロゴが似てしまう | 既存ブランドを参照・模倣 | 固有名詞・ロゴを外し独自の形へ変更 |
| 色が派手でも目立たない | 情報が多く競合 | 強調箇所を一つにし、他を抑える |
| 書き出しがぼやける | サイズ・形式・拡大縮小 | 公式要件を再確認し元サイズから出力 |
| PCでよくてもスマホで見えない | 実表示を確認していない | 実機または縮小プレビューで再構成 |
| 複数案の違いがない | プロンプトの構図指定が曖昧 | 主役位置・余白方向・色を変えて再生成 |
| 余白が空き過ぎて見える | 情報の優先順位が曖昧 | 補足を足す前に背景や主役の配置を調整 |
| 画像が重くアップできない | 容量制限や形式違い | 最新の公開先仕様で形式・容量を確認 |
| チームで最新版が分からない | ファイル名や承認記録がない | v番号、日付、承認者を名前とログへ追加 |

修正を一度に多数加えると、何が効いたのか判別しにくくなります。一回につき一つの変更を行い、変更前・変更後を並べて比較します。結果が悪くなった場合に戻せるよう、編集可能な原本を保管します。

## 9｜品質基準：100点で自己点検

| 項目 | 配点 | 合格の目安 |
|---|---:|---|
| 対象者と内容の明確さ | 15 | 誰向けの何の内容か一文で説明できる |
| 内容との正確さ | 20 | 実際に扱う内容だけを約束し、誇張がない |
| 主役と視線の順序 | 15 | 主役がひとつ明確で、情報の強弱がある |
| 小画面での可読性 | 15 | 実際の掲載サイズで見出しが読める |
| 余白・コントラスト | 10 | 背景と文字が混ざらず、切れや重なりがない |
| 素材と権利の記録 | 15 | 出典・許可・AI利用条件を確認できる |
| 版・承認・書き出し | 10 | 保存ファイルを開き直し、承認と版を記録 |

**公開前ゲート：** 合計点が高くても、内容の誤認、権利不明、仕様未確認、承認漏れがひとつでもあれば公開を止めます。これは学習用の自己評価であり、法令適合・媒体審査・広告成果を保証するものではありません。

## 10｜公開前チェックリスト

- [ ] 対象者と掲載場所をブリーフに記入した
- [ ] 実際のコンテンツと見出し・画像が一致している
- [ ] 根拠のない数値・効果・保証を加えていない
- [ ] 主役が明確で、文字・補足の優先順位がある
- [ ] 小さな表示で見出しと重要情報を読める
- [ ] 端の切れ、UIとの重なり、余白を確認した
- [ ] 写真・イラスト・フォント・ロゴの出典と使用許諾を確認した
- [ ] AI生成箇所が実物や実績と誤認されない
- [ ] 公式仕様の確認日、形式、サイズを記録した
- [ ] 書き出したファイルを閉じて再度開き、色や欠けを確認した
- [ ] ファイル名・バージョン・承認者・日付を記録した
- [ ] 公開先での実表示またはプレビューを確認した

## 11｜権利・安全・公式資料

他人の写真・イラスト・広告を無断で入力素材にしないでください。人物を含む画像や顧客情報は、本人の同意、契約、外部AIへの送信条件を確認できるまで利用を保留します。既存作品やブランドに酷似させる指示を避け、生成結果についても類似性・利用規約・公開範囲を確認します。サービスの機能・ライセンス・利用条件は変わるため、実際に制作する日に公式資料を読み直します。法的判断が必要な案件は専門家に確認します。クリック率や売上などの成果を保証しない教材です。

確認資料（2026-10-23時点。利用時に再確認）：[文化庁「AIと著作権について」](https://www.bunka.go.jp/seisaku/chosakuken/aiandcopyright.html)、[Canvaコンテンツ使用許諾契約](https://www.canva.com/ja_jp/policies/content-license-agreement/)、[Canvaで販売用デザインを作る際のヘルプ](https://www.canva.com/ja_jp/help/using-canva-to-create-products-for-sale/)。公開先の画像サイズ・広告ポリシーは各媒体の公式ヘルプを利用時に確認してください。
