# 080-B｜Webコンテンツ制作事業 見本の読み解き

**状態：架空の個人事業による見本。実際の受注・売上は未検証**

付属の見本は、架空のフリーランス・松本さん（架空）が、地元の飲食店向けに「メルマガとLINE配信の文章づくり」のサービスを始めたときの設計記録です。

- `080-business-flow.png`：サービス決めから納品・振り返りまでの流れ図
- `080-service-menu.png`：サービスの中身（納品物・回数・やらないこと）の図
- `080-pricing-sheet.csv`：料金の決め方の表（作業時間・確認の回数・料金・その理由）
- `080-order-terms.md`：受ける前に確かめる取引条件のメモの見本（納品物・期限・報酬・支払日・直しの回数・権利）
- `080-delivery-checklist.csv`：納品前のチェック表（事実の確認・表示のルール・AIの使い方の説明）

見るポイント：

1. **サービスを1つにしぼった**：「何でもできます」ではなく「飲食店の月4回のLINE配信の文章」にしています。
2. **やらないことも書いた**：配信の操作・写真の撮影・効果の保証はしない、と最初に書いています。
3. **取引条件を書面にした**：納品物・期限・報酬・支払日・直しの回数・文章の権利を、受ける前にお客さんとメールで確かめています。
4. **AIを使うことを伝えた**：下書きにAIを使い、事実と表現は人が確かめる、と説明しています。

この見本は考え方を示すためのもので、実在の人物・事業・売上ではありません。
