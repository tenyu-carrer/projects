# 040-C｜音声編集・ノイズ除去 設計シートとプロンプト

**状態：再利用用初稿／処理の結果は必ず耳で聞き比べる**

## 設計欄

- 録音の用途（動画・ポッドキャスト・ナレーション）と長さ：
- 元の録音ファイルの保存場所（上書きしない）：
- 雑音の種類（ずっと鳴る音／一瞬の音／部屋の響き）：
- 使うソフト・機能と、その利用条件：
- 外部のAIサービスに音声を送る場合の確認（話している人の同意・個人情報）：
- 聞き比べの環境（スピーカー・イヤホン）／確認者／確認日：

```text
録音を聞いて気づいた音【】を、ずっと鳴る音・一瞬の音・部屋の響き・声の問題（息・口の音）に分けて表にして。録音で防げるか、編集で減らせるかも書いて。
```
```text
次の録音環境【部屋・機材・時間帯】で、雑音を減らすための録音前の工夫を5つ。お金をかけずにできる順に並べて。
```
```text
雑音の種類【】ごとに、編集で使う処理の候補（ノイズ除去・音量をそろえる・高い音や低い音を減らす・切る）と、かけすぎたときに起こる問題を表にして。
```
```text
処理の前後の聞き比べの感想【】から、かけすぎ・足りないの判断と、次に試す設定の方向（強く・弱く）を整理して。
```
```text
録音の文字起こし【】から、一瞬の物音や咳が入っている箇所を時刻つきで抜き出して。切るか残すかの判断は人がするので、候補として出して。
```
```text
音声を外部のAIサービスで処理する前の確認リストを作って。話している人の同意、個人情報、サービスの保存・利用の条件。
```
```text
処理記録【】をもとに、次回同じ部屋で録音するときの「設定メモ」を作って。
```
```text
完成した音声の確認表を作って。項目：声のこもり、金属的な音、音量の差、語頭・語尾の欠け、息の音、無音の不自然さ。
```

処理を強くするほど、声そのものも傷みます。「少し雑音が残っても、声が自然」なほうが聞きやすいことが多いです。
