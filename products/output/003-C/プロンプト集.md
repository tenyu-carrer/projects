# 003-C｜名刺・ショップカードのプロンプト集

## 個人情報の扱い

氏名、個人電話、住所、顧客情報、非公開URLをAIへ入力しないでください。`[仕事用連絡先]`等の仮ラベルを使い、生成後に本人が原本と照合します。AIが事実・権利・QRの動作を保証することはありません。

### 1. 掲載項目の優先順位

```text
小規模事業の編集者として、名刺の情報を「必須」「補助」「今回は載せない」に分けてください。
相手：[想定相手]／目的：[相手にしてほしい行動]／仕事内容：[公開可能な事実]
個人情報や連絡先を作らず、不明は「要確認」とする。分類理由を各1行で説明してください。
```

### 2. 仕事説明を短くする

```text
次の事実を、初めて会う[相手]に伝わる名刺用の説明へ短くしてください。
事実：[対象と提供内容]
15〜28字の案を5つ。成果保証・根拠のない最上級・事実の追加は禁止。何を手伝う人か具体的にし、推測が入った案は除外してください。
```

### 3. 表裏の設計案

```text
名刺の表裏の情報設計を提案してください。
相手：[相手]／主目的：[行動]／掲載できる内容：[個人情報を除いた項目]
表面は氏名/屋号と仕事説明を優先。裏面は[サービス/営業時間/予約案内]の1つを主役にする。読む順序、削る候補、QR横の説明文を提案。URL・住所・実績・QR遷移先は創作しない。
```

### 4. 初見テスト

```text
次のカード案の5秒テスト質問を作ってください：[個人情報を除いた掲載文]
誘導しない質問で「誰のカードか」「何を頼めるか」「次に何をするか」を測る。回答者の個人情報を求めず、合格条件も3項目で示してください。
```

### 5. 事実を変えない校正

```text
以下の名刺原稿を校正してください：[公開前に必要最小限の原稿]
表記上の誤り候補、原本との照合が必要な項目、レイアウトで人が確認する項目に分ける。氏名・電話・URL・住所・資格を推測で修正しない。不明は質問にしてください。
```

### 6. 情報を削って余白を作る

```text
名刺に情報を詰め込みすぎています。目的：[目的]、相手：[相手]、候補：[個人情報を除く]
残す項目を最大5つ選び、削除・裏面へ移動・Web誘導に分類。選んだ根拠を説明し、法的に必要だと断定しない。連絡先や住所を創作しない。
```
