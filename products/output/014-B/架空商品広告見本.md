# 014-B 架空商品広告の見本・使い方

## 実物ファイル

- [架空クッキーの広告用商品写真PNG](../014-D/assets/014-cookie-product-photo-concept.png)

この写真は教材用に生成した架空のパッケージとクッキーです。実在する店舗・商品・食品の撮影写真ではなく、販売・注文を受け付ける商品でもありません。写真素材単体は構図練習用。商品名・価格・アレルギー表示・原材料・産地・賞味期限・受賞歴は画像から確定できません。広告へ載せる場合は、実際の販売者が確認した根拠のある情報だけを使います。

## 見本の構図を読む

- 商品パッケージ：中央右に大きく配置し、視線の主役にする。
- 食べ物：手前に置き、商品との関係を見せる。
- 余白：左上はコピーを置けるが、背景の模様があるので文字面を敷くか配置を再考。
- 背景：温かな室内。清潔感を補うが、素材や味を保証するものではない。
- 禁止：架空の商品名を実在ブランドのように表示、未確認の効能・受賞・限定・売上訴求を追加。

## 仮のコピー（架空と明記する用途のみ）

見出し：「午後のおやつに、焼きたてのひと休み」
補足：「商品・販売情報は架空の練習用です」
行動案内：「レイアウトを試してみる」

このコピーは販売用ではありません。商品名・価格・注文リンクを付けず、構成検討にだけ使います。

## 合格

- [ ] 商品写真が最初に見える
- [ ] 読者、約束する価値、次の行動が混ざっていない
- [ ] 余白、コントラスト、文字サイズをスマホで確認
- [ ] 商品情報の事実根拠と広告主の承認がある（実案件のみ）
- [ ] 見本の架空設定が公開画面にも伝わる
