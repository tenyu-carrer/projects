## 再利用プロンプト

### 素材棚卸し
```text
動画素材台帳【】を、ファイル名、尺、内容、人物同意、音楽・画像権利、機密、画質、音質、使用可否で整理。内容を推測せず不明は保留。
```
### 粗編集案
```text
目的【】、視聴者【】、完成尺【】、素材メモ【】からEDL案を作る。開始・終了、残す理由、削る理由、事実欠落リスクを列にし、元動画で人が照合する。
```
### 文字起こし校正
```text
自動文字起こし【】を原音と照合するため、固有名詞、数字、否定、専門語、話者、聞き取り不能を一覧化。推測補完せずタイムコードを残す。
```
### 字幕分割
```text
校正済み台本【】を、意味の切れ目と読み時間で字幕へ分割。音声にない主張を足さず、1画面の情報量、改行、表示時間を確認する表にする。
```
### Bロール候補
```text
台本【】の理解を助けるBロール候補を、必要区間・役割・使用可能素材で提案。事実にない商品・人物・場所を作らず、素材権利と誤認を確認項目にする。
```
### 音声点検
```text
音声ログ【】から、聞き取りにくい区間、急な音量差、ノイズ、無音、音楽との競合を整理。自動補正値を断定せず、ヘッドホンとスピーカーで人が確認する順番を示す。
```
### 書き出し確認
```text
公開先の公式仕様【】と書き出し情報【】を照合。解像度、縦横比、フレームレート、形式、コーデック、音声、容量、字幕を比較し、不明は未確認にする。
```
### 公開前レビュー
```text
編集記録【】を、内容の正確さ、権利、映像、字幕、音声、書き出し、公開先表示、承認で点検。不足は公開保留。再生数・成果を保証しない。
```
