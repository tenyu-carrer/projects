# 009-D プロンプト集｜静止画スタンプ

## 1. 利用場面の整理
```text
利用者：【】関係性：【】会話目的：【】セット数：【公式最新選択肢から】
挨拶、返事、感謝、依頼、確認、保留、労い、別れなどを重複なく提案。
各案に短い文言、ポーズ、表情、利用例を付ける。
広告・URL・個人情報要求・他者キャラクターは提案しない。
```

## 2. キャラクター方向性
```text
スタンプ用のオリジナルキャラクター案を3つ。
利用場面：【】雰囲気：【】固定特徴：【】避ける要素：【】
輪郭、色、目、服、小物、縮小時に識別できる特徴を記述。
既存作品・商標・人物を模倣しない。権利安全性や類似の有無を断定しない。
```

## 3. 1枚の画像生成
```text
キャラクター固定設定：【】場面：【】動作：【】表情：【】文言：【】
文字はデザインツールで後から配置するため、画像生成内は文字なし。
透明背景を想定し、外周余白を確保。顔・手・輪郭を明瞭に。
既存キャラクター、ブランド、実在人物の模倣なし。ロゴ・署名・透かしなし。
```

## 4. 文言・審査ガイド点検
```text
候補文言：【】利用場面：【】画像のポーズ：【】
誤字、意味の重複、画像との矛盾、広告・URL・個人情報等の懸念を列挙。
審査結果を予測・保証せず、公式ガイド確認と人の校正を促す。
```

## 5. 一覧の多様性点検
```text
番号・文言・ポーズ・表情・色：【】
場面重複、ポーズ単調、淡色偏り、小表示、セットの統一感を点検。
点数だけで合格とせず、修正案と人が現物で見る項目を分ける。
```

## 6. 素材台帳整理
```text
素材名・作成者・出典・取得日・ライセンスURL・使用範囲：【】
表に整理。空欄は未確認とし、商用・スタンプ用途の可否を推測しない。
証跡と公式確認が必要な箇所を列挙する。
```

## 7. 申請用メタデータ
```text
タイトル：【】説明文：【】クリエイター名：【】コピーライト：【】
公式ガイドの現在の文字数上限：【確認済み値または未確認】
誤字と画像との一致を点検。上限や審査基準を推測せず、URL・広告があれば要確認。
```
