# 002 プロンプト集｜イベントチラシ

## 1. 情報の不足・矛盾を発見する
```text
次のイベント情報を確認し、(1)不足している項目、(2)互いに矛盾する項目、(3)確認先が必要な項目を表にしてください。情報を推測で補わない。不明欄は「要確認」とする。日付・曜日・料金・定員・住所・申込URLを特に確認。個人情報は入力しない。
情報：〔公開してよい情報のみ〕
```

## 2. 読者に伝わる見出し案
```text
イベント告知の編集者として、以下の確定事実だけを使い、誇張・成果保証・根拠のない最上級表現を避けて見出しを5案作ってください。誰向けかと参加内容が想像できる案を優先。事実を追加しない。各案に「伝わる点」と「確認が必要な表現」を付ける。
対象：〔 〕 内容：〔 〕 確定した参加メリット：〔 〕
```

## 3. A4用短文へ編集
```text
次の確定済み原稿を、A4チラシに載せる短い日本語へ編集してください。意味と条件を変えない。日時・場所・料金・申込方法は別枠に分け、本文は80字以内、内容は箇条書き最大3点。不明は補完せず「要確認」。編集前後の差分も説明。
原稿：〔 〕
```

## 4. 初見の参加者として読解テスト
```text
あなたは初めてこの案内を見る人です。本文から「何の催しか／誰向けか／いつ・どこか／費用はいくらか／どう申込むか」を抜き出してください。答えが見つからない項目は「見つからない」と書き、改善案を示す。書かれていない事実は推測しない。
チラシの文字：〔テキストを貼る〕
```

## 5. 文字・権利・誤認の校正
```text
以下のチラシ原稿を校正してください。誤字脱字、表記ゆれ、矛盾、誤認を招く誇張、根拠のない保証、第三者の権利に関する確認点を分類し、該当箇所・理由・修正案を示してください。権利状態を断定せず、確認が必要なものは「要確認」。事実の正誤は外部一次情報の確認が必要と明記。
原稿：〔 〕
```

## 6. 余白と読み順のレビュー
```text
次のA4チラシ配置を文字で説明します。5秒で「イベント名・日時・次の行動」が見つかるか、読み順が自然か、文字量やコントラストの懸念はないかをレビューしてください。見ていない画像を見たふりせず、判断できない点は質問として挙げる。
配置メモ：〔上からの要素と大きさ〕
```

## 共通の注意
AIは事実・権利・印刷品質を保証しません。氏名、電話番号、参加者情報など不要な個人情報を入力せず、出力を人が確認します。
