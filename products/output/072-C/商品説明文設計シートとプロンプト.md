# 072-C｜AIで商品説明文を作る 設計シートとプロンプト

**状態：再利用用初稿／販売サイトの規約・法律の運用は使う時点で公式ページを確認**

## 設計欄

- 商品名と、その名前にした理由：
- 使う人と使う場面：
- 合わない人：
- 事実シート（サイズ・素材・重さ・色・生産地・お手入れ）を実物で確かめた日：
- ほかの商品とちがう点（事実だけ）：
- 書けない言葉（効果・医薬品のような言葉・確かめていない数字）：
- 写真に写っているものと、商品に含まれるもの：
- 注意（色のちがい・洗濯・使ってはいけない使い方など）：
- よくある質問（3つ以上）：
- 販売サイトの文字数や書き方の決まり（確認日）：
- 公開前に読んでもらう人：
- 確認者／確認日：

## プロンプト（この順で使います）

```text
次の商品の事実を、表に整理して。【商品のメモ】。項目は、サイズ・素材・重さ・色・生産地・お手入れ・注意。メモにない項目は「未確認」と書き、推測で埋めないで。
```
```text
この商品【商品名・事実シート】を使いそうな人と使う場面を10個、合わない人を3つ出して。事実シートにないことは根拠にしないで。
```
```text
次の事実シート【表】から、商品説明文の最初の2行を5案作って。1行目は用途と合う人、2行目はほかの商品とちがう点（事実だけ）。効果・受賞・売上・ランキング・「最高」「No.1」「絶対」は使わないで。
```
```text
次の材料【最初の2行・事実シート・注意・使い方】で、商品説明文を作って。順番は「用途と合う人→特長3つ→仕様の表→使い方とお手入れ→注意→よくある質問」。事実シートにないことは書かないで。
```
```text
次の商品説明文【文】に、事実シート【表】にないことが書かれていないか、1文ずつ照らし合わせて表にして。合っている／事実シートにない／判断できない、で分けて。
```
```text
次の商品説明文【文】に、確かめていない効果の言葉（治る・やせる・〜に効く・抗菌など）、医薬品のような言葉、根拠のない「No.1」「最高」「人気」などがないか点検して。当たりそうな所に印をつけて、事実に置きかえる案を書いて。最終的な判断は私がする。
```
```text
この商品【商品名・事実シート】について、買う前に聞かれそうな質問を8個と、その答えの下書きを作って。答えは事実シートにあることだけで書き、分からないことは「確認中」と書いて。
```
```text
商品ページを公開して30日たちました。分かっていること【よく来た質問・返品や問い合わせの理由・閲覧と購入の数】をもとに、説明文で足すこと・直すことを表にして。数が少ないときは「まだ判断できない」と書いて。
```

AIは**整理・案出し・点検**に使い、書く事実と公開は自分で決めます。販売サイトの決まりや法律は変わることがあるので、公開の前に公式ページを読みます。
