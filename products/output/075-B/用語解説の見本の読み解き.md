# 075-B｜専門用語の解説 見本の読み解き

**状態：架空の書き手による見本。実際の記事での効果は未検証**

付属の見本は、架空の小さな工務店「さくら工房（架空）」のスタッフ・加藤さん（架空）が、お客さん向けに「家づくりでよく出る言葉」の用語集ページを作ったときの記録です。

- `075-explain-flow.png`：用語選びから公開・見直しまでの流れ図
- `075-explain-ladder.png`：説明の3段（ひとこと→たとえ→くわしく）の図
- `075-term-list.csv`：用語の一覧（用語・読む人がつまずく理由・ひとこと・確かめた先）
- `075-sample-glossary.md`：完成見本の用語解説5つ
- `075-accuracy-check.md`：分かりやすくしたことで意味がずれた所と、直した記録

見るポイント：

1. **読む人がつまずく言葉から選んだ**：お客さんに実際に聞き返された言葉を3か月メモして、そこから選んでいます。
2. **説明は3段**：「ひとこと」で全体をつかみ、「たとえ」で身近にし、「くわしく」で正確にしています。たとえだけで終わらせていません。
3. **たとえの限界を書いた**：「断熱材は家のダウンジャケット」には、「ただし、湿気の対策は別に必要です」と限界を添えています。
4. **確かめた先と日付を書いた**：税や制度の言葉は、国の公式ページで確かめた日付を書き、細かい数字は公式ページへのリンクにしています。

この見本は考え方を示すためのもので、実在の人物・お店ではありません。
