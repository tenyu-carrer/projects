# 007-A 無料10分体験｜主役・動作・場所

## 10分で試す
1. 画像の用途を決める（1分）：挿絵／投稿／教材など。
2. 主役を一つ書く（2分）。
3. 主役の動作を具体的な動詞で書く（2分）。
4. 場所・時間を加える（2分）。
5. 「文字なし・ロゴなし」など避けたいものを書く（1分）。
6. 1枚生成し、用途・主役・動作が伝わるか確認（2分）。

## 記入
- 用途：
- 主役：
- 動作：
- 場所・時間：
- 画風：
- 避けるもの：
- 使用サービス／確認日：

## 合格
- [ ] 主役は一つに絞った
- [ ] 動作を具体的に書いた
- [ ] 実在作品・作家の模倣を指示していない
- [ ] 生成物を事実の証拠として誤認させない
- [ ] 不自然な形と文字を現物で確認した
