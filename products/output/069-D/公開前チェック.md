# 069-D｜メルマガ 公開前チェック

- [ ] 送る相手は全員、自分で登録して同意した人
- [ ] 登録の画面に、何を・どのくらい・誰から送るかを記載
- [ ] 同意の記録が残る
- [ ] 1通1テーマ、最初の3行に結論
- [ ] 件名と本文が合っている
- [ ] 体験談は事実だけ
- [ ] 根拠のない言い切り・数字なし
- [ ] 署名に送信者の名前・住所・問い合わせ先
- [ ] 配信停止の連絡先と案内
- [ ] 自分あてにテスト配信した
- [ ] 配信サービスの規約・料金を確認日つきで確認
- [ ] 見直す日と見る数字を決めた

同意のない相手に送る、署名や配信停止の案内がない場合は配信しない。売上・読者の数を保証しない。
