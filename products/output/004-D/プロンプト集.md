# 004-D 実務プロンプト集｜Canvaプレゼン

各プロンプトは、機密情報を入れずに使います。AIの出力は下書きです。事実・数字・権利・計算は人が元資料で検証します。

## 1. 構成案
```text
入力だけを根拠に、聞き手に伝わるプレゼンの骨組みを作成してください。
聞き手：【】／疑問：【】／目的（最後の行動一つ）：【】
時間：【】分／枚数：【】／用途：【投影・配布】
確認済みの事実と出典：【】
未確認事項：【】
各ページに「結論見出し・本文最大3項目・視覚表現案・出典表示・話すメモ」を提案。
入力にない数字、実績、引用、URL、開催条件は作らず「要確認」と記す。
見出しのみ順に読んだときの論理の飛躍も最後に指摘する。
```

## 2. 一枚一主張チェック
```text
次のスライド草稿を、1ページにつき主張が一つか点検してください。
聞き手：【】　このページの目的：【】　草稿：【】
複数の主張がある場合は分け方を提示。意味を変える短縮や新しい事実の追加は禁止。
出力：主張／補助情報／削る候補／確認が必要な表現。
```

## 3. 出典・数値点検
```text
次の資料にある数値・引用・事実の主張を抽出し、出典台帳と照合してください。
スライド：【】　出典台帳：【】
数値は単位、期間、母数、比較条件が揃っているか確認。
根拠が見当たらないものは推測で補わず「出典未確認」とし、削除または確認する質問を示す。
```

## 4. 文章の簡潔化
```text
スライド本文を読みやすく短くしてください。
ページの結論：【】　聞き手：【】　本文：【】　残すべき条件：【】
見出し候補3つと本文3項目以内を出す。断定の強さ、条件、対象を変えない。
削ると意味が変わる場合は削らず、その箇所と理由を伝える。
```

## 5. 視覚表現選び
```text
伝えたい結論：【】　確認済み情報：【】　出典：【】
文章／比較表／時系列／手順図／写真のうち適した表現を選び、理由と配置案を示す。
データが不足している場合はグラフを作らない。概念図を提案するときは「概念図」と明記。
色だけで意味を区別せず、文字ラベルや形も併用する案にする。
```

## 6. 発表者メモ
```text
次のページを発表するための自然な話し言葉のメモを作ってください。
聞き手：【】　ページ見出し：【】　表示本文：【】　根拠資料：【】
目安時間：【】秒。スライドにない事実を付け足さず、詳細は出典を示す。
次ページへのつなぎを一文、想定質問を2つ、回答に必要な確認事項を添える。
```

## 7. アクセシビリティ・読みやすさ
```text
次のスライドの読みやすさ上のリスクを、テキスト情報から点検してください。
背景色・文字色：【】　文字サイズ：【】　本文：【】　図の説明：【】
小さい文字、色だけの区別、略語、長文、代替テキスト不足、読み順の不明瞭さを指摘。
実際の見え方を確認できない項目は「画面で要確認」とする。
```

## 8. 最終校閲
```text
公開前のプレゼンを校閲してください。草稿の正しさを推測で補完しないでください。
ページごとの原稿：【】　出典台帳：【】　用途：【】　制限時間：【】分
論理、表記、日付・URL、出典、権利、個人情報、誤認を招く表現を表形式で点検。
各指摘にページ番号、問題、影響、修正案、人の確認先を付ける。
```

## 9. 発表時間の調整
```text
以下の発表メモの所要時間を段落ごとに見積もり、指定時間に収まる調整案を出す。
指定時間：【】分　質疑時間：【】分　メモ：【】
読み上げ速度は仮定として明記し、実測時間ではないと注意する。
削る候補は重要度の低い補足から提案し、根拠や条件は削らない。
```

## 10. 質疑準備
```text
聞き手：【】　プレゼンの目的：【】　掲載内容：【】
聞き手が確認しそうな質問を5つ出し、回答に必要な事実と出典を示す欄を付ける。
資料にない答えは創作せず「担当者へ確認」とする。個人情報や内部情報を含む質問への安全な対応も提案。
```
