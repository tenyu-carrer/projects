# 013-C 写真補正設計シートとプロンプト

## 作業前ブリーフ

- 写真の用途・媒体：
- 撮影者・使用権限・本人同意の確認：
- 原本ファイル・サイズ：
- 直したい症状（最大2つ）：
- 残すもの（被写体・色・形・背景）：
- 変えてよいもの：
- 公開範囲・納品先仕様：
- 使用アプリ・AI機能・プラン・確認日：
- 個人情報・位置情報・顔の有無：

## AIへ相談するプロンプト

### 補正方針を整理

```text
写真の用途：【】。困っている点：【】。絶対に変えないもの：【】。
編集は最小限にし、変える項目を一つずつ提案してください。
各提案に、見込める効果・起きる副作用・元に戻す方法を付ける。
人物の年齢、体型、肌、表情、身元を変える提案はしない。
```

### 背景除去の前提確認

```text
目的：【】。被写体と髪・透明物・影で守る境界：【】。
背景のみを変える手順と、輪郭が欠けた時の復旧方法を示してください。
元データを保持し、変更前後を比較する。本人の同意や利用権が不明なら作業を保留する。
```

### 編集ログの整理

```text
原本：【】、編集コピー：【】、変更項目と値：【】、採用理由：【】。
保存先・形式・サイズ：【】。未確認の権利・色・印刷・本人同意：【】。
事実を追加せず、記録漏れと次に確認する点を箇条書きで示す。
```

## 失敗時の戻し方

原本から再コピーし、変更は一つだけに限定。AI加工で顔や商品形状が変わった場合は、部分修正で整合したと決めつけず、当該編集を破棄して別手法か元画像を選びます。
