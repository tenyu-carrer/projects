# 039-C｜ポッドキャスト 設計シートとプロンプト

**状態：再利用用初稿／AIの案は必ず自分の言葉と事実で直す**

## 設計欄

- 番組名／テーマ／聞いてほしい人／1回の長さ／配信の頻度：
- 話し手（1人・2人・ゲストあり）と、出演・配信の同意の取り方：
- 毎回の型（オープニング・話題・質問・エンディング）：
- 配信先（配信サービス）と、その規約の確認日：
- BGM・ジングル（番組の始まりの短い音楽）の利用条件：
- 確認者／確認日：

```text
テーマ【】、聞いてほしい人【】で、ポッドキャスト番組の企画を作って。番組名3案、1回の長さ、配信の頻度、毎回の型、最初の4回分の題名を出して。
```
```text
今回の話題【】で、15分回の進行表を作って。オープニング・話題3つ・聞いている人への質問・エンディングの各部分に、時間と話すことを書いて。
```
```text
進行表【】の中で、事実・数字・制度・料金など、話す前に確認が必要な箇所を抜き出して、確認先の候補を付けて。
```
```text
録音の文字起こし【】から、エピソードの説明文（200文字程度）と、話題ごとの時刻（チャプター）を作って。
```
```text
録音の文字起こし【】から、言い間違い・長い沈黙・話がそれた箇所を時刻つきで一覧にして。削るかどうかの判断は人がするので、候補として出して。
```
```text
ゲスト出演の依頼文を作って。番組名【】、話してほしいこと【】、録音の方法と時間、配信する場所、名前の出し方、編集の範囲を入れて。
```
```text
エピソード【題名・説明文】を紹介するSNS投稿文を2案作って。内容を大げさにしないで。
```
```text
これまでのエピソード一覧【題名と話題】を見て、次の4回分の題名案を出して。同じ話題のくり返しにならないように。
```

AIは企画や説明文の下書きに使い、話の中身は自分の経験と確認した情報で話します。
