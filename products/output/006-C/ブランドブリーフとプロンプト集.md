# 006-C ブランドブリーフとプロンプト集

## ブリーフ
- ブランド正式表記・読み方：
- 事業内容（1文）：
- 顧客の課題：
- 覚えてほしい印象3語：
- 使用場所・背景・最小サイズ：
- 避けたい誤認・図柄・色：
- 競合と区別する理由：
- 使用するツール・素材・フォント：
- 商標調査語・検索先・確認日：
- 専門家確認の要否・担当：

## プロンプト1｜方向性発想
```text
ブランド名：【】事業：【】顧客：【】印象：【】使用場所：【】
避ける表現・誤認：【】
既存ブランド・特定作家の模倣なしで、ロゴの方向性を3案文章で説明。
各案の形の意味、縮小時の注意、単色版、人が独自性を検討する質問を含める。
商標の空きや登録可能性を断定しない。
```

## プロンプト2｜生成指示文の下書き
```text
用途はコンセプト検討用。事業：【】印象：【】避けるもの：【】
特定企業・商標・キャラクター・作家の模倣を避けた抽象的な図形案を3方向。
文字・実績・認証マークを画像内に生成しない。
生成画像は最終ロゴや商標登録可能素材とみなせない旨を明記。
```

## プロンプト3｜デザイン批評
```text
事業：【】顧客：【】用途：【】印象：【】素材と条件：【】
ロゴ案の説明または画像特徴：【】
視認性、文字可読性、小サイズ、白黒、事業との一致、既存ブランドとの識別観点で批評。
法的な安全性や類似商標の有無は断定せず、必要な人の確認を示す。
画像を見ていない場合は見たと装わない。
```

## プロンプト4｜商標検索語の準備
```text
名称：【】読み方：【】表記ゆれ：【】商品・サービス分野：【】
文字、称呼、略称、ローマ字、類似音の検索語候補を整理。
実検索結果や登録可能性を作らず、J-PlatPat等で人が調べる事項と専門家相談のポイントを分ける。
```

## プロンプト5｜素材台帳整理
```text
素材名・出典・作成者・ツール・公式規約URL・取得日・予定用途：【】
表に整理し、空欄は未確認。ライセンスの意味や商標利用可否を推測しない。
公式条件を確認する質問と保管する証跡を列挙。
```

AIは案の整理を助けますが、類似調査や権利判断を代替しません。機密情報を不用意に入力しないこと。
