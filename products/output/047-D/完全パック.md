# 047-D｜TikTok投稿をAIで企画・制作する方法

**状態：初稿／企画カード図・企画計画表CSV付き。実際の撮影・投稿・反応は未検証**  
対象：TikTokで短い動画を出してみたいが、何を撮ればよいか迷う初心者｜所要：約4〜6時間（企画10個と1本目の制作準備まで）｜更新日：2026-11-01  
前提：022のショート動画、024のTikTok動画づくり（先に読んでも後でもよい）。追加課金、有料API、素材購入は行いません。

## 1｜到達点と完成物

この講座のゴールは、**テーマを決めて企画を10個出し、企画カードで撮影の準備をして、権利と広告表示を確かめてから1本目を投稿できるようにする**ことです。024では1本の動画の作り方を学びましたが、この講座では「続けて出すための企画づくり」に重点を置きます。

完成物は、①設計シート、②企画10個のリスト、③企画カード3枚、④撮影リスト、⑤説明文とハッシュタグ、⑥広告表示の確認記録、⑦公開前チェック記録の7点です。

付属見本は、架空のアカウント「台所すっきり研究」の企画カード図と計画表です。実際の動画や反応の数字はありません。

進め方の目安：1日目にテーマと企画10個、2日目に企画カード3枚と撮影リスト、3日目に撮影と編集、4日目に確認して投稿。最初の1本は完璧を目指さず、出して振り返ることを優先します。

**完成条件：** 企画カードの最初の2秒がはっきりしていて、自分で撮れる内容で、音楽と広告表示が確認され、人の確認の印がある。

## 2｜この講座で使う言葉

- **おすすめフィード**：TikTokが一人ひとりに合わせて動画を並べる画面。フォローしていない人にも表示されることがあります。
- **企画カード**：1本の動画の、見せる順番・文字・撮る物を書いたメモ。
- **最初の2秒**：動画が表示されてすぐの部分。ここで見続けるかが決まりやすいと言われています。
- **ビジネスアカウント**：お店や会社向けのアカウントの種類。分析機能などがありますが、使える音楽の条件が違うことがあります。
- **ブランドコンテンツ**：お金や商品をもらって作る動画。広告であることを示す必要があります。

## 3｜テーマを1つに絞る

TikTokでも、テーマが決まっているほうが、見た人が「次も見たい」と思いやすくなります。

- 自分が実際にやっていること・持っているものから選ぶ
- 見てほしい人を決める（「台所が散らかりがちな共働きの人」など）
- 1本の長さを決める（最初は15〜30秒がおすすめ）

## 4｜企画を10個出す

```text
テーマ【】で、TikTokの企画を10個出して。各企画に「最初の2秒で見せるもの」と「見た人が得られること」を1行ずつ。自分で撮れる内容にして。
```

AIが出した企画の中には、自分では撮れないもの（持っていない道具、行けない場所）が入ることがあります。**自分で撮れるものだけ**を残します。

## 5｜最初の2秒を決める

最初の2秒には、次のどれかを見せます。

- **結果を先に**：片づけ後のすっきりした引き出し
- **疑問を見せる**：「この隙間、どう使う？」
- **失敗を見せる**：物があふれて閉まらない引き出し

```text
企画カード【】の最初の2秒を3案。結果を先に見せる・疑問を見せる・失敗を見せる、の3つの型で。
```

最初の2秒で見せたことに、動画の中で必ず答えます。答えない「あおり」は、見た人をがっかりさせます。

## 6｜企画カードを作る

```text
企画【】の企画カードを作って。最初の2秒・3場面の流れ・画面の文字（12文字以内）・最後のひと言・撮影する物のリスト。
```

| 項目 | 見本 |
|---|---|
| 最初の2秒 | すっきりした引き出し（完成） |
| 場面1 | 片づけ前の引き出し |
| 場面2 | 100円の仕切りケースを入れる手元 |
| 場面3 | 立てて入れて完成 |
| 画面の文字 | 「仕切り3つで変わる」 |
| 最後のひと言 | 「ほかの引き出しもやってみます」 |

## 7｜画面の文字と字幕

TikTokは音を消して見る人もいるので、画面の文字が大切です。

```text
動画の画面の文字【】を、スマホの画面で読める長さに直して。1画面12文字以内、表示する秒数も付けて。
```

画面の右側や下側にはボタンや説明文が重なるので、大事な文字は真ん中寄りに置きます（022参照）。

## 8｜撮影と編集

- 縦型で撮る
- 明るい場所で、手元を固定して撮る
- 1場面につき2〜3回撮って、いちばん分かりやすいものを選ぶ
- 編集は021・022の方法で、不要な部分を切って、文字を入れる

TikTokのアプリの中でも編集できます。AIで動画を作る機能を使う場合は、本物と誤解されないよう、TikTokのAIラベルのルールを確認します。

## 9｜音楽の権利

TikTokの中で使える音楽でも、アカウントの種類や使い方（広告・ビジネス）によって条件が違うことがあります。

- 個人のアカウント：TikTokの中で選べる音楽を使う
- お店・会社のアカウント：商用で使える音楽（ビジネス向けの音楽ライブラリなど）を使う
- アプリの外で作った動画に、市販の曲をつけてアップロードしない

条件はTikTokの公式ヘルプで確認します。

## 10｜広告であることを示す

お店から商品をもらった、お金をもらって紹介する、などの動画は広告です。日本では、広告であることが分からない表示（ステマ）は景品表示法で規制されています（031参照）。TikTokには、ブランドコンテンツであることを示す機能があります。

```text
商品をもらって作る動画【内容】について、広告であることの示し方（動画内・説明文・TikTokの機能）を案にして。
```

## 11｜説明文とハッシュタグ

```text
動画の内容【】の説明文を2案。内容に合うハッシュタグを3〜5個。言い過ぎなし。
```

内容に関係ない人気のハッシュタグをたくさん付けるのは、見た人を誤解させるのでやめます。

## 12｜作り置きと続け方

企画10個のリストがあれば、撮影をまとめて行えます。

- 週末に3本まとめて撮る
- 平日に1本ずつ編集して出す
- 反応のよかった企画は、続きもの（パート2）にする

```text
これまでの企画【】から、続きものにできる企画を3つ。同じ型のくり返しにならないように。
```

予約投稿の機能がある場合は、それも使えます。作り置きした動画も、出す前に必ず見直します。

## 13｜コメントとアカウントを守る

コメントへの返事は人がします。動画で返事をする機能を使って、質問に答える動画を作る方法もあります。悪口や攻撃的なコメントは、削除・制限・報告の機能を使います。

- 二段階認証を設定する
- 子どもや家族が映る場合は、顔や名前、学校などが分からないようにする
- 位置情報が分かる景色に注意する

## 14｜反応を見て1つだけ変える

```text
1週間の反応【動画ごとの再生・最後まで見られた割合・保存・コメント】から、届いた企画の傾向を整理して。次に1つだけ変えることを提案して。
```

TikTokは、同じ内容でも出すたびに表示のされ方が変わることがあります。1本の数字で決めつけず、何本か続けて傾向を見ます。

## 15｜AIで企画を広げるコツ

企画を10個出したら、反応がよかった企画を「ずらして」新しい企画にします。AIに頼むと、ずらし方の案をたくさん出してもらえます。

- **場所をずらす**：引き出し→冷蔵庫→玄関
- **人をずらす**：一人暮らし→子どものいる家→親の家
- **時間をずらす**：5分でできる→週末にじっくり
- **失敗をずらす**：うまくいった話→失敗した話

```text
反応がよかった企画【】を、場所・人・時間・失敗の4つの方向にずらして、新しい企画を8個出して。自分で撮れる内容だけにして。
```

## 16｜見本で通し練習：1本目を準備するまで

付属の `047-tiktok-plan.csv` の1行目を例にします。

1. **企画**：「100円の仕切りで引き出しを片づける」。仕切りケースは実際に持っている設定です。
2. **最初の2秒**：完成した引き出しを真上から。
3. **3場面**：片づけ前→仕切りを入れる手元→立てて入れて完成。
4. **画面の文字**：「仕切り3つで変わる」（9文字）。
5. **音**：個人のアカウントなので、TikTokの中で選べる音楽を使います。
6. **広告**：商品は自分で買ったもので、広告ではありません。お店の名前を出すかどうかは自分で決めます。
7. **qa**：全編を見て、文字の誤字や位置を確認してから投稿します。

## 17｜よくある質問

**Q. 毎日投稿しないとだめですか？**  
A. 頻度より、続けられることと、見た人の役に立つ内容が大切です。作り置きを使って、無理のない頻度にします。

**Q. 踊ったり顔を出したりしないとだめですか？**  
A. 手元だけ、画面録画だけでも、役に立つ動画は作れます。自分が続けやすい見せ方を選びます。

**Q. 再生が少ないときは？**  
A. 最初の2秒と画面の文字を見直すのが近道です。一度にいくつも変えず、1つずつ試します。

## 18｜自動化と収益化（第3段階）

- **固定する作業**：企画10個→企画カード→最初の2秒の3案→画面の文字→説明文→広告表示の案→反応の整理→続きもの。Cの8プロンプトを順に使います。
- **人がやる作業**：撮影、編集の確認、音楽と広告表示の確認、返事。
- **お金につなげる場合**：お店や商品の紹介動画を作る仕事、自分の商品やサービスへの案内などが考えられます。依頼を受けた動画は、広告であることを必ず示します。TikTokの収益化の仕組みには条件があり、公式で確認します。

再生数・フォロワー数・収益を保証しない教材です。

## 19｜課題（3段階）

1. **練習**：自分のテーマで企画を10個出す（合格：自分で撮れるものだけ）
2. **実用品**：企画カード3枚と撮影リストを作り、1本撮る（合格：最初の2秒がはっきりしている）
3. **公開想定**：説明文・音楽と広告表示の確認・公開前チェックをそろえて投稿する（合格：全項目に印と確認日）

## 20｜よくある失敗と直し方

1. **自分で撮れない企画**：持っている物・できることに絞る。
2. **最初の2秒で何の動画か分からない**：結果か疑問を先に見せる。
3. **あおって答えない**：見せたことに必ず答える。
4. **画面の文字が長い**：12文字以内にする。
5. **文字がボタンに隠れる**：真ん中寄りに置く。
6. **ビジネスで使えない音楽**：条件を確認する。
7. **市販の曲をつけてアップロード**：TikTokの中の音楽を使う。
8. **もらった商品なのに広告と示さない**：示す。
9. **関係ないハッシュタグ**：内容に合うものだけ。
10. **家族の顔や学校が映る**：分からないようにする。
11. **1本の数字で決めつける**：何本か続けて見る。
12. **作り置きがなく止まる**：まとめて撮る。
13. **AIで作った映像をそのまま本物のように出す**：AIラベルのルールを確認する。
14. **一度にいくつも変える**：1つずつ試す。

## 21｜公開前チェック、公式情報、限界

- [ ] テーマと見てほしい人が決まっている
- [ ] 企画は自分で撮れる内容
- [ ] 最初の2秒がはっきりしていて、動画の中で答えている
- [ ] 画面の文字が読めて、ボタンに隠れない
- [ ] 音楽の使用条件を確認した
- [ ] 広告の場合は広告であることを示した
- [ ] ハッシュタグが内容に合っている
- [ ] 家族・位置情報など個人情報が映っていない
- [ ] コミュニティガイドラインを確認した
- [ ] 投稿前に全編を見た（qa）

確認した公式情報：[TikTok コミュニティガイドライン](https://www.tiktok.com/community-guidelines/ja)、[TikTok サポート](https://support.tiktok.com/ja)、[消費者庁「ステルスマーケティング」](https://www.caa.go.jp/policies/policy/representation/fair_labeling/stealth_marketing/)（確認日：2026-11-01）。音楽や機能の条件は変わるため、使う時点で再確認してください。

本教材は架空アカウントの企画カード図と計画表のみで、実際の撮影、投稿、反応の数字を検証していません。再生数・フォロワー数・収益を保証しない教材です。権利の判断に迷う場合は、専門家に確認してください。

## A/B/C/Dの役割と次の一歩

- **A｜無料体験**：企画カードを3枚作る。
- **B｜完成見本**：企画カード図と計画表を読む。
- **C｜再利用できる道具**：設計シートと8プロンプトで企画から続きものまで回す。
- **D｜作り方講座**：企画を出し続け、権利と広告表示を確かめて投稿する。
