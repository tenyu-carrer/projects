# 028-D｜AIで長尺動画から短尺動画を作る方法

**状態：初稿／切り抜き設計図・候補表付き。実映像・外部AI・各SNSの実投稿は未検証**  
対象：YouTubeやセミナー録画などの長い動画を、縦型ショートに作り直したい初心者｜所要：約4〜6時間｜更新日：2026-10-31  
前提：021の編集基礎、026の字幕、027の非破壊カット。追加課金、有料API、素材購入は行いません。

## 1｜到達点と完成物

この講座のゴールは、長い動画を「ただ短くする」のではなく、**1本の長尺から、単独で見ても意味が通るショートを3本作り、元動画へ戻れる形で公開準備する**ことです。

完成物は、①切り抜き設計シート、②章ごとの要約、③候補場面の表（元時刻つき）、④縦型9:16の編集版3本、⑤ショート用字幕、⑥公開前チェック記録の6点です。

付属見本は架空の30分セミナーを題材にした設計図と候補表です。実際の映像や再生数はありません。

**完成条件：** 3本それぞれについて、元動画の何分何秒から切ったか、補足した言葉、確認者が記録され、前後の文脈と意味が変わっていないことを人が確認している。

## 2｜切り抜いてよい動画かを先に確かめる

最初に確認するのは編集の腕ではなく「権利」です。自分のチャンネルの動画でも、ゲスト、インタビュー相手、セミナー参加者、BGM、画面に映った他人の作品が入っていれば、その人たちの許可や利用条件が関わります。

- 自分が撮影・出演し、BGMも自分で用意した → 基本的に自分で判断できる
- ゲストが出演している → 「ショートへの切り抜きも含めて使ってよいか」を確認する
- 他人のチャンネルの動画 → 切り抜きを公式に許可しているか、その条件（収益の分け方・クレジット表記）を必ず確認する。許可がなければ作らない

```text
元動画の情報【出演者・BGM・画面に映る資料・撮影場所】から、ショートへ切り抜く前に許可が必要な人・物の一覧を作って。
誰に・何を・どう確認するかを1行ずつ。判断できない項目は「要確認」として残して。
```

許可を取ったら、誰が・いつ・どの範囲（ショートのみ／広告にも使う、など）でOKしたかを制作ログに書いておきます。口頭のOKだけだと、あとで「そこまでは許可していない」と食い違うことがあるため、メッセージなど記録に残る形で確認するのが安全です。

## 3｜文字起こしと章分け

長い動画を何度も見直すのは大変です。先に文字起こしを用意し、026で学んだように数字・固有名詞・否定を原音で直してから、章に分けます。YouTubeの自動字幕や編集ソフトの文字起こし機能を使えますが、誤認識はそのまま残っている前提で扱います。

```text
校正済み文字起こし【】を、話題が変わるところで5〜8章に分けて。
各章に「開始時刻」「一言の題」「主張」「根拠や例」「注意・条件」を付けて表にして。
```

章分けの目的は、**「この章だけ見て意味が通るか」を判断しやすくすること**です。前の章の説明を前提にしている章（「さっきの方法で」など）は、ショートにするなら字幕の補足が必要になります。

## 4｜ショートに向く場面の見つけ方

ショートに向くのは、次のどれかがはっきりしている場面です。

- **1つの問いと答え**がそろっている（例：「AIに文章を頼むときのコツは？」→「型を先に渡す」）
- **具体的な手順**が30〜60秒で完結する
- **失敗談や気づき**に、話し手の実感がこもっている
- **意外な事実**があり、根拠も同じ場面で言っている

反対に、向かないのは「結論だけで根拠が別の章にある」「冗談や皮肉で、前後がないと本気に聞こえる」「質問者など他の人の顔や声が中心」の場面です。

```text
章の表【】から、ショートに向く場面を最大5つ選んで。
選んだ理由を「問いと答え／手順／失敗談／意外な事実」のどれかで示し、前後の章がないと誤解される危険度を高・中・低で付けて。
```

## 5｜最初の3秒を決める

縦型ショートは、最初の数秒で見続けるかが決まりやすい形式です。ただし、目を引くために**動画の中で言っていないことを冒頭に書くのは禁止**です。場面の中にある一番わかりやすい一言を、冒頭に持ってくるか、テロップで先に見せます。

```text
候補場面の文字起こし【】から、冒頭3秒に置ける一言を3案出して。
条件：場面の中で実際に言っている内容だけを使う。「絶対」「誰でも」「必ず」は使わない。疑問形・数字・意外さのどれかを入れる。
```

冒頭の一言を場面の途中から持ってくる場合は、編集で順番を入れ替えたことが意味を変えないか確認します。

## 6｜縦型9:16に作り直す

横長（16:9）の動画を縦（9:16）にすると、左右がかなり切れます。話している人の顔、スライドの文字、手元の作業が枠から外れないよう、場面ごとに寄せる位置を決めます。編集ソフトの自動リフレーム（被写体を追って枠を動かす機能）も便利ですが、スライドの文字は追ってくれないことがあるので、全編見て直します。

画面の文字が小さくなる場合は、スライドを別に大きく表示する、上下に分けて「話す人」と「スライド」を並べる、などの方法があります。各SNSの画面では、下側や右側に「いいね」ボタンや説明文が重なるので、大事な字幕はそこを避けて置きます。

```text
場面の説明【話す人の位置・スライドの有無・手元作業】から、9:16で見せる配置案を2つ。
顔・文字・手元のどれを優先するか、上下分割にするか、SNSのボタンと重ならない字幕位置を示して。
```

## 7｜切る・つなぐ（非破壊で）

027と同じく、元の長尺プロジェクトは上書きしません。ショート用に新しいシーケンス（編集の作業台）を作り、そこに候補場面をコピーして切ります。

1. 候補の開始・終了時刻の**前後に2秒ずつ余白**をつけて置く
2. 再生しながら、言い始めと言い終わりがきれいに収まる位置まで詰める
3. 途中の言い直しや長い間を詰める（027の考え方で、否定や条件は残す）
4. 冒頭の一言を置く場合は、その後に本編へ自然につながるか確認する
5. 書き出し前に、元の長尺の同じ部分と並べて見比べる

## 8｜字幕と補足

ショートは音を消して見る人も多いため、字幕を付けます。長尺の字幕をそのまま流用すると、行の長さが縦画面に合わなかったり、「これ」「さっきの」など前の章を指す言葉が残ったりします。

```text
ショート用字幕【】を1行16文字前後・2行までに区切り直して。
「これ」「さっき」「その方法」など前後がないと分からない言葉には、[補足：〜]として言い換え案を付けて。
```

補足は話者の発言を書き換えるのではなく、括弧や別の色で「補足」と分かるように入れます。

## 9｜題名・説明文・元動画への案内

ショートの題名と説明文には、内容を大げさにしない言葉を選びます。そして、元の長尺へのリンクや「続きは本編で」という案内を入れ、切り抜きだけで判断されないようにします。YouTubeでは、ショートから関連動画として長尺を案内する機能があります（機能の名前や場所は変わるため、公開時にヘルプで確認）。

```text
ショートの内容【】から、題名3案と説明文1案を作って。
題名は場面で言っていることの範囲を超えない。説明文の最後に、元の長尺動画への案内を1文入れて。
```

## 10｜見本で通し練習：候補1を作るまで

付属の `028-clip-plan.csv` の候補1（元03:10〜03:52、42秒）を例に、最初から最後までの流れを確認します。

1. **権利**：架空セミナーは講師1人だけが話し、BGMなしという設定なので、講師本人の判断で切り抜けます。
2. **場面の確認**：03:10からは「朝の5分でSNS投稿を作る」話です。ただし「この方法なら」という言葉が出てきて、その方法は前の章で一度だけ説明されています。そこで補足字幕「[補足：AIに下書きを頼む方法]」を用意します。
3. **冒頭の一言**：場面の中で講師が実際に言う「朝の5分で投稿は作れます」を疑問形にして、冒頭テロップ「朝の5分でSNS投稿は作れる？」にします。言っていない数字や約束は足しません。
4. **縦型**：講師がカメラ中央に座っている設定なので、顔を上3分の1に置き、下に字幕を置きます。スライドはないので上下分割は不要です。
5. **切る**：03:08〜03:54を余白つきで置き、言い始めの「はい、では」と最後の「次にいきます」を詰めて42秒にします。
6. **確認**：元の長尺の03:00〜04:20を続けて見て、ショートだけ見た人が「5分で何でもできる」と受け取らないか確認します。講師は「下書きまで」と言っているので、字幕でも「下書き」を省略しません。

この順番を候補2・3でも同じように繰り返すと、3本そろいます。迷ったら、候補表の「risk」欄に理由を書いて保留にし、ほかの場面を選び直してかまいません。

## 11｜自動化と収益化（第3段階）

ここまでを手作業で1回できたら、繰り返す部分を自動化できます。

- **毎回同じ作業**：文字起こし→章分け→候補選び→字幕の区切り直し。ここはプロンプトを固定して、Cの8本を順番に使えば毎回同じ質で進められます。
- **人が必ず見る作業**：意味が変わっていないか、権利、縦型の枠。ここは自動化しません。
- **仕事にする場合**：長尺動画を持っている人（講師、店舗、YouTuber）から依頼を受け、「1本の長尺からショート3本＋字幕＋題名案」のような形で引き受ける方法があります。料金は作業時間と修正回数から考え、相場を調べてから決めます。依頼主の動画でも、ゲストやBGMの権利確認は依頼主と一緒に行います。

収益や再生数は、内容・発信者・時期で大きく変わります。この講座は再生数や売上を保証しない教材です。

## 12｜課題（3段階）

1. **練習**：付属の架空目次から候補を3つ選び、候補表を埋める（合格：全候補に元時刻・誤解の危険度がある）
2. **実用品**：自分の動画（5分以上）からショート1本を作り、字幕まで付ける（合格：前後を知らない人に見せて意味が通じる）
3. **公開想定**：ショート3本と題名・説明文・元動画への案内をそろえ、公開前チェックを全部通す（合格：チェック全項目に印と確認日）

## 13｜よくある失敗と直し方

1. **他人の動画を許可なく切り抜く**：公式の許可と条件を確認できるまで作らない。
2. **結論だけ切って根拠が消える**：根拠を含む範囲まで広げるか、字幕で補う。
3. **冗談が本気に聞こえる**：前後の笑いや表情まで含めるか、候補から外す。
4. **冒頭に言っていないことを書く**：場面内の言葉だけで作り直す。
5. **縦にしたらスライドが読めない**：上下分割か、スライドを拡大して別に表示する。
6. **字幕がSNSのボタンに隠れる**：下側と右側を避けて配置し直す。
7. **「これ」「さっき」が残る**：補足字幕で言い換える。
8. **元時刻を記録していない**：候補表に元時刻を書き、元プロジェクトを残す。
9. **長尺の字幕をそのまま使って行が長い**：縦画面用に区切り直す。
10. **ゲストや質問者の顔・声を無断で使う**：本人の許可を取るか、映さない場面を選ぶ。
11. **BGMの利用範囲が分からない**：ショートで使える条件を確認し、不明なら差し替える。
12. **同じ場面を何本も出す**：1場面1本にし、別の場面を探す。

## 14｜公開前チェック、公式情報、限界

- [ ] 切り抜いてよい権利（出演者・ゲスト・BGM・資料）を確認
- [ ] 元の長尺プロジェクトを上書きしていない
- [ ] 候補表に元時刻・確認者がある
- [ ] 否定・条件・数字が抜けて意味が変わっていない
- [ ] 冒頭の一言が場面内で実際に言っている内容
- [ ] 縦型で顔・文字・手元が切れていない
- [ ] 字幕がボタンと重ならず、補足が補足と分かる
- [ ] 題名・説明文が内容を大げさにしていない
- [ ] 元動画への案内が入っている
- [ ] 書き出したファイルを最初から最後まで再生した

確認した公式情報：[YouTube ヘルプ「YouTube ショートの作成を始める」](https://support.google.com/youtube/answer/10059070)、[YouTube ヘルプ「YouTube のチャンネル収益化ポリシー」](https://support.google.com/youtube/answer/1311392)、[Instagram ヘルプセンター](https://help.instagram.com/)（確認日：2026-10-31）。機能名・長さの上限・収益化の条件は変わるため、公開時に再確認します。
