# 076-B｜インタビュー記事 見本の読み解き

**状態：架空の取材による見本。実際の取材・記事ではありません**

付属の見本は、架空の商店街「ひばり通り商店街（架空）」の広報係・岡田さん（架空）が、パン屋「麦の家（架空）」の店主・西村さん（架空）にインタビューして記事にしたときの記録です。

- `076-interview-flow.png`：依頼から公開までの流れ図（依頼→質問→取材→文字起こし→構成→確認→公開）
- `076-article-structure.png`：インタビュー記事の型（導入→人物紹介→本文の見出し3つ→締め）の図
- `076-question-sheet.csv`：質問の一覧（質問・ねらい・聞けたこと）
- `076-sample-article.md`：完成見本の記事と、本人の確認で直した所
- `076-consent-form.md`：取材の依頼と同意の確認書の見本（録音・写真・掲載先・確認の手順）

見るポイント：

1. **先に書面で同意をもらった**：録音すること、AIで文字起こしすること、写真と名前を載せる場所、公開前に本人が確認できることを、取材の前に伝えて同意をもらっています。
2. **話した言葉を勝手に変えていない**：読みやすく整えた所はありますが、意味が変わる直しはしていません。本人に原稿を見てもらい、2か所直しています。
3. **AIの文字起こしを聞き直した**：店名・人の名前・数字は、録音を聞き直して確かめています。
4. **記事に書かないことを決めた**：取材中に「これは書かないで」と言われた話は、メモに印をつけて記事から外しています。

この見本は考え方を示すためのもので、実在の人物・お店・取材ではありません。
