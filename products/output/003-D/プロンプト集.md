# 003-D 講座用プロンプト集

個人の氏名・電話・住所・顧客情報をAIへ入力しない。出力は本人が原稿・公式仕様と照合します。

### 仕事説明
```text
相手：[相手]、事実：[公開可能な仕事内容]。名刺用15〜28字を5案。誇張・成果保証・事実追加は禁止。不明は質問してください。
```

### 情報分類
```text
目的：[相手にしてほしい行動]、相手：[相手]、掲載候補：[個人情報を除く項目]。必須/補助/今回は載せないに分類し、理由を付けてください。住所・連絡先を創作しない。
```

### 表裏構成
```text
表面は氏名・屋号・仕事説明を優先。裏面は[予約/アクセス/サービス]の一つを主役にする配置案を提案。QRの横の案内文、読み順、削る情報を示す。URLや実績を創作しない。
```

### 5秒テスト
```text
カード文面：[個人情報を除く]。誰のカードか、何を依頼できるか、次の行動は何かを測る誘導のない質問を3つ作り、合格基準を提案してください。
```

### 校正
```text
名刺原稿：[必要最小限]。表記ミス候補、原本と照合する事実、目視確認するレイアウトに分類。氏名・電話・URL等を推測で直さない。不明点を質問してください。
```

### 情報削減
```text
目的：[目的]、相手：[相手]、項目：[個人情報を除く]。5項目以内に絞り、残す・裏面へ・削除へ分類し理由を説明。法的要件を断定せず連絡先を作らない。
```
