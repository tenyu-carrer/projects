# 078-B｜企業ブログ 見本の読み解き

**状態：架空の会社による見本。実際のブログ運用での効果は未検証**

付属の見本は、架空の小さな工務店「さくら工房（架空）」が、ホームページのブログを3か月運用する計画を立て、1本目の記事を書いたときの記録です。

- `078-blog-flow.png`：目的決めから公開・見直しまでの流れ図
- `078-article-template.png`：企業ブログの1記事の型（結論→理由→自社の経験→注意→次の行動）の図
- `078-content-plan.csv`：3か月の記事計画（テーマ・読む人・元になった質問・担当・公開日）
- `078-sample-post.md`：完成見本の記事1本
- `078-quality-checklist.csv`：公開前の品質チェック表（自社の経験・事実の確認・AIの使い方・宣伝の割合）

見るポイント：

1. **ブログの目的を1つに決めた**：「家づくりを考え始めた人に、相談前の不安を減らしてもらう」。売り込みの記事にしていません。
2. **テーマはお客さんの質問から**：3か月分12本のテーマは、すべて実際に聞かれた質問から作っています。
3. **自社の経験を必ず入れた**：AIの下書きに、実際の工事で起きたこと（お客さんの許可を取った範囲）と、現場の写真を足しています。
4. **月に4本ではなく2本**：続けられる本数にして、1本ずつ点検してから公開しています。

この見本は考え方を示すためのもので、実在の会社・運用ではありません。
