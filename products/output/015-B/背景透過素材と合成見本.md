# 015-B 背景透過・合成の練習素材

- [合成見本：明るい台所の背景](../015-D/assets/015-composite-practice.png)

透過PNGの外周ピクセルは透明（アルファ0）であることを確認しました。素材は教材用AI生成の架空イメージです。合成見本は生成AIで作り直したコンセプトで、透明素材のピクセルをそのまま保持した合成結果ではありません。見本で急須の形・色・細部が変化し得るため、実商品合成の完成見本には使いません。

## 透過PNGの見方

1. 透明対応アプリで開き、チェッカーボードや異なる色の背景に重ねる。
2. 透明部分が白く塗られているだけではないか、レイヤー表示やPNG情報で確認。
3. 100%表示で縁を点検。注ぎ口・取っ手の内側・ふたの隙間・布の毛羽を見る。
4. 薄色・濃色・柄背景の三種類に一時配置して、縁の色残りや欠けを探す。
5. 合成後に被写体の光向き・接地影・遠近・色温度が背景と合うか確認。

## 合成見本の観察

- 商品を置く面の遠近と光の向きを合わせる。
- 切り抜き画像に影を追加するなら、影の向き・濃さ・柔らかさを背景と照合。
- 大きさを過度に変えない。実物のサイズ感が必要な広告では比較物や寸法を正確に示す。
- 生成AIで再構成された背景合成は、元画像の細部が変わることがある。

## 合格

- [ ] 透過PNGと背景付き画像を区別
- [ ] 別背景で境界を複数色チェック
- [ ] 合成で影・接地・色温度が極端にずれていない
- [ ] 架空素材を実在商品の撮影写真と表示していない
- [ ] 未検証の出力形式・寸法を保証していない
