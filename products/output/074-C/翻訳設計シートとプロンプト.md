# 074-C｜AIで翻訳・多言語記事を作る 設計シートとプロンプト

**状態：再利用用初稿／検索エンジンの決まり・著作権の扱いは使う時点で公式ページを確認**

## 設計欄

- 訳す文章（自分で書いたものか、使ってよい条件を確かめたものか）：
- 訳す言語と、読む人（どこの国の、どんな場面の人か）：
- 目的（お店の案内・商品の説明・記事など）：
- 用語集（訳し方を決めた言葉・訳さない言葉・説明を足す言葉）：
- 値段・時間・日付・住所など、変えてはいけない情報：
- 確かめ方（訳し戻し・用語集との照合・その言語を話す人の確認）：
- その言語を話す確認者（いれば）：
- 公開する場所と、言語ごとのURLの分け方：
- 言語の切り替えリンクの置き場所：
- 翻訳であることの表示（必要なら）：
- 見直す日と、届いた問い合わせの記録：
- 確認者／確認日：

## プロンプト（この順で使います）

```text
次の日本語の文章【文章】から、訳し方がぶれやすい言葉（料理名・商品名・お店の決まった言い方・日本独特の言葉）を抜き出して、用語集の案を作って。列は「日本語・訳の候補・訳さずローマ字にするか・説明を足すか」。最終的な訳し方は私が決める。
```
```text
次の日本語の文章【文章】を、【言語】に訳して。読む人は【読む人】。用語集【用語集】のとおりに訳し、値段・時間・日付・住所・固有名詞はそのまま。訳しにくかった所を、訳のあとに一覧で書いて。
```
```text
次の【言語】の文章を、日本語に訳して。意訳せず、書かれているとおりに訳して。【訳した文章】
```
```text
次の2つの日本語（元の文章と、訳し戻した文章）を比べて、意味がちがう所、抜けている所、足されている所を表にして。【元の文章】【訳し戻した文章】
```
```text
次の【言語】の文章【訳した文章】が、用語集【用語集】のとおりに訳されているか照らし合わせて、合っていない所を表にして。訳は書き換えないで。
```
```text
次の【言語】の文章【訳した文章】を、その言語を話す人が読んで不自然に感じそうな所、日本語の直訳になっている所を指摘して。直し方の案と、その理由を日本語で書いて。
```
```text
次の日本語の文章【文章】の中で、外国の人には分かりにくい日本独特の言葉や習慣（例：お通し・のれん・整理券）を探して、短い説明を足す案を作って。説明は1文まで。
```
```text
私のホームページで、日本語と【言語】のページを公開します。言語ごとのURLの分け方の案と、言語の切り替えリンクの置き方の案を、初心者向けに説明して。検索エンジンの細かい設定は、私が公式ページで確かめる。
```

AIは**下訳・照合・指摘**に使い、訳し方の決定と公開は自分で決めます。大事な案内（値段・安全・決まりごと）は、その言語を話す人にも確かめてもらいます。
