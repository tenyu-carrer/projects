# 074-B｜翻訳・多言語記事 見本の読み解き

**状態：架空のお店による見本。実際の翻訳記事での効果は未検証**

付属の見本は、架空の和菓子店「つきみ屋（架空）」の店主・山田さん（架空）が、外国からのお客さん向けに、ホームページの「はじめての方へ」を英語にしたときの記録です。

- `074-translation-flow.png`：用語集づくりから公開・見直しまでの流れ図
- `074-check-steps.png`：翻訳の確かめ方の3段階（訳し戻し→用語集との照合→ネイティブの確認）の図
- `074-glossary.csv`：用語集（日本語・英語・訳さない言葉・説明を足す言葉）
- `074-sample-translation.md`：日本語の元の文と英語の訳、訳し戻しの比較
- `074-review-log.csv`：確かめた所と直した所の記録

見るポイント：

1. **先に用語集を作った**：「どら焼き」「あんこ」「季節限定」など、訳し方がぶれやすい言葉を先に決め、AIにも同じ用語集を渡しています。
2. **訳すだけでなく、説明を足した**：「あんこ（sweet red bean paste）」のように、外国の人が知らない言葉には短い説明を足しています。
3. **直訳しすぎない**：「お気軽にお立ち寄りください」は直訳せず、意味が伝わる自然な英語にしています。
4. **最後は人が読んだ**：英語を話す知り合い（架空）に読んでもらい、不自然な所を2か所直した設定です。

この見本は考え方を示すためのもので、実在の人物・お店ではありません。
