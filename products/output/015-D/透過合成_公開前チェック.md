# 015 背景透過・合成 公開前チェック

- [ ] 原本を別に保管
- [ ] 透過PNGを濃色・淡色・柄背景で確認
- [ ] 髪・毛羽・穴・透明部・影の境界を拡大確認
- [ ] 白縁・黒縁・欠け・色残りを点検
- [ ] 背景の遠近・光向き・色温度が合う
- [ ] 接地影の方向・濃さ・柔らかさが自然
- [ ] 被写体の形・色・質感を不当に変えていない
- [ ] 元写真・背景・素材の権利と利用許可を確認
- [ ] 外部AIへの画像送信条件を確認
- [ ] PNG等の出力先仕様を公式情報で確認
- [ ] 保存後に透過状態を再確認
- [ ] AI再構成画像を実物写真・完全一致の編集結果と表示していない

判定：合格／修正／元に戻す／権利・仕様確認まで保留
