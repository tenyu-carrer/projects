# 033-C｜ナレーション 設計シートとプロンプト

**状態：再利用用初稿／AI出力は必ず耳で確認**

## 設計欄

- 動画の内容・長さ・見る人：
- 声の種類（自分の声／音声合成ソフト）と、その声の利用規約・クレジット表記の要否・確認日：
- 話す速さの目安（1分あたり300文字前後から試す）：
- 読み間違いやすい言葉（固有名詞・数字・英字・型番）：
- 字幕用原稿と読み上げ用原稿の保存場所：
- 確認者／確認日：

```text
説明文【】を、ナレーション用の原稿に直して。かっこ書きなし、1文25文字前後、耳で一度で分かる順番に。
```
```text
原稿【】の中で、音声合成が読み間違えやすい言葉（固有名詞、数字、英字、型番、同じ漢字で読み方が違う言葉）を全部抜き出し、ひらがなの読みを付けて。
```
```text
原稿【】を1文ずつ表にして、各文に「間（秒）」「話す速さ（ふつう・ゆっくり）」「強調する言葉」を付けて。話題が変わる前には0.5秒の間を入れて。
```
```text
動画の長さ【秒】に合わせて、原稿【】の文字数を調整して。1分あたり300文字前後を目安に、削るなら補足から削って。
```
```text
読み上げ用原稿【】から、字幕用原稿を作って。読みのひらがなを元の漢字・数字に戻し、1行16文字以内に区切って。
```
```text
ナレーションを聞いた人の感想【】から、聞きにくかった箇所と直し方を整理して。
```
```text
使う音声合成ソフト【名前】の利用規約で確認すべき項目（商用利用、クレジット表記、禁止される内容、利用できる媒体）の確認リストを作って。答えは書かず、確認する場所を示して。
```
```text
30秒の原稿【】を、親しみのある話し方と、落ち着いた話し方の2種類に書き分けて。内容は変えないで。
```

音声合成の声には、それぞれ利用規約があります。規約は必ず公式ページで本人が読んで確認します。
