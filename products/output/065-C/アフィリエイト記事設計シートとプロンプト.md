# 065-C｜AIでアフィリエイト記事を作る 設計シートとプロンプト

**状態：再利用用初稿／ASP・広告主・Amazonなどの規約は使う時点で公式ページを確認**

## 設計欄

- 紹介する商品と、自分が使った期間・場面：
- 使ったことのない商品を紹介しない（はい／いいえ）：
- 使うASP・プログラムと、その規約を確認した日：
- 広告の表示の書き方と、置く場所（記事の最初）：
- 数字（明るさ・重さ・値段など）の確認先：
- 健康・お金・効果をうたう表現の確認：
- 確認者／確認日：

```text
私が実際に使った商品【】について、紹介記事のメモを作るために、私に10個質問して。使った期間・場面・よかった点・気になった点・向かない人を中心に。
```
```text
私の答え【】をもとに、紹介記事の見出しを5〜7個作って。最初に広告の表示を置き、気になった点と向かない人の見出しも入れて。
```
```text
見出し【】の本文の下書きを作って。私の答え【】にない体験は書かないで。数字・値段は【要確認】と書いて自分で決めないで。
```
```text
記事【全文】の1文ずつを「体験」「調べたこと」「意見」に分けた表にして。調べたことには確認先の欄を付けて空けておいて。
```
```text
記事【全文】の中から、言い切りすぎの表現（必ず・絶対・誰でも・最安・No.1・効く・治る・稼げる）を探して、言いかえ案を出して。
```
```text
記事【】の最初に置く広告の表示の文を3案作って。読む人がすぐに広告だと分かる、短くはっきりした言葉で。
```
```text
商品【A】と【B】の比べ方の表の欄を作って。私が両方使った場合だけ「使ってみた感想」の欄を入れ、使っていない方は「メーカーの説明」の欄だけにして。
```
```text
公開した記事【】について、半年後に見直す点を5つ挙げて。値段・型番・販売の終了・自分の使い続けた感想を中心に。
```

紹介するのは、**自分が使って、人にすすめられると思った商品だけ**。報酬の高さで選びません。
