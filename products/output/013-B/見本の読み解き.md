# 013-B 写真補正の見本を読み解く

## 収録している実物

- [練習用のマグカップ写真PNG](../013-D/assets/013-source-photo.png)

このPNGは教材用に新規生成した練習素材です。実在の商品・人物・撮影現場を表すものではありません。補正済み完成品ではなく、各自が編集を試すための元画像です。補正前後の差を記録して、自分の判断基準を作るのが目的です。

## どこを見るか

1. マグカップの白：白飛びせず、表面の粒状模様が見えるか。
2. 窓辺の明るい部分：輪郭や外の景色が消えていないか。
3. テーブルの影：黒く潰れず木目が残っているか。
4. 葉：緑が蛍光色にならず、複数の色調が見えるか。
5. 全体の色：白いカップを基準に、過剰に黄・青へ寄っていないか。

## 判断の手順

最初に編集前画像を複製し、同じ倍率の左右比較またはアプリの比較表示を使います。一度に明るさ・彩度・シャープを全部変えると、何が改善したか分からなくなります。露出を少し変えたら一度保存し、変化が必要な場合だけ次の項目を調整します。画面の自動補正が気に入らない場合は、適用を取り消して手動調整へ戻ります。

## 完了条件

- [ ] 元画像と編集画像が別ファイル
- [ ] 変更した項目を記録
- [ ] 100%表示と縮小表示の両方で確認
- [ ] 編集後データを別アプリで開いた
- [ ] 未実施の印刷・色校正を実施済みと表示していない
