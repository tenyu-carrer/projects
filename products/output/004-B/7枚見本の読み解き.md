# 004-B 完成見本の読み解き｜7枚プレゼン

この教材のサムネイル画像は、架空の企画を表現した参考モックアップです。Canvaテンプレート、実イベント、実績の証拠ではありません。以下は実データの入っていない「構成見本」です。

## 7枚の役割
1. **表紙と結論**：「親子で参加できる体験会」など、何の案内かを最初に明示。日付を載せるなら主催者確認済みのものだけ。
2. **対象者**：誰に向けた機会か、参加条件や対象外条件を明確にする。
3. **体験内容**：当日の流れを開始・体験・終了の順に図示。所要時間を載せるなら確認する。
4. **参加前の不安**：持ち物、服装、付き添い、雨天時など、質問されやすい項目に答える。
5. **根拠**：主催者プロフィール、公開許可済み写真、公式情報など。根拠のない満足度や推薦文を作らない。
6. **条件**：日時、場所、費用、定員、締切、キャンセル条件。空欄は公開前に必ず解決。
7. **次の行動**：申込方法と問い合わせ先を一つにまとめる。QRを使う場合もURLを文字で併記。

## 見本の読み方
- 見出しだけを順に読むと、結論から行動までの筋を追えるか。
- 1枚に主張を詰め込みすぎていないか。
- 図は説明を助けているか、それとも飾りか。
- 出典のない数字、未確認の開催条件、架空の声が紛れ込んでいないか。
- 配布だけでも意味が通るだけの情報があるか。投影専用なら詳細を口頭に回せるか。

## 自分の題材へ置き換える
まず各ページの役割を保ち、題材だけを置き換えます。5枚目で根拠が用意できない場合は、根拠を作らず、確認済みの説明へ変更するかページを再設計してください。6枚目の条件が未確定なら配布・公開を止めます。

## 合格条件
- [ ] 見出しだけで全体の論理が追える
- [ ] 5枚目の根拠が実在し出典を示せる
- [ ] 6枚目に未確認の条件がない
- [ ] 最終ページで行動・連絡先が明確
- [ ] モックアップを実物・実績と誤認させない
