# 038-C｜歌詞 設計シートとプロンプト

**状態：再利用用初稿／AIの案は必ず自分の言葉で直す**

## 設計欄

- 歌のテーマ／誰に向けた歌か／使う場面：
- 元になる思い出や気持ち（具体的な物・場所・時間・言葉）：
- 曲の長さと構成（Aメロ・Bメロ・サビの回数）：
- 入れたい言葉／入れたくない言葉：
- 既存の歌詞・タイトルに似ていないかの確認方法：
- 確認者／確認日：

```text
思い出【】から、歌詞に使える具体的な言葉（物・場所・時間・音・におい・せりふ）を10個抜き出して。
```
```text
テーマ【】と具体的な言葉【】から、Aメロ（4行）・Bメロ（2行）・サビ（4行）の歌詞のたたき台を作って。サビには具体的な言葉を1つ必ず入れて。
```
```text
歌詞【】の各行の文字数を数えて、同じ部分（Aメロ同士など）で文字数の差が大きい行を指摘し、そろえる案を出して。
```
```text
歌詞【】の中で、よくある言葉だけでできている行（ありがとう、大好き、ずっと一緒など）を指摘して、具体的な言葉に置き換える案を出して。
```
```text
歌詞【】を歌ったとき、聞き取りにくい・読み間違えやすい言葉を挙げて、ひらがなにする案や言い換え案を出して。
```
```text
歌詞【】の中で、有名な歌詞やタイトルに似ているかもしれない言い回しを挙げて。断定はせず、確認が必要な候補として出して。
```
```text
2番の歌詞を作って。1番【】と同じ構成で、同じ思い出の別の場面【】を使い、サビは1番と同じでよい。
```
```text
完成した歌詞【】を、贈る相手【】が読んだときに誤解しそうな表現、傷つきそうな表現がないか点検して。
```

AIの案はたたき台です。最後は自分の思い出と気持ちに合うように、自分の言葉で直します。
