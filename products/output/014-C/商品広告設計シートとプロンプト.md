# 014-C 商品写真・広告画像 設計シートとプロンプト

## 制作ブリーフ

- 商品名・商品カテゴリ：
- 販売者・承認担当：
- 誰に届けるか：
- 掲載先・画像比率・表示幅：
- 伝えたい価値（確認済みの事実）：
- 主役にする商品写真：
- 写真の権利・撮影者・使用範囲：
- 使えるロゴ・フォント・色：
- 価格・日付・数量など更新の必要な情報：
- 行動案内と正しいリンク：
- 言ってはいけないこと・未確認事項：
- 画像AI・デザインツール・プラン・確認日：

## プロンプト1｜広告構成を決める

```text
商品：【】。見る人：【】。掲載面：【】。写真の特徴：【】。
使える事実：【】。未確認情報：【】。伝えたい価値：【】。
見出し・補足・行動案内を別々に3案。誇大表現、架空の実績、効能、価格、在庫は追加しない。
```

## プロンプト2｜レイアウト指示

```text
画像比率：【】、安全余白：【】、商品写真：【ファイル名】。
商品を主役にし、見出しを【場所】、補足を【場所】、行動案内を【場所】に配置。
文字と商品が重ならない。スマホ縮小時も見出しが読める。
ロゴ・ラベル・包装の実物形状や文字を生成し直さない。
```

## プロンプト3｜写真の撮り直し計画

```text
商品カテゴリ：【】。撮影環境：【】。必要なカット：【正面/斜め/利用場面】。
背景、光、反射対策、サイズ比較用小物、撮影後の確認項目を整理。
実物より大きさ・色・質感・内容量を誤認させる演出は提案しない。
```

## プロンプト4｜広告表現の点検

```text
広告文：【】。確認できている根拠と出典：【】。
事実と印象表現を分け、根拠が必要な断定・比較・効能・最上級・期限を抽出。
法律適合を断定せず、確認先と保留すべき箇所を示す。
```

## プロンプト5｜サイズ違い展開

```text
元画像比率：【】。展開先：【】。維持する要素：【商品・見出し・事実】。
各比率で切れる箇所と再配置案を提案。自動トリミング後は商品、文字、CTAの欠けを点検。
```

## 素材・権利ログ

素材名／提供者／取得日／許諾・ライセンスURL／使用媒体／期限／確認担当／改訂版を記録。Canva素材・フォントの条件と広告掲載先の仕様は使用時に公式案内で確認する。
