# 039-D｜AIでポッドキャストを制作する方法

**状態：初稿／番組の流れ図・エピソード計画表CSV付き。実録音・編集・配信は未検証**  
対象：声だけの番組（ポッドキャスト）を始めてみたい初心者｜所要：約5〜8時間（1回目の配信準備まで）｜更新日：2026-10-31  
前提：033のナレーション、040の音声編集（先に読んでも後でもよい）。追加課金、有料API、素材購入は行いません。

## 1｜到達点と完成物

この講座のゴールは、**番組の企画と毎回の型を決め、1回目（15分）を録音・編集して、配信の準備を整える**ことです。

完成物は、①番組の設計シート、②エピソード計画表（4回分）、③1回目の進行表、④録音・編集した音声ファイル、⑤説明文とチャプター（話題ごとの時刻）、⑥ゲストがいる場合の同意の記録、⑦公開前チェック記録の7点です。

付属見本は、架空の番組「スマホのいろは」の流れ図とエピソード計画表です。実際の録音や再生数はありません。

進め方の目安：1日目に企画と4回分の題名、2日目に1回目の進行表と事実確認、3日目に録音と編集、4日目に説明文と配信前の確認。1日で全部やろうとせず、区切って進めるほうが続けやすくなります。

**完成条件：** 毎回の型が決まり、1回目の音声が聞き取りやすく、話した事実が確認済みで、BGMの利用条件と出演者の同意が記録されている。

## 2｜この講座で使う言葉

- **ポッドキャスト**：インターネットで配信する、声の番組。好きな時間に聞ける。
- **エピソード**：番組の1回分。
- **ジングル**：番組の始まりや区切りに流す、短い音楽や効果音。
- **チャプター**：エピソードの中の話題ごとの区切りと時刻。
- **配信サービス**：番組を登録して、聞く人に届けるサービス。登録方法や規約はサービスごとに違います。

## 3｜番組の企画を決める

続けられる番組にするために、最初に次のことを決めます。

- **テーマ**：自分が10回以上話せること
- **聞いてほしい人**：「50代でスマホに苦手意識がある人」など具体的に
- **長さ**：最初は10〜15分がおすすめ。長いほど準備と編集が大変
- **頻度**：週1回、隔週など。無理のない頻度にする

```text
テーマ【】、聞いてほしい人【】で、ポッドキャスト番組の企画を作って。番組名3案、1回の長さ、配信の頻度、毎回の型、最初の4回分の題名を出して。番組名は実在の番組と同じにならないように注意して。
```

番組名は、検索して同じ名前の番組がないか自分で確かめます。

## 4｜毎回の型を作る

毎回同じ型にすると、準備も編集も楽になり、聞く人も安心して聞けます。

| 部分 | 時間 | 内容 |
|---|---|---|
| オープニング | 1分 | ジングル、あいさつ、今日の話題を一言 |
| 話題 | 10分 | 3つに分けて話す |
| 質問 | 2分 | 聞いている人への問いかけ、お便りの紹介 |
| エンディング | 2分 | まとめ、次回の予告、ジングル |

## 5｜進行表を作る（台本は書きすぎない）

ポッドキャストでは、一字一句の台本を読むと不自然になりやすいので、話す順番とポイントだけの進行表にします。

```text
今回の話題【】で、15分回の進行表を作って。各部分に時間と、話すポイントを箇条書きで3つまで書いて。文章の台本にはしないで。
```

話の中に事実や数字が入る場合は、録音の前に確認します。

```text
進行表【】の中で、事実・数字・制度・料金など、確認が必要な箇所を抜き出して、確認先の候補を付けて。
```

## 6｜録音の準備

特別な機材がなくても、スマホで始められます。

- **静かな部屋で**：カーテンや布団のある部屋は声が響きにくい
- **スマホは口から20〜30cm**：近すぎると息の音が入る
- **通知を切る**：録音中の着信音や通知音を防ぐ
- **試しに30秒録る**：聞き返して、声の大きさと雑音を確認してから本番

2人で話す場合やオンラインでゲストと話す場合は、それぞれの声がはっきり録れているか、最初に確認します。

## 7｜録音する

進行表を見ながら、自分の言葉で話します。言い間違えても、止めずにもう一度言い直せば、あとで編集で切れます。言い直す前に2秒ほど間を空けると、編集で切る場所が分かりやすくなります。

## 8｜編集する

編集の基本は3つです。

1. **不要な部分を切る**：言い間違い、長い沈黙、話がそれた部分（027の考え方で、意味が変わらないか確認）
2. **音を整える**：雑音を減らし、音量をそろえる（040で詳しく学びます）
3. **ジングルとBGMを入れる**：オープニングとエンディングに。話している間のBGMは小さく、またはなしに

```text
録音の文字起こし【】から、言い間違い・長い沈黙・話がそれた箇所を時刻つきで一覧にして。削るかどうかは人が判断するので、候補として出して。
```

AIの文字起こしで削る候補を探すと、聞き返す時間を減らせます。ただし、削るかどうかは必ず音を聞いて決めます。

## 9｜説明文とチャプター

エピソードには、内容が分かる説明文を付けます。話題ごとの時刻（チャプター）を書いておくと、聞く人が聞きたい部分から聞けます。

```text
録音の文字起こし【】から、エピソードの説明文（200文字程度）と、話題ごとの時刻を作って。話していない内容は書かないで。
```

## 10｜BGM・ジングルの権利

番組のジングルやBGMは、使ってよい条件の音源だけを使います。037で作ったBGMを使う場合も、作ったときのプランの条件を確認します。市販の曲を番組で流すことは、権利の手続きが必要になることが多いため、この講座では扱いません。

## 11｜ゲストを呼ぶ場合

ゲストに出てもらう場合は、録音の前に次のことを伝えて、同意を記録します。

- 番組名と、どこで配信するか
- 話してほしいこと
- 名前の出し方（本名・ニックネーム・匿名）
- 編集の範囲（言い間違いを切るなど）と、配信前に聞いてもらえるか

```text
ゲスト出演の依頼文を作って。番組名【】、話してほしいこと【】、録音の方法と時間、配信する場所、名前の出し方、編集の範囲、配信前の確認の有無を入れて。
```

ゲストの話の中に、ほかの人の個人的な話が出てきた場合は、名前を出さない、または編集で切るなどの配慮をします。

## 12｜配信する

配信サービスに番組を登録し、エピソードをアップロードします。登録の方法、番組のカバー画像のサイズ、使ってはいけない内容などは、サービスごとに決まっています。登録の前に、配信サービスの公式ヘルプを読みます。カバー画像は、001などで学んだ方法で、自分で作った画像を使います。

## 13｜続けるための仕組み

ポッドキャストは、続けることがいちばん難しい部分です。次の仕組みを作っておくと、忙しい週も止まりにくくなります。

- **作り置き**：時間のある週に2回分録っておく。
- **ネタ帳**：日々の気づきや聞いた人からの質問を、スマホのメモに1行ずつためておく。
- **記録表**：配信日・題名・長さ・確認したことを1行ずつ書く。付属のエピソード計画表をそのまま使えます。
- **休む回を決める**：無理をせず、「月末は休み」などを最初に決めて番組の中で伝える。

```text
ネタ帳【1行ずつのメモ】から、次の4回分のエピソード案を作って。同じ話題のくり返しを避け、各回の話題3つと確認が必要な事実を付けて。
```

## 14｜聞いた人の声を受け取る

番組の最後で問いかけをすると、聞いた人から感想や質問が届くことがあります。届いた声を番組で紹介する場合は、送った人に紹介してよいか確認し、名前の出し方（ラジオネームなど）を決めます。個人が特定される情報は読み上げません。

```text
届いた感想や質問【】を、番組で紹介できるもの・個人情報があるので紹介しないもの・次回の話題にできるものに分けて。紹介する場合の読み上げ文の案も作って。
```

## 15｜見本で通し練習：1回目を準備するまで

付属の `039-episode-plan.csv` の1回目を例にします。

1. **題名**：「スマホの文字を大きくする3つの方法」
2. **進行表**：話題を「設定から大きくする」「拡大鏡を使う」「音声で読み上げる」の3つに分けます。
3. **確認**：設定の場所の名前は、機種やOSの版で違うため、自分のスマホで確認した手順だけ話し、「機種によって違います」と一言添えます。
4. **録音**：静かな部屋で、通知を切って、15分を目安に話します。
5. **編集**：文字起こしで言い間違いの候補を探し、聞いて確かめてから切ります。
6. **説明文とチャプター**：3つの話題の時刻を書きます。

## 16｜よくある質問

**Q. 顔を出さなくても続けられますか？**  
A. ポッドキャストは声だけの番組なので、顔を出さずに始められます。ただし、声や話の内容から本人が分かることもあるため、住んでいる場所や家族の話など、出したくない情報は話す前に決めておきます。

**Q. 機材を買ったほうがいいですか？**  
A. 最初はスマホで十分です。何回か配信して続けられそうだと分かってから、必要に応じて考えます。この講座では買い物はしません。

**Q. AIの声で番組を作ってもいいですか？**  
A. 033の音声合成を使う方法もあります。その場合は、声の規約とクレジット表記を確認し、AIの声であることを番組の中で伝えます。

## 17｜自動化と収益化（第3段階）

- **固定する作業**：企画→4回分の題名→進行表→確認箇所の抜き出し→編集候補→説明文とチャプター→SNSの紹介文。Cの8プロンプトを順に使えば、毎回の準備が短くなります。
- **人がやる作業**：話すこと、事実の確認、削るかの判断、ゲストへの配慮。
- **仕事にする場合**：お店や会社の番組づくりの手伝い（企画・編集・説明文づくり）を引き受ける方法があります。配信の名義と責任は依頼主にし、音源の利用条件の記録を納品物に含めます。

再生数や収益を保証しない教材です。

## 18｜課題（3段階）

1. **練習**：番組の企画と4回分の題名を作る（合格：テーマ・聞いてほしい人・長さ・頻度・型がある）
2. **実用品**：1回目を録音・編集する（合格：雑音が少なく、言い間違いが整理されている）
3. **公開想定**：説明文・チャプター・公開前チェックをそろえる（合格：全項目に印と確認日）

## 19｜よくある失敗と直し方

1. **テーマが広すぎて話がまとまらない**：聞いてほしい人を具体的にする。
2. **長すぎて続かない**：10〜15分から始める。
3. **台本を読んで棒読みになる**：進行表のポイントだけ見て話す。
4. **通知音が入る**：録音前に通知を切る。
5. **声が小さい・大きすぎる**：試しに30秒録って確認する。
6. **言い間違いで止まる**：2秒空けて言い直し、あとで切る。
7. **事実が間違っている**：話す前に確認箇所を確かめる。
8. **BGMで声が聞こえない**：話している間は小さく、またはなし。
9. **市販の曲を流す**：使ってよい条件の音源だけ使う。
10. **ゲストの同意がない**：録音前に同意を記録する。
11. **説明文に話していない内容を書く**：文字起こしから作る。
12. **番組名が既存の番組と同じ**：検索して確かめる。
