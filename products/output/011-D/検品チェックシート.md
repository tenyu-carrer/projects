# 011｜塗り絵 100点検品シート

## 採点

- [ ] 主役が3秒で分かる（10点）
- [ ] 対象年齢と細かさが合う（10点）
- [ ] 背景が純白、線が黒（10点）
- [ ] 灰色・影・黒つぶれがない（10点）
- [ ] 線の太さがおおむね揃う（10点）
- [ ] 主な輪郭が閉じている（10点）
- [ ] 小さすぎる塗り面が多くない（10点）
- [ ] 四辺に安全余白がある（10点）
- [ ] 文字・ロゴ・既存作品・権利不明素材がない（10点）
- [ ] 保存ファイルを開き、試し刷りした（10点）

合計：　／100点　判定：合格／再修正

## 点数にかかわらず不合格

- [ ] 他者の権利を侵害するおそれがある。
- [ ] 重要な線や主役がページ端で切れている。
- [ ] ファイルが開けない、印刷できない。
- [ ] 子ども向けとして不適切・危険な表現がある。
