# 011｜塗り絵プロンプト集

## 1. 初心者向け

```text
A4縦の初心者向けオリジナル塗り絵。主役は【 】、背景は【2要素】。
純白背景、黒の均一な中太線、閉じた大きな形、十分な余白。
灰色、影、塗り、文字、ロゴ、透かし、細かすぎる模様は使わない。
```

## 2. 大人向け中程度

```text
A4縦の大人向けオリジナル塗り絵。場面は【 】。
大きい塗り面70％、小さな模様30％。線の太さをそろえ、全領域を閉じる。
白背景と黒線だけ。影、ハッチング、グレー、黒い面、文字、ロゴなし。
```

## 3. 子ども向け

```text
【年齢】向けの楽しく安心できる塗り絵。主役は【 】。
丸みのある単純な形、太い輪郭、重なりを少なく、1ページに主役1つ。
怖い表情、尖った危険物、小さな部品、文字、ロゴ、灰色、影を入れない。
```

## 4. シリーズ統一

```text
前のページと同じ線の太さ、難易度、余白、構図密度を保つ。
変えるのは場面だけ：【新しい場面】。
主役の固定要素：【形・服・持ち物など3項目】。
新しい装飾や文字を追加しない。
```

## 5. 修正専用

```text
主役と構図は変えず、【直したい点】だけを修正する。
変更しないもの：【 】。
完成条件：白背景、黒線のみ、閉じた形、均一な線、安全余白。
新しい物、文字、ロゴ、影、灰色を追加しない。
```

## 出力評価

生成後は「白黒／線／閉じた形／余白／権利」の5項目を確認する。AIの自己評価だけで合格にせず、人が画像を開き、必要なら試し刷りする。
