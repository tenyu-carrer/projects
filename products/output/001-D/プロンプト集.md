# 001｜SNS投稿画像プロンプト集

## 1. 見出し5案

```text
SNS投稿画像1枚の文章案を5つ作ってください。
対象：【 】 テーマ：【 】 目的：【 】 元情報：【 】
主見出し18文字以内、補足25文字以内。
元情報にない数字や効果を作らず、各案に強調する1語を付けてください。
```

## 2. 初心者向けに直す

```text
次の文章を、専門知識がない【対象】にも分かる言葉へ直してください。
内容と事実は変えず、専門語には短い説明を付けます。
主見出し1つ、補足1つ、投稿文3行を出してください。
```

## 3. 短くする

```text
次の主見出しを18文字以内で5案に短くしてください。
削ってはいけない情報：【 】
大げさな表現、意味の変化、元にない数字は禁止です。
各案について、何を残し何を削ったか説明してください。
```

## 4. 誇張を検査する

```text
次のSNS画像文を検査してください。
元情報：【 】
文章：【 】
元情報にない効果、数字、実績、断定を一覧にし、安全な修正案を出してください。
問題がない箇所は変えないでください。
```

## 5. 3枚シリーズへ展開する

```text
同じ対象者・同じ目的で、テーマだけ違うSNS投稿表紙を3案作ってください。
固定するもの：文章3段、主見出し18文字以内、同じ口調。
変えるもの：【3つのテーマ】
3枚を並べたとき重複しないようにしてください。
```

## 6. 修正専用

```text
元の内容を増やさず、次の問題だけを修正してください。
問題：【読みにくい／対象が不明／長い／大げさ】
変更しないもの：【固有名詞・数字・重要語】
修正前、修正後、直した理由を表で出してください。
```

## 使った後の確認

AIの案をそのまま掲載しない。元情報、固有名詞、数字、対象者、行動の5点を人が照合する。
