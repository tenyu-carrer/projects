# 007-B 作例プロンプトの分解

## 作例（架空場面）
「雨上がりの小さな本屋の前で、黒猫が赤い傘を閉じている。温かみのある児童書風の手描きイラスト。濃紺と橙、路面に柔らかな反射光。猫の全身が見える正方形構図。文字・ロゴ・余分な人物なし。」

## 部品を見る
| 指示 | 役割 | 抜いた場合に起こること |
|---|---|---|
| 黒猫 | 主役 | 焦点が曖昧になる |
| 傘を閉じる | 動作 | 場面が静止しやすい |
| 雨上がりの本屋 | 場所・状況 | 背景が広がりすぎる |
| 児童書風の手描き | 一般的な画風 | 表現の幅が広がる |
| 濃紺と橙、反射光 | 色と光 | 雰囲気が変化する |
| 全身・正方形 | 構図と比率 | 切り取りが意図と違う可能性 |
| 文字・ロゴなし | 避ける物 | 疑似文字等が混ざる可能性 |

これは既存の作品・作家を指すものではなく、実在の本屋や猫の写真でもありません。生成後の品質を保証する見本ではなく、指示を分けて考える教材例です。

## 改善練習
主役の位置だけを「画面左寄り」に変更し、ほかの指示は固定します。次に色だけを変更し、違いを記録します。一度に複数条件を変えると、どの指示が効いたか分かりにくくなります。
