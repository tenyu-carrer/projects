# 068-D｜有料教材 公開前チェック

- [ ] 教材のゴールが「〜できる」の1文
- [ ] すべての単元に目標が1つずつ
- [ ] すべての単元に演習と合格の目安
- [ ] 自分の経験や工夫が入っている
- [ ] 事実に確認先と確認日
- [ ] 見本は架空と明記、または本人の許可あり
- [ ] 文章・画像・テンプレートの権利を確認
- [ ] 品質の評価表で「足りない」なし
- [ ] 販売ページに教材にないこと・根拠のない言い切りなし
- [ ] 事業者の表示・価格・支払い・提供の時期・返品の条件を記載
- [ ] 感想は本人の許可と依頼の有無を確認
- [ ] 販売の場所の規約・手数料を確認日つきで確認
- [ ] 販売後の見直しの日と見る数字を決めた

評価表に「足りない」が残っている、販売ページに根拠のない言い切りがある、事業者の表示や返品の条件がない場合は販売に進まない。売上・受講者の数を保証しない。
