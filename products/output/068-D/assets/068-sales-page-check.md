# 販売ページの表示チェック（見本・架空）

**状態：架空の教材『片づけが続く7日間ワークブック』の販売ページの下書きの点検記録。実在の販売ページではありません**

## AIの案から消した言葉

| AIの案 | 判断 | 理由 |
|---|---|---|
| 部屋が見違える | 消した | 家の広さや家族の協力で変わる結果で、教材の中で約束できない |
| リバウンドしない | 消した | 根拠を示せない効果の約束（優良誤認に当たるおそれ） |
| 受講者満足度98% | 消した | 調べていない数字。根拠のない数字は書かない |
| 今だけ半額 | 消した | 実際に値下げの予定がない。事実でない「今だけ」は書かない |
| 片づけのプロ〇〇さんも推薦 | 消した | 推薦をもらっていない。実在の人の名前を使わない |

## 販売ページに書く項目（自分で書く必要があるかは販売の場所で確かめる）

| 項目 | 書いた内容（架空） | 確かめ先 |
|---|---|---|
| 販売価格 | 1,980円（税込）（架空） | 自分で決めた |
| 支払いの時期と方法 | 販売の場所の決済画面で確認して書く | 販売の場所の公式ヘルプ |
| 提供の時期 | 支払いのあとすぐにダウンロード | 販売の場所の仕組み |
| 返品（キャンセル）の条件 | 販売の場所の決まりを確かめて書く | 消費者庁「特定商取引法ガイド」・販売の場所の公式ヘルプ |
| 事業者の氏名・住所・電話番号 | 書き方を確かめて書く | 消費者庁「特定商取引法ガイド」 |
| 価格のほかにかかるお金 | なし（通信料は受講者の負担） | 自分で確かめた |
| 動作環境 | PDFを開けるアプリ | 教材の形式 |
| 共有の範囲 | 購入した本人だけが使える | 自分で決めた |

確認日：2026-11-19（架空の設定）。法律と販売の場所の決まりは、販売する時点で公式ページをもう一度読む。
