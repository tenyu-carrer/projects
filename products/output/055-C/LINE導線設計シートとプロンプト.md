# 055-C｜SNS→LINE導線 設計シートとプロンプト

**状態：再利用用初稿／LINEの規約・料金・個人情報の扱いは必ず自分で確認**

## 設計欄

- LINEで友だちになってもらう目的（お知らせ・予約・相談など）：
- 友だち追加の特典（今すでに用意できるもの）：
- SNSのどこにLINEへの入口を置くか（プロフィール・投稿の最後など）：
- あいさつメッセージで伝えること：
- 配信の頻度（週に何回まで）と、送る時間帯：
- 売り込みの回数の上限：
- 名前・メールなどを聞く場合の利用目的の書き方：
- 配信の道具（LINE公式アカウントの機能／外部の配信ツール）：
- 月に送れる数の上限とプラン（公式ページで確認）：

```text
活動【】と見てほしい人【】から、友だち追加の特典の案を5つ出して。今の私が用意できるものだけ。効果や結果を約束する言い方は使わないで。
```
```text
特典【】を受け取れるLINEへの誘い文を、Instagramの投稿の最後に入れる用に3案作って。押しつけず、特典の中身が正確に伝わるように。
```
```text
LINE公式アカウントのあいさつメッセージを作って。①お礼 ②特典の受け取り方 ③これから届く内容と頻度 ④通知の切り方・ブロックできること、の順で、200字くらいで。
```
```text
友だち追加から7日間の配信表を作って。列は「日目・目的・内容・リンク先」。役立つ話を中心にし、案内（売り込み）は1回だけにして。
```
```text
配信の文章【】を点検して。LINE公式アカウントのガイドラインで気をつけたい点（大げさな約束、「◯◯するだけ」「儲かる」などの言い方、内容と関係のないリンク）と、広告の主体が分かるかを指摘して。
```
```text
LINEで名前やメールアドレスを聞くフォームを作る前に、利用目的の書き方の案を作って。何に使うか・いつまで持つか・問い合わせ先を入れて。
```
```text
LINEの数字【友だち数の変化・ブロック数・メッセージを開いた数（自分で写したもの）】から、配信の頻度や内容で1つだけ変えることを提案して。数字が少ない場合はそう書いて。
```
```text
LINEで届いた質問【個人名を伏せた内容】に返す文章の下書きを作って。答えられないこと（体調・お金の判断など）は、専門の窓口をすすめる形にして。
```

LINEのプランや機能は変わることがあります。使う時点で、LINE公式アカウントの公式ページで確かめてください。
