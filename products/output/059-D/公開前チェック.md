# 059-D｜SNS多言語投稿 公開前チェック

- [ ] 届けたい人と言語を決めた
- [ ] 日本語を翻訳しやすく整えた
- [ ] 全部の投稿で訳し戻し
- [ ] 時間・数字・値段・条件・否定のずれなし
- [ ] 文化・習慣の違いを点検
- [ ] 屋号・商品名の書き方を統一
- [ ] ハッシュタグを検索で確認
- [ ] 画像の中の大事な情報を本文にも
- [ ] その言語が分かる人の確認
- [ ] 他人の文章・写真を無断で使わない
- [ ] コメントへの返し方を決めた

確認者のいない訳文、意味のずれ、権利の未確認があれば投稿を止めて直す。海外からの集客を保証しない。
