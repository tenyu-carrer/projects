# 005-B 完成見本の読み解き｜電子書籍表紙

## 架空の構成例
- 書名：はじめてのAI仕事術
- 副題：毎日の文章と整理を見直す入門
- 著者：山田 花子（架空）
- 想定読者：業務でAIを初めて試す人
- ビジュアル：ノートと光の抽象イラスト

「30分短くする」は効果の実証がないため採用しません。販売実績・レビュー・受賞・出版社との関係を示す見本でもありません。

## 5つの観察ポイント
1. 縮小時に最初に読めるのは書名か。
2. 副題が対象・内容を補い、書名の繰返しになっていないか。
3. 画像が本のテーマに関係し、文字を邪魔していないか。
4. 背景と文字の明るさに差があり、色覚に依存しない読み順か。
5. 内容と一致しない成果、肩書き、実績を約束していないか。

## 自分の本に置き換える
本の目次と本文の要約を先に用意し、表紙に載せる約束を照合します。書名の類似、商標、人物名は公開前に確認します。画像を使うなら素材名、出典、ライセンス、確認日を記録。販売先の公式仕様に合うキャンバスを作り、縮小表示と書き出しファイルの両方を検査します。

## 合格
- [ ] 見本が架空であると明示した
- [ ] 自分の本の内容と書名が一致
- [ ] サムネイルでも書名が判読可能
- [ ] 素材と入稿条件が確認済み
