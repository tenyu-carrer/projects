# 034-C｜多言語翻訳・吹き替え 設計シートとプロンプト

**状態：再利用用初稿／AI翻訳は必ず逆翻訳と人の確認で検品**

## 設計欄

- 元の動画の言語・長さ・内容：
- 翻訳する言語と、その言語で見てほしい人：
- 字幕だけにするか、吹き替えもするか：
- 確認してくれる人（その言語が分かる人）の有無：
- 声の種類（音声合成・自分の声・依頼した話者）と規約：
- 公開方法（別の動画として公開／1本の動画に複数の音声を追加）：

```text
日本語字幕【】を、【英語】の動画用字幕に訳して。1行42文字以内（英語の場合）、話し言葉で。程度・条件・否定の言葉を落とさないで。
```
```text
訳した字幕【】を日本語に訳し戻して、元の字幕【】と意味がずれた行を表にして。ずれの種類（条件が消えた・強くなった・逆になった）も付けて。
```
```text
元の字幕【】の中で、【英語】圏の人に伝わりにくい言葉（行事・制度・単位・ことわざ・お金）を抜き出して、説明を足す案と言い換える案を出して。
```
```text
吹き替え用の訳【】について、元の映像の秒数【行ごとの秒数】に入りきるか確認して。長すぎる行は短い言い方を出して。
```
```text
動画の題名と説明文【日本語】を【英語】にして。直訳ではなく、その言語で検索されやすく自然な言い方で。誇張しないで。
```
```text
多言語版の確認表を作って。項目：字幕のずれ、吹き替えと口の動き、数字と単位、固有名詞、画面の中の日本語の文字、題名と説明文。
```
```text
画面の中に出てくる日本語の文字【場面ごとの文字】を一覧にして、翻訳版で差し替えが必要なものに印を付けて。
```
```text
その言語が分かる確認者に送る依頼文を作って。確認してほしい点（意味のずれ・不自然さ・失礼な表現）と、締め切りを入れて。
```

AI翻訳はたたき台です。公開前に、その言語が分かる人の確認を受けるのが理想です。
