# 047-C｜TikTok企画・制作 設計シートとプロンプト

**状態：再利用用初稿／撮影前に企画カードを確認**

## 設計欄

- アカウントのテーマ／見てほしい人：
- アカウントの種類（個人／ビジネス）と、使える音楽の条件：
- 1本の長さ（15〜60秒など）と投稿の頻度：
- 顔を出すか（手元・画面録画などの見せ方）：
- 商品をもらった・依頼された動画の広告表示の方法：
- 確認者／確認日：

```text
テーマ【】で、TikTokの企画を10個出して。各企画に「最初の2秒で見せるもの」と「見た人が得られること」を1行ずつ。自分で撮れる内容にして。
```
```text
企画【】の企画カードを作って。最初の2秒・3場面の流れ・画面の文字（12文字以内）・最後のひと言・撮影する物のリスト。
```
```text
企画カード【】の最初の2秒を3案。結果を先に見せる・疑問を見せる・失敗を見せる、の3つの型で。
```
```text
動画の画面の文字【】を、スマホの画面で読める長さに直して。1画面12文字以内、表示する秒数も付けて。
```
```text
動画の内容【】の説明文を2案。内容に合うハッシュタグを3〜5個。言い過ぎなし。
```
```text
商品をもらって作る動画【内容】について、広告であることの示し方（動画内・説明文・TikTokの機能）を案にして。
```
```text
1週間の反応【動画ごとの再生・最後まで見られた割合・保存・コメント】から、届いた企画の傾向を整理して。次に1つだけ変えることを提案して。
```
```text
これまでの企画【】から、続きものにできる企画を3つ。同じ型のくり返しにならないように。
```

企画カードは撮影の地図です。撮る前に、自分で撮れるか、権利に問題がないかを確かめます。
