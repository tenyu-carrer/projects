# 080-C｜AIでWebコンテンツ制作事業を始める 設計シートとプロンプト

**状態：再利用用初稿／法律・税・取引の決まりは使う時点で公式ページを確認**

## 設計欄

- 提供するサービス（1つ）：
- 誰向けか（業種・困りごと）：
- 納品物（数・形・文字数の目安）：
- やらないこと：
- 自分の経験とのつながり：
- 見本（実績がなければ架空と明記した見本）：
- 料金と、その理由（作業時間・確認の回数）：
- 取引条件（納品物・期限・報酬・支払日・直しの回数・権利）：
- AIを使うことの説明と、人が確かめること：
- お客さんの情報の扱い（AIに貼らない情報）：
- お客さんの見つけ方（知り合い・地域・ホームページ）：
- 税・開業の手続きで確かめること：
- 振り返る日と見る数字（受けた件数・作業時間・継続）：
- 確認者／確認日：

## プロンプト（この順で使います）

```text
私がAIを使って作れるもの【一覧】と経験【経験】から、小さなお店や会社に頼んでもらうサービスの案を5つ出して。誰向けか・何を納品するか（数と形）・自分の経験とのつながりを表にして。結果を約束する言葉は使わないで。
```
```text
次のサービス【サービス】について、お客さんが頼む前に不安に思いそうなことを10個出して。それぞれに、サービスの説明で答えられること・答えられないことを分けて。
```
```text
次のサービス【サービス】のメニュー案を作って。納品物・回数・文字数の目安・直しの回数・納品までの日数・やらないことを表にして。料金の欄は空けておいて。
```
```text
次のサービス【サービス・納品物】の料金を決めるために、1件あたりの作業の流れと、それぞれにかかる時間の目安を表にして。打ち合わせ・下書き・確認・直し・納品をすべて入れて。料金は私が決める。
```
```text
次のサービス【サービス】をお客さんから受けるときに、事前に確かめておく取引条件の一覧を作って。納品物・期限・報酬の額・支払日・直しの回数・文章の権利・AIを使うこと・お客さんの情報の扱い、を必ず入れて。表の形で、中身は空けておいて。
```
```text
次の納品物【文章】を、お客さんに渡す前に点検して。①事実（数字・日付・名前）を確かめる所、②表示のルールで気をつける表現（効果の約束・根拠のない数字）、③お客さんの言い方やお店らしさに合っていない所、を表にして。文は書き換えないで。
```
```text
次のサービス【サービス】の紹介文を、ホームページや知り合いへの案内に使う形で3案作って。誰向けか・納品物・やらないこと・AIを使うことを入れ、結果の約束・実績の数字・作り話のお客さんの声は入れないで。
```
```text
3か月仕事をしました。分かっていること【受けた件数・1件あたりの作業時間・直しの回数・続けて頼んでくれたお客さん・断った仕事】をもとに、料金・メニュー・やり方で見直す点を表にして。数が少ないときは「まだ判断できない」と書いて。
```

AIは**案出し・整理・点検**に使い、サービス・料金・取引条件・受けるかどうかは自分で決めます。
