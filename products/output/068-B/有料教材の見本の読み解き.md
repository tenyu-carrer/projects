# 068-B｜有料教材 見本の読み解き

**状態：架空の講師による教材設計の見本。実際の販売・受講者の反応は未検証**

付属の見本は、架空の整理収納の講師「青木さん（架空）」が、架空の有料教材『片づけが続く7日間ワークブック』（PDFとワークシート、販売価格1,980円の設定）を作ったときの設計記録です。

- `068-course-flow.png`：受講者を決めてから、販売後の見直しまでの流れ図
- `068-unit-anatomy.png`：1単元の型（ゴール→説明→見本→演習→合格の目安→次へ）の図
- `068-curriculum-map.csv`：カリキュラム表（単元・できるようになること・演習・合格の目安・所要時間）
- `068-sample-unit.md`：完成見本の1単元（1日目）
- `068-quality-rubric.csv`：教材の品質の評価表（項目・合格の基準・確かめ方）
- `068-sales-page-check.md`：販売ページの表示チェック（特定商取引法・景品表示法の観点）

見るポイント：

1. **単元ごとに「できるようになること」が1つ**：7日分すべてが「〜できる」の1文で始まり、1単元に目標を2つ以上入れていません。
2. **単元ごとに演習がある**：最後にまとめて課題を出すのではなく、毎日5〜10分の演習と合格の目安を置いています。
3. **見本は1単元を完成品まで作る**：設計表だけでなく、受講者が実際に読む形の1日目を作り、そこから残りの単元を同じ型で作っています。
4. **販売ページは書けることだけ**：AIの案にあった「部屋が見違える」「リバウンドしない」を消し、事業者の表示や返品の条件を書く欄を先に作っています（下書きに記録）。

この見本は考え方を示すためのもので、実在の人物・教材・販売実績ではありません。
