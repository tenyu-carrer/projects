# 014-A 無料10分体験｜商品写真から広告の骨組みを作る

練習素材は架空のバタークッキー袋です。商品名・価格・産地・味の説明は空欄のままにし、実在商品と誤認されない広告の構成を考えます。

1. 誰に見せるかを一人に絞る（例：手土産を探す人）。
2. 写真で一番見せたいものを一つ選ぶ（商品／食感／利用場面）。
3. 写真の余白を見て、文字を置く場所を決める。
4. 見出しを短く仮置きし、商品説明・価格・行動案内を別々にする。
5. スマホ幅に縮小し、商品と見出しが読めるか確認。
6. 事実でない受賞・原材料・健康効果・在庫表示がないか点検。

## 合格

- [ ] 誰向けかが一言で言える
- [ ] 商品が文字より先に目に入る
- [ ] 写真の余白と文字配置が競合しない
- [ ] 実在商品の広告と混同されない表記を入れた
- [ ] 未確認の効能・品質・価格を加えていない
