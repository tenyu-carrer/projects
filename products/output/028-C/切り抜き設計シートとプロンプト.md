# 028-C｜切り抜き設計シートとプロンプト

**状態：再利用用初稿／AI出力は必ず元動画で確認**

## 設計欄（1本の長尺ごとに書く）

- 元動画の題名・公開場所・長さ・権利者：
- ショートを見る人／見たあとにしてほしいこと：
- 切り抜いてよい範囲（出演者・ゲスト・視聴者の写り込みの許可）：
- 1本の長さの目安（例：15〜45秒）／縦横比（9:16）：
- 必ず残す言葉（否定・条件・注意・数字）：
- 元動画へのリンクの入れ方（概要欄・固定コメント・関連動画）：
- 確認者／確認日：

```text
文字起こし【】を章ごとに要約し、各章に「主張」「根拠」「例」「注意」を1行ずつ付けて。時刻は元の文字起こしのまま残して。
```
```text
章の要約【】から、前後を知らない人が見ても意味が通る場面を最大5つ選んで。開始・終了時刻、60秒以内か、補足が必要な言葉を表にして。
```
```text
候補場面【文字起こし】の最初の3秒に置く一言を3案。誇張や「絶対」「必ず」を使わず、場面の中で実際に言っている内容だけで作って。
```
```text
候補場面【】を切り抜いたとき、否定・条件・例外・皮肉・冗談が抜けて意味が逆になる箇所がないか点検して。危ない箇所は時刻と理由を出して。
```
```text
縦型9:16にしたとき、話している人・画面の文字・手元が枠から切れる場面【時刻と説明】を洗い出し、寄せる位置の案を出して。
```
```text
ショート用の字幕【】を、1行16文字前後・2行までに区切り直して。固有名詞と数字は元の文字起こしと照合する欄を付けて。
```
```text
ショート3本【題名と内容】について、長尺へ戻ってもらう一言を各1案。押し売りにならない言い方で。
```
```text
公開済みショート【題名・元時刻】と長尺の該当部分を並べて、要約が言い過ぎていないか、元の文脈とずれていないかを点検する表を作って。
```

AIが選んだ候補はたたき台です。最後は人が元動画を前後30秒ずつ含めて見て決めます。
