# 032-C｜広告動画 設計シートとプロンプト

**状態：再利用用初稿／AI出力は必ず事実と広告ポリシーで確認**

## 設計欄

- 商品・サービス名／料金（税込）／申込先：
- 広告を見てほしい人（年齢層・地域・関心）と、その人の困りごと：
- 配信先（YouTube・Instagram・Facebook・TikTokなど）と縦横比・長さ：
- 言える事実と根拠／言えない表現：
- 配信先の広告ポリシーで注意する点と確認日：
- 予算の上限と期間（オーナーの承認が必要）：
- 比べる指標（再生の続き具合・クリック・申込）：

```text
商品【】の広告動画の冒頭3秒を、困りごと・できるようになること・意外な事実の3パターンで作って。誇張表現は使わない。
```
```text
冒頭3案【】に共通でつなぐ後半（4〜15秒）の構成を作って。サービスの内容、料金（税込）、申込方法、注意点を入れて。
```
```text
広告の言葉【】を点検して。最上級、効果の保証、個人の特徴（年齢・体型・悩み）を決めつける言い方、根拠のない比較に印を付けて言い換え案を出して。
```
```text
広告動画の構成【】を、縦型9:16・正方形1:1・横型16:9の3つに作り替えたときの配置案を出して。文字が切れない位置も示して。
```
```text
3案のテスト計画【】を作って。変えるのは1か所だけ。期間、予算の上限、比べる指標、止める条件を表にして。
```
```text
広告の結果【案ごとの数字】を読み、どの案が良かったかと、その理由として考えられることを整理して。数字が少なすぎて判断できない場合はそう書いて。
```
```text
広告のリンク先ページ【内容】と広告動画【内容】を比べて、言っていることが食い違っている点がないか確認して。
```
```text
広告動画【内容】の字幕を、音を消しても内容が分かるように作って。1行16文字以内、料金と申込方法は必ず入れて。
```

広告はお金がかかります。配信の設定・予算・期間は、必ずお金を出す人（オーナー・依頼主）の承認を取ってから行います。
