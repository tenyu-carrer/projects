# 008-D プロンプト集｜AI漫画

各文は候補作りの補助です。既存漫画や作家の具体的な表現を模倣せず、生成・公開前に人が内容と利用条件を確認します。

## 1. 4コマ脚本
```text
読者：【】テーマ：【】主人公：【】伝えること一つ：【】
日常→問題→行動→小さな変化の4コマ。
各コマに絵の指示・短いセリフ・表情・視線・次へのつながり。
入力にない実績や数字を作らず、説教・大げさな成功談を避ける。
既存作品、キャラクター、作家の固有表現を模倣しない。
```

## 2. キャラクター固定文
```text
架空の主人公。役割：【】性格：【】髪・顔：【】服：【】色：【】持ち物：【】
毎コマ保持する特徴：【】各コマで変えてよい特徴：【表情・動作・背景】
特定の作品や実在人物に似せない。デザインは独自の組合せにする。
```

## 3. コマ画像
```text
共通設定：【キャラクター固定文】画風・色：【】
コマ番号：【】このコマの動作：【】背景：【】表情：【】視線：【】
固定設定を維持。変更は動作・表情・背景のみ。文字・吹き出し・ロゴなし。
```

## 4. セリフ短縮
```text
話者の気持ち：【】セリフ：【】読者：【】
意味と条件を変えず、短い候補を3つ。絵で分かる説明は削る案を提示。
誇張や入力にない事実を追加しない。
```

## 5. つながりの点検
```text
コマごとの絵・セリフ：【】読み方向：【】
日常から問題、行動、変化へ因果がつながるか、視線とキャラクター設定を点検。
番号／問題／読者への影響／修正案で回答。法律判断は行わない。
```

## 6. 公開前リスク確認
```text
制作履歴：【】参照素材：【】使用サービスと規約URL：【】公開先：【】
人が確認すべき著作物・人物・個人情報・誤認表示・AI表示の項目を列挙。
侵害の有無や適法性を断定せず、不明な点は公開保留・専門家相談とする。
```

## 7. 編集メモ
```text
4コマ台本：【】対象読者：【】スマホ表示幅：【】
読み順、吹き出し配置、セリフの重複、余白、最小文字サイズの点検表を作成。
実際の画像を見ていない場合は、現物確認が必要と明記。
```
