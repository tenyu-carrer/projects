# 008 権利・完成チェックシート

## 物語・レイアウト
- [ ] 4コマの因果がつながっている
- [ ] 読み方向とコマ番号が明確
- [ ] セリフと絵が同じ説明を重複しない
- [ ] スマートフォンで吹き出しを読める
- [ ] 主人公の固定設定が各コマで揃っている
- [ ] 実話・創作・AI生成の表示が誤解を招かない

## 参照・権利・プライバシー
- [ ] 他作品・作家・キャラクターの具体的表現を模倣していない
- [ ] 参照画像や素材の作成者・利用許可・条件を記録
- [ ] AIサービスの現行規約を確認した
- [ ] 顔写真・個人情報・秘密情報の入力許可を確認
- [ ] 迷う点は公開を保留し、専門家確認を検討

## 出力
- [ ] 掲載先の最新寸法・容量・形式を確認
- [ ] 別アプリ・端末で全体を確認
- [ ] 文字化け・端の切れ・画質・読み順を確認
- [ ] 台本・固定文・プロンプト・編集元を保存
- [ ] 公開前確認者・確認日を記録
