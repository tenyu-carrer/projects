# 006-D AIプロンプト集｜ロゴの発想・点検

AI案は候補にすぎません。商標調査、類似性、素材ライセンス、登録可能性をAIの回答だけで決めないでください。

## 1. ブリーフの不足確認
```text
ブランド名：【】事業：【】顧客：【】用途：【】避ける表現：【】
ロゴ制作に必要な情報の不足だけを質問してください。
個人情報や競合の未公開情報は要求しない。商標の安全性を断定しない。
```

## 2. 独自コンセプトの文章化
```text
事業：【】顧客：【】印象3語：【】使用場所：【】避けるもの：【】
既存ロゴ・特定作家を模倣せず、異なる視覚コンセプトを3案文章で提案。
各案に図形の意味、単色版、小サイズの工夫、独自性を人が検討する問いを含める。
```

## 3. 画像生成用の説明
```text
用途はロゴ方向性の検討用。名称：【】事業：【】印象：【】
抽象的で単純な形を3方向、文字や実在企業名なしで提案。
商標・キャラクター・著名作家の模倣をしない。生成結果は完成ロゴや登録可能性を保証しないと表示。
```

## 4. 案の批評
```text
事業：【】顧客：【】印象：【】用途：【】素材条件：【】
案の特徴：【】
可読性、小サイズ、単色、識別性、事業との一致を点検。
類似商標や権利侵害の有無は断定せず、人が確認する方法を挙げる。
```

## 5. 商標調査語の整理
```text
名称：【】読み方：【】表記揺れ：【】商品・サービス分野：【】
文字・称呼・略称・ローマ字・類似音の検索語候補を整理。
実際の検索結果を作らず、J-PlatPatで人が確認する項目と専門相談が必要な点を分ける。
```

## 6. 素材台帳の点検
```text
素材記録：【素材名、出典、作成者、規約URL、取得日、用途】
空欄を「未確認」とし、ライセンス内容を推測せず確認事項を表にする。
ロゴ用途、商標、独占使用、編集元共有、素材単体配布の確認を含める。
```

## 7. 納品前説明文
```text
納品物：【】確認済み用途：【】未確認事項：【】素材条件：【】
利用者向けに、できること、してはいけないこと、権利確認の残り、編集方法を簡潔に記載。
商標登録済み・独占可能など、入力にない状態を主張しない。
```
