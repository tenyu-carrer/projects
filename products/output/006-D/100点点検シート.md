# 006 ロゴ制作・公開前点検シート

自動点数は教材の存在と構成を点検するもので、ロゴの権利や商標登録可否を証明しません。

## ブリーフと用途
- [ ] 正式名称・読み方・事業内容が確定
- [ ] 顧客・使用場所・最小サイズ・避けたい誤認を記録
- [ ] ロゴの用途（商標／販促／社内）を区別

## 制作と比較
- [ ] 方向性を複数比較し採用理由を記録
- [ ] 特定ブランド・作家・キャラクターを模倣していない
- [ ] 小サイズ、白黒、単色、異なる背景で確認
- [ ] 名前の読みやすさと図形の視認性を第三者にも確認

## 権利・素材・調査
- [ ] AI・デザインツールの現行規約を確認
- [ ] 素材・フォント・テンプレートの条件と出典を記録
- [ ] 商標名・読み方・図形について確認範囲と日付を記録
- [ ] 検索結果だけで安全・登録可能と断定していない
- [ ] 必要な専門家相談を実施、または未確認として利用保留

## 納品
- [ ] 用途に合うファイル形式で書き出した
- [ ] 別アプリで透明、色、余白、フォントを確認
- [ ] 素材再配布・編集元共有条件を確認
- [ ] 版番号、採用理由、使用ガイドを保存
