# 014-D 完全パック｜AIで商品画像・広告画像を作る方法

版：初稿 v1.0｜状態：試作｜対象：商品写真と広告画像を初めて作る成人｜所要：約3〜5時間｜公式資料確認日：2026-10-23

## 1｜この講座で作るもの

一つの商品を題材に、用途と対象者を決め、写真を選び、広告の情報階層を組み、媒体別画像を1点作って検品する講座です。到達物は、商品写真1点、正方形または縦型の広告画像1点、コピーの根拠表、素材ライセンス記録、書き出し確認表。見栄えだけでなく、商品が実物と違って見えない、根拠のない効果・実績・限定情報が混ざらない、スマートフォンで要点が読める状態を合格とします。

練習素材はAI生成の架空クッキー包装写真です。実在商品・販売者・食品撮影の実績ではありません。公開や販売への利用を想定した見本ではなく、構図と情報設計を学ぶための練習用です。実際の商品へ転用する場合は、販売者の確認済み商品情報、実物写真、ロゴ、価格、使用許可に置き換えて再点検します。

対象：SNS・ネットショップ向け画像を作りたい初心者。前提：画像ファイルを開いて保存できること。必要なもの：商品写真、文章作成AI（任意）、Canva等のデザインツール、掲載先の仕様。ツールの料金・画面・素材条件は変わるため、利用前に公式情報を確認。追加費用が必要な場合は自動更新・解約条件を確認してから申し込みます。

## 2｜10分体験：一枚の広告設計

1. 商品と対象者を一つずつ書く（例：架空クッキー／手土産を探す人）。
2. 読者へ伝えたい価値を、確認可能な事実から一つ選ぶ。
3. 商品写真で最初に見せる部分を決める。
4. 見出し・補足・行動案内を別々に仮置きする。
5. 写真の余白と文字の重なりを確認。
6. 画像をスマホ幅へ縮小し、商品・見出し・CTAを読めるか見る。
7. 未確認の価格・効果・在庫・受賞・No.1表記がないか点検。

完成サイン：何の商品を誰向けに見せるか一言で説明でき、主役の商品が最初に視線へ入る。最後に「この表示を裏付ける資料はどれか」と自分に質問し、根拠のない文言は削除します。

## 3｜企画と撮影を設計する

いきなりテンプレートを選ばず、商品名・対象者・利用場面・掲載先・必要寸法・目的（知ってもらう／詳細を見る／購入ページへ移る）をブリーフに記入します。広告一枚に情報を詰め込まず、「誰に何を知ってもらうか」を一つに絞ります。価格、期間、送料、割引条件、数量、原材料、アレルギー、効果などは、責任者が確認した資料をもとに入力します。AIに事実を作らせません。

商品写真を撮るときは、必要なカットを先に決める：正面の全体、質感が分かる寄り、サイズや使い方が分かる場面。窓光など自然な光でも、反射や影は商品形状を隠さないよう調整。商品色・大きさ・内容量が実物より良く見える演出は避けます。食品・化粧品・医療関連などは、広告表示の専門的な確認を追加し、AIによるラベル文字の生成や商品形状の改変を使いません。

## 4｜完成見本：架空クッキー写真の読み解き

付属 `014-cookie-product-photo-concept.png` は、文字・ロゴのない架空パッケージとクッキーの広告素材イメージです。右側の商品袋が主役、左上に文字用の余白、手前の皿が利用場面を補います。写真が伝えるのは雰囲気と構図だけで、実在の味、素材、手作り、焼きたて、受賞、人気、健康効果、価格、販売状況は示しません。

見本に広告を組む際は、まず主役が読めるか、文字が余白へ収まるか、縮小しても見出しが視認できるかを確認します。背景が明るいため、白文字を直接置くとコントラストが弱くなることがあります。文字の後ろに薄い色面を使う、濃い文字色にする、位置を変えるなど、読みやすさを優先。AI画像のパッケージに後から実在ラベルを合成する場合は、実物の形状と表示を誤認させないよう販売者の承認を得ます。

仮コピー「午後のおやつに、焼きたてのひと休み」は学習用の架空例。商品事実の根拠がないため、広告として公開しません。練習レイアウトには必ず「架空の商品・広告練習」と明記します。

## 5｜プロンプト5本：案を作り、事実を守る

### 1. 広告構成

```text
商品：【】。見る人：【】。掲載先：【】。伝えたい価値：【】。
確認済みの事実と根拠：【】。未確認情報：【】。
見出し・補足・行動案内を別々に3案。価格、効果、人気、受賞、在庫を創作しない。
各案が誰に何を伝えるかを一文で説明。
```

### 2. レイアウト指示

```text
比率：【】。掲載面：【】。商品画像：【ファイル名】。
商品を主役にし、見出しは【場所】、補足は【場所】、CTAは【場所】。
安全余白を確保し、写真と文字が重ならない。縮小時に読める文字量にする。
包装、商品形状、ラベル、ロゴの再生成・変更は禁止。
```

### 3. 写真撮影計画

```text
商品カテゴリー：【】。撮影場所・機材：【】。用途：【】。
必要なカット、背景、光の向き、反射対策、サイズ感の伝え方、撮影後の確認項目を提案。
実物より大きさ・内容量・色・質感を誤認させる加工は提案しない。
```

### 4. 表現・根拠チェック

```text
広告文：【】。確認済みの根拠資料：【】。比較対象・調査条件：【】。
品質・価格・効果・実績・期限を示す断定表現を抽出し、根拠が不足する箇所を保留表示。
法令適合を断定せず、責任者が確認すべき一次資料と質問を列挙。
```

### 5. 媒体サイズ展開

```text
原稿比率：【】。展開先と仕様：【】。維持する要素：【】。
各比率で切れやすい場所と再配置案を提示。自動トリミング後に商品、文字、価格、CTAの欠けを確認。
```

AI案の採用基準：誤情報を追加しない、商品より装飾が目立たない、広告主が事実を承認できる、権利不明素材がない。再指示は一項目だけ変え、「文字を短く」「余白を増やす」のように具体化します。

## 6｜制作手順：ブリーフから納品まで

1. **原稿・素材の確認**：商品名、価格、条件、根拠資料、撮影者、素材利用範囲を責任者と確認。曖昧な表示は保留。
2. **掲載先仕様の確認**：画像サイズ・比率・容量・セーフエリアを掲載先の最新公式ヘルプで確認。古いテンプレートをそのまま流用しない。
3. **写真選定**：解像度、色、向き、主役の位置、余白、商品状態を確認。画像生成素材なら実物写真とは区別。
4. **情報の優先順位**：主役商品、見出し、補足、CTAの順に置く。価格・日付など更新頻度が高い情報は独立した要素にする。
5. **デザイン制作**：Canva等で指定寸法を設定し、文字は編集テキストとして配置。余白・対比・文字サイズ・ブランドルールを確認。
6. **AIの補助**：コピー案・配置案・背景案など作業を限定。商品形状、ラベル、文字、利用者レビューをAIに創作させない。
7. **縮小・表示確認**：スマホ相当サイズで要点が読めるか、背景とのコントラスト、端切れ、誤読を確認。色覚・小画面でも識別しやすいかも見る。
8. **事実・権利チェック**：すべての断定表現に根拠を紐付け、写真・フォント・アイコン・テンプレートの利用条件を記録。
9. **承認**：商品責任者・広告主から書面または履歴が残る形で確認を得る。未承認案は公開フォルダーへ入れない。
10. **書き出し・再表示**：指定形式・寸法で保存し、ファイルを閉じて開き直す。ファイル名・版・承認者・公開日・リンクをログに残す。

Canvaなど素材ライブラリの素材は、含まれる素材種別と利用条件によって再利用範囲が異なります。テンプレートや素材そのものを再配布できると決めつけず、素材ごとのライセンスと商用利用条件を使用時に確認。掲載先の仕様、キャンペーン条件、価格変更があれば、公開済み画像も更新します。

## 7｜課題・よくある失敗・検品

### 課題

1. **練習**：架空クッキー素材で、商品・見出し・架空表記だけの構図案を作る。合格＝実在広告と混同せず、余白・読みやすさが説明できる。
2. **実用品**：自分の商品または許可を得た素材で広告1点。合格＝商品情報の根拠、素材権利、掲載仕様を記録。
3. **納品想定**：同一広告の正方形と縦長版を制作。合格＝各版を個別に再点検、最新版の承認履歴と編集可能原稿がある。

### トラブルシューティング

1. **商品が目立たない**：文字・装飾が競合。装飾を一つ外し、商品サイズと余白を見直す。
2. **スマホで読めない**：文字が小さい・長い。見出しを短くし、重要でない説明を遷移先へ移す。
3. **背景と文字が溶ける**：明度・色相が近い。文字色・背景面・位置を変え、縮小して再確認。
4. **商品が実物と違う**：AIがラベルや形を変えた。生成商品画像は実物広告に使用せず、実物写真に差し替える。
5. **パッケージ文字が崩れる**：画像生成AIの文字表現。パッケージ面を見せない／実物写真を使用／許可済みラベルを正確に合成。
6. **主張の根拠がない**：「人気」「No.1」「効果」等がAIから追加。根拠がそろうまで削除し、広告責任者が確認。
7. **価格・日付が古い**：本文へ焼き込まれて管理漏れ。更新箇所を独立レイヤーにし、公開前に台帳と照合。
8. **サイズ違いで切れる**：自動トリミング依存。媒体別に再配置し、商品・CTA・条件表示を個別確認。
9. **素材のライセンスが不明**：ダウンロード元・条件の記録なし。公開を保留し、公式契約・素材情報を確認。
10. **広告っぽさが強すぎる**：伝えることを詰め込みすぎ。目的と対象を一つに戻し、主要CTAを一つにする。
11. **食品の見た目が誇張**：AI画像で量・色・トッピングを変えた。実物の撮影画像に差し替え、実物との違いを誤認させない。
12. **書き出し後に画質劣化**：寸法・圧縮設定の不一致。指定サイズから再書き出し、ファイルを開いて確認。

### 100点チェック（合格目安85点）

対象・目的15点／商品写真の適切さ15点／情報階層と読みやすさ15点／掲載仕様への適合10点／表示根拠・誠実さ20点／素材・権利記録10点／書き出し再確認10点／承認・版管理5点。根拠のない重要表示、実物と誤認させる架空商品写真、無許諾素材、未承認の公開、リンク・価格の重大な誤りは点数によらず不合格。

- [ ] 商品名・条件・価格は承認済み原稿と一致
- [ ] 数値・品質・効果・比較・限定表示に根拠資料がある
- [ ] 商品写真と実物の色・形・内容量を誤認させない
- [ ] 写真・ロゴ・フォント・テンプレートの利用条件を記録
- [ ] 商品、見出し、CTAがスマホ縮小時にも確認できる
- [ ] 各掲載比率で端切れ・文字つぶれがない
- [ ] 編集可能原稿・書き出し画像・版が一致
- [ ] 承認者・承認日・公開予定を記録
- [ ] リンク・価格・キャンペーン条件を公開直前に再確認
- [ ] 架空の練習素材は架空と明示

## A/B/C/Dの役割

A｜10分体験は広告の骨組みを作る短い入口。B｜完成品はすぐ使える練習用の架空商品広告素材。C｜設計シートは別商品でも再利用できる道具。D｜この講座は事実確認・素材管理・媒体別制作・検品を自力で行う力を育てます。架空の写真を実在商品の完成広告とは扱いません。

制作時間の配分例：企画と根拠確認30〜45分、写真選定・撮影45〜90分、レイアウト60〜90分、媒体別展開30〜60分、最終点検20〜30分。これは学習上の目安であり、商品の種類・素材・承認フローにより大きく変わります。写真の許可や広告表示の根拠が未確認なら、所要時間にかかわらず公開工程へ進めません。特に公開直前の価格・URL・期限は、制作初日に入力したままにせず、責任者と一緒にもう一度照合してください。


本教材は、販売成果・売上・クリック率を保証しない教材です。写真・素材の権利は、素材ログで確認してから使ってください。
