# 042-C｜Threads運用 設計シートとプロンプト

**状態：再利用用初稿／投稿前に必ず全文を自分で読む**

## 設計欄

- アカウントのテーマ（1つに絞る）と、読んでほしい人：
- 読んでほしい人が知りたいこと（3つ）：
- 投稿の型（使い方・実話・問いかけ・お知らせ）の回し方：
- 1日の投稿数と時刻／コメントに返す時間帯：
- 実話の事実確認のしかた（書いてよいことの範囲）：
- 作り置きと予約の方法／確認者：

```text
アカウントのテーマ【】と読んでほしい人【】から、その人が知りたいことを10個挙げて。それぞれに合う投稿の型（使い方・実話・問いかけ・お知らせ）を付けて。
```
```text
話題【】で、Threadsの投稿を書き出しの型違いで3案。各300文字以内、絵文字3〜6個、言い過ぎなし。実際にあったことだけを書く。
```
```text
1週間の投稿計画【】を点検して、同じ型・同じ書き出し・同じ締めが続いている所を指摘して、入れ替え案を出して。
```
```text
投稿の下書き【】の中で、事実の確認が必要な部分（体験・数字・サービスの機能）を抜き出して。確かめていない習慣や出来事が書かれていたら指摘して。
```
```text
長い話【】を、つながった複数の投稿（スレッド）に分けて。1つ目だけで興味が持てるようにし、各投稿は1つの話題にして。
```
```text
もらったコメント【】への返事を2案。相手の言葉を受け止めて、押しつけない言い方で。
```
```text
1週間の反応【投稿ごとの表示・いいね・返信】から、読む人に届いた話題の傾向を整理して。次の週に1つだけ変えることを提案して。
```
```text
Threadsの投稿【】を、Instagramのキャプション用に書き直して。文章の長さと絵文字の数を合わせ、同じ文章のままにしないで。
```

AIの下書きはたたき台です。自分の言葉と、確かめた事実だけで仕上げます。
