# 015-C 背景透過・画像合成 設計シートとプロンプト

## 作業前設計

- 元画像・撮影者・使用許可：
- 被写体の用途・媒体：
- 出力サイズ・形式・透過の要否：
- 保持する形・色・質感：
- 切り抜く境界（髪・毛・透明・細い枝など）：
- 変えてよい背景・小物：
- 光の向き・色温度・地面：
- 影の向き・濃さ・柔らかさ：
- 合成背景の権利・素材出典：
- AIへ画像を送る条件・確認日：

## プロンプト1｜透過計画

```text
用途：【】。被写体：【】。保持する細部：【】。背景：【透明】。
切り抜きで特に点検する境界を列挙し、欠損・縁色・穴の誤認を防ぐ確認手順を提案。
影は【残す／別レイヤーで作る／含めない】。被写体の形・色・模様を変更しない。
```

## プロンプト2｜マスク修正

```text
修正する範囲：【位置・境界】。保持する輪郭：【】。問題：【欠け／縁の色／穴の埋まり】。
変更はマスク境界だけ。被写体の色・形・質感、他の領域を変えない。
濃色・淡色・柄背景の上で比較する確認手順を添える。
```

## プロンプト3｜合成背景の設計

```text
被写体：【】。背景の場所・面：【】。光の向き：【】。カメラ高さ・遠近：【】。
被写体が接地する位置と影を自然に合わせる。背景素材の出典・使用許可が不明なら保留。
実際のサイズ・品質・商品情報を誤認させない構図にする。
```

## プロンプト4｜境界の検品

```text
被写体の境界を部位ごとに点検：外周、細い部分、穴、半透明部分、影。
欠け・白縁・黒縁・色残り・背景の穴・不自然な影を一覧化し、最小の修正を一つずつ提案。
画像を見られない場合は検査済みと断定しない。
```

## プロンプト5｜書き出し

```text
用途：【】。必要な背景透過：【はい／いいえ】。サイズ・形式：【出力先仕様】。
透明保持を確認する再表示手順、ファイル名、原本・編集版の管理方法を提示。
仕様値が未提示なら推測せず、公式仕様を調べるべき項目として返す。
```

## 変更ログ

原本ファイル名／マスク版／背景版／影の設定／出力形式／透明再確認／確認者／未解決事項を記録します。
