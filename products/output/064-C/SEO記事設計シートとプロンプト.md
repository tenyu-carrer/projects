# 064-C｜AIでSEO記事を作る 設計シートとプロンプト

**状態：再利用用初稿／順位は保証されない。事実と体験は人が確かめる**

## 設計欄

- 書く人と、このテーマで書ける理由（実際の経験）：
- 検索しそうな言葉（3〜5個）：
- 検索する人の場面と、本当に知りたいこと：
- 記事の最初で出す答え：
- 事実（数字・値段・時間）の確認先：
- Search Console（検索の数字を見る道具）の登録：
- 確認者／確認日：

```text
テーマ【】について、検索する人が入れそうな言葉を10個挙げて。それぞれ、検索する場面と本当に知りたいことを1行で。
```
```text
検索の言葉【】の、本当に知りたいこと【】に答える記事の見出しを5〜7個作って。最初の見出しで答えを出す順にして。本文は書かないで。
```
```text
見出し【】の本文の下書きを作って。400〜600字。数字・値段・時間は【要確認】と書いて自分で決めないで。最後に、書く人が体験を足すとよい場所を3つ示して。
```
```text
記事【全文】が、検索の言葉【】で来た人の知りたいことに答えているか点検して。答えが遅い所、関係のない話、足りない情報を指摘して。
```
```text
記事【】のタイトル案を5つと、検索結果に出る説明文（120字前後）の案を3つ作って。中身にない約束や、大げさな言葉は使わないで。
```
```text
記事【】の中で、同じサイトのほかの記事【一覧】へつなぐとよい場所を3つ挙げて。つなぐ理由も書いて。
```
```text
記事【】の事実（数字・値段・時間・言い切り）を全部抜き出して表にして。確認先の欄は空けておいて。
```
```text
Search Consoleの数字【表示回数・クリック数・検索の言葉】から、記事に足すとよいことを3つ挙げて。数字が少なすぎる場合はそう書いて。
```

検索の順位は、Googleが決めます。この教材でできるのは、**検索する人の役に立つ記事を作ること**までです。
