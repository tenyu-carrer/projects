# 040-D｜AIで音声編集・ノイズ除去をする方法

**状態：初稿／処理の流れ図・処理記録CSV付き。実音声の処理・外部AI・書き出しは未検証**  
対象：録音した声の雑音を減らし、聞きやすく整えたい初心者｜所要：約3〜5時間｜更新日：2026-10-31  
前提：033のナレーション、039のポッドキャスト（どちらかで録音したことがあると分かりやすい）。追加課金、有料API、素材購入は行いません。

## 1｜到達点と完成物

この講座のゴールは、**録音した声の雑音の種類を見分け、録音で防げるものは防ぎ、編集では弱い処理から試して聞き比べ、声が自然なまま聞きやすく整える**ことです。

完成物は、①雑音チェック表、②録音前の工夫メモ、③処理記録（CSV）、④処理前後の聞き比べメモ、⑤書き出した音声ファイル、⑥次回の設定メモ、⑦公開前チェック記録の7点です。

付属見本は、架空の録音を題材にした処理の流れ図と処理記録です。実際の音声ファイルはありません。

まずは自分の30秒の録音で練習し、慣れてから本番の長い録音に進みます。

**完成条件：** 元の録音が残っていて、処理の内容と強さが記録され、処理後の声にこもりや金属的な音がなく、スピーカーとイヤホンの両方で聞きやすい。

## 2｜この講座で使う言葉

- **ノイズ（雑音）**：声以外の、じゃまな音。
- **ノイズ除去**：雑音を減らす処理。AIを使って声と雑音を分けるものもあります。
- **ノイズプロファイル**：雑音だけが鳴っている部分を聞かせて、「これが雑音です」とソフトに教えること。
- **ノーマライズ／ラウドネス調整**：音量をそろえる処理。
- **イコライザー（EQ）**：高い音・低い音など、音の高さごとに大きさを変える処理。
- **非破壊**：元のファイルを変えずに作業すること。

## 3｜雑音の種類を見分ける

雑音は、大きく4つに分けられます。種類によって、効く対処が違います。

| 種類 | 例 | 主な対処 |
|---|---|---|
| ずっと鳴る音 | エアコン、パソコンのファン、冷蔵庫 | ノイズ除去が効きやすい |
| 一瞬の音 | 物を置く音、咳、通知音 | 切る、または残す |
| 部屋の響き | 何もない部屋で声が反響 | 録音の場所を変えるのがいちばん効く |
| 声の問題 | 息の音、口の音、マイクに息がかかる | 距離と角度を直す、軽い処理 |

```text
録音を聞いて気づいた音【】を、ずっと鳴る音・一瞬の音・部屋の響き・声の問題に分けて表にして。録音で防げるか、編集で減らせるかも書いて。
```

## 4｜録音で防ぐのがいちばん

ノイズ除去は便利ですが、かけると少なからず声も変わります。いちばんきれいなのは、雑音を録音しないことです。

- エアコンや換気扇を、録音の間だけ止める
- 布の多い部屋（カーテン、ソファ、布団）で録る
- スマホやマイクを口から20〜30cmに固定し、少し横にずらして息がかからないようにする
- 車の少ない時間帯を選ぶ
- 通知を切る

```text
次の録音環境【部屋・機材・時間帯】で、雑音を減らすための録音前の工夫を5つ、お金をかけずにできる順に並べて。
```

## 5｜元のファイルを守る

処理を始める前に、元の録音ファイルをコピーし、元のファイルは別のフォルダに保管します。処理はコピーに対して行います。処理をやり直したくなったとき、元のファイルがないと戻れません。ファイル名には「_元」「_処理v01」のように版を付けます。

## 6｜ずっと鳴る音を減らす

エアコンの音のような、ずっと鳴っている雑音には、ノイズ除去が効きやすいです。無料の音声編集ソフト（Audacityなど）の一般的な手順は次の通りです（画面の名前は版で変わります）。

1. 録音の中で、声がなく雑音だけが鳴っている部分（1〜2秒）を選ぶ
2. ノイズ除去の機能で、その部分を「雑音のサンプル」として読み込ませる
3. 全体を選び、**弱い設定**でノイズ除去をかける
4. 前後を聞き比べる
5. 足りなければ少しずつ強くする

AIを使ったノイズ除去機能は、声と雑音を自動で分けてくれるものもあります。ただし、**外部のサービスに音声を送る場合は、話している人の同意、個人情報が含まれていないか、サービスが音声を保存・利用する条件**を確認します。

## 7｜かけすぎのサイン

ノイズ除去を強くかけすぎると、次のような問題が出ます。

- 声がこもる、水の中で話しているように聞こえる
- 金属的な「シュワシュワ」という音が出る
- 語尾や小さな声が消える
- 無音の部分が不自然に「真空」のようになる

```text
処理の前後の聞き比べの感想【】から、かけすぎか足りないかを判断して、次に試す設定の方向（強く・弱く）を整理して。
```

**少し雑音が残っても、声が自然なほうが聞きやすい**ことが多いです。完全に消すことを目指しません。

## 8｜一瞬の音を処理する

物を置く音や咳などの一瞬の音は、ノイズ除去ではうまく消えません。

- 声と重なっていない → その部分を切る、または音量を下げる
- 声と重なっている → 無理に消すと声も欠けるので、そのまま残すか、録り直す

```text
録音の文字起こし【】から、一瞬の物音や咳が入っている箇所を時刻つきで抜き出して。切るか残すかの判断は人がするので、候補として出して。
```

切るときは、027で学んだように、意味が変わらないか、語頭・語尾が欠けないかを確認します。

## 9｜音量をそろえる

雑音を減らしたら、音量をそろえます。

- 全体の音量を、聞きやすい大きさにそろえる（ノーマライズ・ラウドネス調整）
- 声が急に大きくなる部分だけ下げる
- 2人で話している場合は、それぞれの声の大きさをそろえる

配信先によって、推奨される音量の目安があることがあります。目安は配信先のヘルプで確認します。

## 10｜聞き比べと書き出し

処理が終わったら、元のファイルと処理後のファイルを、同じ部分で聞き比べます。

- スマホのスピーカーとイヤホンの両方で聞く
- 最初・真ん中・最後の3か所だけでなく、できれば全部聞く
- 家族など、ほかの人にも聞いてもらう

```text
完成した音声の確認表を作って。項目：声のこもり、金属的な音、音量の差、語頭・語尾の欠け、息の音、無音の不自然さ。各項目に、確認した時刻と結果を書く欄を付けて。
```

書き出すときは、用途に合った形式（動画に入れるならWAV、配信ならMP3など、配信先の指定を確認）を選びます。

## 11｜処理を記録する

どの処理を、どのくらいの強さでかけたかを記録しておくと、次回同じ部屋で録るときにすぐ同じ設定を使えます。

```text
処理記録【】をもとに、次回同じ部屋で録音するときの設定メモを作って。録音前の工夫、ノイズ除去の強さ、音量の目安を1枚にまとめて。
```

## 12｜2人以上で話す録音

2人以上で話す場合は、1人で話すときとは別の問題が出ます。

- **声の大きさの差**：声が大きい人と小さい人の差を、音量をそろえる処理で縮めます。できれば、それぞれにマイク（スマホ）を用意して、別々のファイルで録ると調整しやすくなります。
- **声が重なる**：話がかぶった部分は、無理に分けずに残すか、聞き取りにくければ言い直してもらいます。
- **オンラインで話す場合**：相手側の通信状態で音が途切れることがあります。大事な部分は、相手にも自分の手元で録音してもらい、あとで合わせる方法もあります。録音することは必ず相手に伝えます。

```text
2人で話した録音の問題点【声の大きさ・重なり・途切れ】から、録音のやり方の改善案と、編集での対処を表にして。
```

## 13｜動画の音声を整える場合

動画の音声も、同じ手順で整えられます。動画の場合は、音を処理したあとに、映像と口の動きがずれていないかを必ず確認します。音声だけを書き出して処理し、動画に戻すときは、最初と最後の位置を合わせます。BGMを入れるのは、声を整えたあとにします（037参照）。声とBGMを同時に処理すると、ノイズ除去がBGMまで削ってしまうことがあるためです。

## 14｜見本で通し練習：エアコンの音を減らすまで

付属の `040-noise-log.csv` の1行目を例にします。

1. **雑音の確認**：エアコンの「ブーン」という音が、録音全体でずっと鳴っている。
2. **録音で防げたか**：次回はエアコンを止めて録る、とメモ。今回は編集で減らします。
3. **元のファイルを保管**：「ep01_元.wav」を別フォルダへ。コピーの「ep01_処理v01.wav」で作業。
4. **ノイズ除去**：冒頭の声がない2秒を雑音のサンプルにして、弱い設定でかけます。
5. **聞き比べ**：エアコンの音は小さくなり、声のこもりはない。OK。
6. **記録**：処理・強さ・結果を記録表に書きます。

## 15｜よくある質問

**Q. 有料のソフトでないときれいにならないですか？**  
A. 無料のソフトでも、録音の工夫と弱めのノイズ除去・音量調整で、十分聞きやすくなることが多いです。まずは録音環境を見直しましょう。

**Q. AIのノイズ除去は強く効くので、全部それでいいのでは？**  
A. 強力な分、声が不自然になることもあります。また外部サービスに音声を送る場合は、同意や個人情報の確認が必要です。前後を聞き比べて判断します。

## 16｜自動化と収益化（第3段階）

- **固定する作業**：雑音チェック表→録音前の工夫→処理の候補→聞き比べの判断→物音の候補出し→設定メモ。Cの8プロンプトと処理記録を使えば、毎回同じ手順で整えられます。
- **人がやる作業**：耳での聞き比べ、切るか残すかの判断、外部サービスに送る前の確認。
- **仕事にする場合**：ポッドキャストや動画の音声を整える作業を引き受ける方法があります。依頼主から預かった音声の扱い（保管・削除・外部サービスに送るか）を最初に取り決め、処理記録を納品物に含めます。

依頼数や収益を保証しない教材です。

## 18｜よくある失敗と直し方

1. **元のファイルに上書き**：必ずコピーで作業する。
2. **強くかけすぎて声がこもる**：弱い設定に戻す。
3. **金属的な音が出る**：ノイズ除去を弱め、録音環境を見直す。
4. **雑音のサンプルに声が入っている**：声のない部分を選び直す。
5. **一瞬の音を無理に消して声が欠ける**：切るか、そのまま残す。
6. **部屋の響きをノイズ除去で消そうとする**：録音の場所を変える。
7. **息の音がうるさい**：マイクを少し横にずらして録り直す。
8. **音量がばらばら**：音量をそろえる処理をする。
9. **スピーカーでしか聞かない**：イヤホンでも聞く。
10. **処理を記録していない**：処理記録に強さと結果を書く。
11. **外部サービスに無断で音声を送る**：話している人の同意と条件を確認する。
12. **書き出し形式が合わない**：配信先の指定を確認する。
