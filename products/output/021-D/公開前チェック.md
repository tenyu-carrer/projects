# 021-D｜動画公開前チェック

- [ ] 視聴者・目的・完成尺が明確
- [ ] 元動画・音声・画像・音楽・フォントの権利を確認
- [ ] 人物の同意と個人・機密情報を確認
- [ ] EDLの開始・終了・残す理由を原素材と照合
- [ ] 自動文字起こしの固有名詞・数字・否定を原音確認
- [ ] 字幕の誤字、改行、表示時間、画面端を確認
- [ ] 映像の欠け、黒フレーム、意図しないジャンプを確認
- [ ] 音声をヘッドホンとスピーカーで確認
- [ ] 最新の公開先仕様で書き出し設定を確認
- [ ] 書き出し後のファイルを最初から最後まで再生
- [ ] PC・スマートフォン等の実表示を確認
- [ ] 版・承認者・日付・未検証事項を記録
