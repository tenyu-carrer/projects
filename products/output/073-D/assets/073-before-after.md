# 直す前と直した後（見本・架空）

**状態：架空の整体院「ひだまり整体」の「はじめての方へ」の見本。実在のお店ではありません**

## 直す前

はじめてのお客様は、受付で問診票を記入して頂いた後、施術者がお身体の状態をお伺いし、その日の状態に合わせた施術内容をご提案させて頂きますので、ゆったりお過ごしください。施術時間は約40分で、料金は4,000円です。多くの方に喜ばれています。

## 直した後

はじめてのお客さまは、受付で問診票をご記入ください。
そのあと、施術者がお体の状態をうかがい、その日の状態に合わせた施術をご提案します。ゆったりお過ごしください。
施術時間は約40分、料金は4,500円です（2026年11月の料金表で確認・架空）。

## 直した理由

| 直した所 | 理由 |
|---|---|
| お客様→お客さま | 表記のルール表 |
| 1文（110文字）を3文に分けた | 1文が長く、言いたいことが3つ入っていた |
| 頂いた・させて頂きます→ください・します | 回りくどい言い方を短く |
| 料金 4,000円→4,500円 | 最新の料金表で確かめたら古い料金だった |
| 「多くの方に喜ばれています」を消した | 根拠がない（AIのリライトで残っていた） |
| 「ゆったり」は残した | お店の言い方として残す（AIは「ゆっくり」をすすめた） |
