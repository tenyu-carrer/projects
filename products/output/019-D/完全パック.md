# 019-D｜SUZURIでステッカーを販売する方法

**状態：初稿／630×630px練習素材付き。SUZURI実入稿・印刷・貼付・剥離・耐水・注文・販売は未検証**  
対象：小さくても伝わるオリジナルステッカーを初めて登録したい人｜所要：約3〜5時間｜公式確認日：2026-10-23  
費用：教材制作では追加課金なし。アカウント、サンプル注文、販売・税務上の費用は受講者が必要性を判断します。

## 1｜到達点と完成物

この講座では、正方形画像をアップロードするだけでなく、小サイズで残す情報を選び、透明外周と製品余白を区別し、権利・説明・価格・実物未検証を記録します。完成物は、①ステッカー設計シート、②素材・権利台帳、③630×630pxの入稿候補、④縮小比較、⑤SUZURIプレビュー記録、⑥商品名・説明文・価格記録、⑦公開前チェックです。

2026-10-23に確認した公式情報では、ステッカーの推奨画像は横630×縦630px、完成品は最大80×80mmです。希望寸法を直接指定する機能はなく、小さく作りたい場合は630×630pxより小さい画像で登録する案内があります。また、デザイン周囲には必ず余白が付き、余白をなくすことはできません。この三点を企画の前提にします。

## 2｜公式仕様と変動情報を確認する

公式のアイテム一覧、ステッカー注意事項、画像アップロード条件、販売手順、規約を順に確認します。推奨キャンバスと製品の仕上がり寸法は同じ種類の数字ではありません。630pxは画像データ、最大80mmは製品サイズです。画面上の透明領域も、製品に必ず付く余白の幅やカット形状を保証しません。

| 項目 | 2026-10-23確認内容 | 公開直前の確認 |
|---|---|---|
| 推奨画像 | 630×630px | 公式一覧で再確認 |
| 完成品 | 最大80×80mm | 注意事項で再確認 |
| 小さく作る場合 | 630×630pxより小さい画像で登録 | 実プレビューでサイズ感確認 |
| 周囲余白 | 必ず付く。ゼロにはできない | プレビューと必要なら実物で確認 |
| 形式・容量 | PNG/JPG、15MB以下 | ファイル情報で実測 |
| 価格 | 変動情報 | 作成画面で三数値を記録 |

公式はステッカーを防水仕様、再剥離可能と案内していますが、貼り付ける素材によって剥がれにくい場合があるとも説明しています。「どこでも跡なく剥がれる」「屋外で永久に使える」と拡張してはいけません。本教材では実物を試していないため、耐水・貼付・剥離を検証済みと表示しません。

**完了条件：** 仕様、URL、確認日、変動情報、未検証事項が設計シートへ記録されている。

## 3｜小サイズで残す要素を選ぶ

ステッカーは一覧画像、商品ページ、手元の実物と表示サイズが変わります。大画面で美しい細部も、64pxのサムネイルや数cmの実物では消える場合があります。主役を一つ、補助を二つ以内に絞り、輪郭と色面で意味を作ります。細い飾り、長い文章、複数の小さな顔、細かなグラデーションへ意味を依存させません。

```text
テーマ【】、対象者【】、貼る場面【】から、ステッカー図案を3案。
各案は主役1つ、補助2つ以内。小さな文字、細線、複雑な背景を避ける。
既存作品、ブランド、人物、作家名を参照しない。
630px、128px、64pxへ縮小したとき失いそうな要素を案ごとに示す。
```

付属見本は太陽、道、二枚の葉だけで構成します。主役は黄色い円、紺色の道は視線の流れ、緑の葉は補助です。文字を入れず、フォントライセンスや小さい文字の判読問題を切り離しています。この見本をそのまま販売せず、自分の主題へ置き換えます。

**判断基準：** 64px表示を3秒見た人が主役の形を説明できる。補助を隠しても主題が崩れない。  
**完了条件：** 採用案と、削除した細部・不採用案の理由が記録されている。

## 4｜透明背景と製品余白を区別する

透明PNGの外周は「画像に色がない領域」です。SUZURI製品として必ず付く余白は「製造仕様」です。両者を同一視しないでください。透明境界がそのままカットされる、余白が一定幅になる、複雑な凹凸に沿う、と教材だけで断定しません。公式テンプレートと作成画面のプレビューを確認します。

```text
630×630px透明キャンバスに図案【】を配置する仕様書を作る。
主役は中央寄り、重要要素は外周から離し、透明領域を残す。
要素の位置と大きさをキャンバス比率で示す。
製品余白の幅・カット形状は推測せず、SUZURIプレビュー確認項目にする。
```

透明部分には、消し残し、半透明の点、白い縁が残ることがあります。白・黒・色付きの背景上でPNGを表示し、四隅、輪郭の周り、図案内部の穴を確認します。アルファ値が0の完全透明と、薄く見える半透明を区別します。必要ない半透明は削除し、意図した影なら小サイズで残るか確認します。

**完了条件：** 四隅透明を実測し、透明外周と製品余白の違いを説明できる。

## 5｜細線・文字・隙間を検査する

小さな製品では、線や隙間が画面より弱くなります。SUZURIの一般的な線画注意事項では、1mm以下の線や文字を含むオブジェクトは正常に加工されず、つぶれや欠けが起きるおそれがあり、1.1mm以上が推奨されています。商品や加工方法による違いがあるため、ステッカーへ機械的に絶対条件として転記するのでなく、最新の作成画面・商品詳細と合わせて安全側の確認項目にします。

```text
図案【】について、主役輪郭、補助線、文字、要素間の隙間を、630px、128px、64px、約2cmで確認する表を作る。
消える、つぶれる、別の形に見える候補を列挙。
実印刷の結果は推測せず、サンプル確認欄を残す。
```

文字を入れる場合は、商品名を図案へ全部書き込まず、短い単語一つ程度から試します。小文字、細い書体、長い曲線上の文字は避けます。利用フォントの商用・商品化条件を確認し、文字を画像へ変換した後も誤字を目視します。読みやすさと権利の両方が確認できなければ、文字なし図案に戻します。

**完了条件：** 64pxと約2cmの見え方を記録し、消える細部を削除または太くした。

## 6｜権利・規約を画像以外にも適用する

SUZURIでは、図案、サムネイル、商品名、説明文を含めて禁止事項や権利侵害が判断されます。既存キャラクター、有名人、ブランド、車、実在商品、無許可写真、ロゴ、トレース、模写、二次創作を使いません。短い言葉でも商標やシリーズ名に似る可能性があるため、商品名候補を確認します。

AI生成物は、利用サービスの規約、入力素材、生成日時、編集内容を台帳へ残します。「AI生成だから自由」「自作だから類似確認不要」とは考えません。人物写真、個人情報、依頼者の秘密素材は、同意や契約条件を確認できるまで外部AIへ送信しません。

```text
図案【】、商品名候補【】、説明文【】を、著作権、商標、肖像、プライバシー、素材ライセンス、AI利用条件、SUZURI禁止事項で質問形式に点検。
適法性を断定せず、根拠資料・許可・作成記録の保存先を問う。
不明な項目は「販売保留」にする。
```

**完了条件：** 全要素に作成者・出典・許諾・証拠があり、商品名と説明まで確認済み。

## 7｜入稿データを作って開き直す

編集原稿と入稿版を分けます。例：`019_sticker_source_v01.svg`、`019_sticker_upload_v01.png`。透明が必要ならPNGを使い、JPGへ変換して意図しない白背景を作らないようにします。公式の推奨サイズ、形式、容量を利用時に再確認します。

1. 元データを保存する。
2. 630×630pxのPNGを書き出す。
3. ファイルを閉じ、別の画像ビューアで開く。
4. 寸法、容量、RGBA、四隅のアルファを実測する。
5. 白・黒・色背景で消し残しと白縁を見る。
6. 128px、64pxへ縮小表示して主役を確認する。
7. 商品ID、版、日付を制作ログへ記録する。

付属PNGは630×630px、RGBA、透明四隅の教材用図案です。外部素材を使わず単純図形から作成していますが、SUZURIへ入稿していないため、受理、製品余白、印刷輪郭、色は未検証です。

**完了条件：** 元データと入稿版を再び開け、実測結果と縮小結果がログにある。

## 8｜SUZURIプレビューを観察する

公式の販売手順では、画像をアップロードし、対象アイテムを選び、必要ならペンマークから位置を調整し、商品名・説明・トリブンを設定して規約確認後に販売します。本教材ではログイン、アップロード、販売開始をしていません。受講者は販売確定前に、図案の大きさ、周囲余白、主役位置、細部の見え方を観察します。

```text
SUZURIステッカープレビュー【観察内容】を、図案外周、必ず付く余白、主役の大きさ、細部、背景、想定サイズで表にする。
画面で見える事実と、カット形状・余白幅・印刷色・貼付結果など未確認事項を分ける。
画面だけで実物合格と判定しない。
```

プレビュー画像は合成イメージで実物と異なる可能性があります。モニター設定やRGBからCMYKへの変換で色が変わる可能性もあります。プレビューの輪郭がきれいでも、実物のカット・印刷・素材を保証しません。必要ならサンプルを注文し、費用を記録して検品します。

**完了条件：** 採用配置、不採用配置、修正理由、未検証事項をプレビュー票に記録した。

## 9｜商品名・説明文・価格を作る

商品名は図案内容に正確で、他者の知名度に便乗しないものにします。説明文にはモチーフ、想定場面、確認済み事実を書きます。公式の防水・再剥離に触れる場合も、確認日と貼付素材による注意を分けます。本教材自身が耐水試験をしたようには書きません。「どこでも使える」「跡が絶対残らない」「永久に色落ちしない」は避けます。

```text
確認済み事実【】、図案【】、対象【】、貼る場面【】から商品名10案と説明文3案。
他社名、作品名、人物名、誇張、耐久・剥離・効果・収益の保証を使わない。
防水・再剥離は最新公式情報の確認日と、貼付素材による注意を分ける。
未確認事項を明記する。
```

価格は一覧の「価格〜」を確定額として転記せず、作成画面の原価、トリブン、表示販売価格を記録します。トリブン関連手数料、送料、税務は最新公式情報と自分の条件を確認します。販売数や利益をAIに予測させて確定根拠にしません。

```text
作成画面の原価【】、設定トリブン【】、表示販売価格【】、確認日【】を転記表にする。
三数値の不一致と未確認費用を示す。
送料、手数料、税、利益を推測せず、最新公式表示を確認先にする。
売上や収益を保証しない。
```

**完了条件：** 商品名・説明の全表現が根拠へ戻れ、価格三数値の画面記録がある。

**合格条件：** 主役、補助、透明外周、製品余白の違いを説明できる。

### 課題2：自作図案と登録下書き（60分）

自作図案を作り、権利台帳を埋め、入稿版を実測。SUZURIで販売確定前までのプレビューを記録する。  
**合格条件：** 仕様、縮小、余白、権利、商品情報、価格の記録が揃う。

### 課題3：サンプル検品（任意費用）

必要性と費用を判断して注文し、寸法、余白、輪郭、色、貼付、剥離、水濡れ後を記録する。貼付先を傷めない目立たない場所から試す。  
**合格条件：** 実物写真と結果があり、問題を説明文・販売判断へ反映。本教材は未実施。

## 11｜よくある失敗と直す順番

1. **細部が多く主役が分からない**：主役1つ、補助2つへ削る。
2. **64pxで形が消える**：細線を太くし、小さな点を削除する。
3. **長い文字が読めない**：短い語へ変更するか商品説明へ移す。
4. **白い背景が付いた**：JPGや不透明レイヤーを確認し透明PNGへ再出力。
5. **輪郭に白い縁がある**：色背景上で半透明ピクセルを確認し元データを修正。
6. **余白をゼロにしたい**：仕様上必ず余白が付くことを前提にデザインを再構成。
7. **透明境界どおりに切れると思った**：カット形状を保証せず、実プレビューとサンプルで確認。
8. **最大80mmを超えると思った**：最大寸法と画像pxを分け、公式注意事項を再確認。
9. **小さくする方法が曖昧**：公式案内に従い小さい画像で登録し、プレビューでサイズ感を確認。
10. **商品名が既存ブランドに似る**：公開停止し名称・商標を確認。重要案件は専門家へ。
11. **AI素材の利用条件が不明**：規約、入力素材、生成記録を確認し、証拠がなければ自作へ。
12. **防水を過大に説明した**：公式文言と確認日に戻り、自分の未試験と使用環境差を明記。
13. **どこでもきれいに剥がせると書いた**：貼付素材によって剥がれにくい注意を反映し断定を削除。
14. **一覧価格と購入価格が違う**：作成画面の原価・トリブン・販売価格を記録する。
15. **プレビューだけで完成扱いした**：合成イメージと実物検品を分け、サンプル未実施を表示。
