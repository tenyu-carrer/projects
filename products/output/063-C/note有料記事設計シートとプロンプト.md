# 063-C｜noteで記事を作成・販売する 設計シートとプロンプト

**状態：再利用用初稿／noteの規約・手数料・機能は使う時点で公式ページを確認**

## 設計欄

- 読む人（1人に絞る）と、その人の困りごと：
- 書く人の経験（有料にできる理由）：
- 無料部分で役立つこと：
- 有料部分の中身（目次）：
- 値段の考え方（中身の量・読み終えて得られること）：
- noteの規約・手数料・振込の条件を確認した日：
- 確認者／確認日：

```text
読者【】の困りごと【】について、書く人【】の経験から書ける有料記事のテーマを3案出して。それぞれ、無料部分で役立つこと1つと、有料部分の中身を1行で。
```
```text
テーマ【】の記事の目次を、無料部分と有料部分に分けて作って。有料部分に何があるかを正直に見せて。
```
```text
目次【】のうち【無料部分】の本文の下書きを作って。600〜900字。数字は【要確認】と書いて、自分で決めないで。最後に、書く人が体験を足すとよい場所を3つ示して。
```
```text
目次【】のうち【有料部分の1章】の本文の下書きを作って。手順・表・失敗の直し方など、読んだ人がそのまま使える形にして。数字は【要確認】にして。
```
```text
記事【全文】の中の事実（数字・値段・日付・効果）を抜き出して表にして。確認先の欄は空けておいて。
```
```text
記事【全文】を読んで、無料部分と有料部分の中身の量、読み終えて得られることを整理して。値段を決めるときに考えることを3つ挙げて。値段そのものは決めないで。
```
```text
記事【】の紹介文（記事の最初の数行とSNSでの告知）を作って。中身にない約束（必ず・誰でも・稼げる）はしないで。
```
```text
公開した記事への感想や質問【】から、記事に足すとよいことと、次に書くとよいテーマを3つ挙げて。
```

有料にするのは「書く人の経験からしか書けないこと」です。検索すれば無料で分かる一般論だけを有料にしません。
