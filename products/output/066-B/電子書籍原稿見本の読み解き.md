# 066-B｜AIで執筆する電子書籍 見本の読み解き

**状態：架空の著者による原稿見本。実際の出版・販売・読者の反応は未検証**

付属の見本は、架空の著者「ベランダでハーブを育てて5年の会社員・森さん（架空）」が、短い電子書籍『ベランダで始めるハーブ 最初の30日』（架空・全6章・約2万字の予定）を書く途中の記録です。

- `066-ebook-flow.png`：読者を決めてから、原稿ファイルにするまでの流れ図
- `066-ai-record.png`：AIを「どこに使ったか」を分けて記録する考え方の図
- `066-chapter-plan.csv`：章立て表（各章の読者の疑問・自分の経験・文字数の目安・AIの使い方・状態）
- `066-style-sheet.csv`：表記ルール表（「1鉢／ひと鉢」などの書き方をそろえる表）
- `066-sample-chapter1.md`：第1章の見本原稿（架空・約1,500字）と、直した箇所の記録

見るポイント：

1. **章ごとに「読者の疑問」がある**：章立て表の各行に「この章で答える疑問」が書いてあります。疑問が書けない章は、本に入れません。
2. **体験は著者の言葉**：第1章の「水をやりすぎて根をいためた」は森さん（架空）の体験として書かれ、AIは聞き手と文の直しにだけ使っています。
3. **数字は確認先を書く**：水やりの回数や日当たりの時間など、種の袋や園芸メーカーの説明で確かめる数字には【要確認】の印を残し、確かめたら確認先を記録します。
4. **AIの使い方を記録**：章立て表に「AIの使い方」の列があり、「聞き手」「文の直し」「AIの下書き」を分けて書いています。出版先によっては、AIが作った文章があるかどうかを申告する必要があるためです（Kindleダイレクト・パブリッシングの規定。067で詳しく扱います）。

この見本は考え方を示すためのもので、実在の人物・本・販売実績ではありません。園芸の内容も、実際に育てるときは種の袋や専門の情報で確かめてください。
