# 032-D｜AIで広告動画を作る方法

**状態：初稿／3案比較図・テスト計画表CSV付き。実広告配信・広告審査・外部AIは未検証**  
対象：SNSや動画サイトに、お金を払って配信する広告動画を作りたい初心者｜所要：約5〜8時間｜更新日：2026-10-31  
前提：031の商品PR動画（表現チェック表）、022のショート動画。追加課金、有料API、素材購入は行いません。**この講座では実際の広告配信（お金を使う操作）は行いません。**

## 1｜到達点と完成物

この講座のゴールは、**冒頭だけを変えた15秒の広告動画を3案作り、広告ポリシーと表現のルールを確認したうえで、配信テストの計画を立てる**ことです。

完成物は、①設計シート、②冒頭3案と共通の後半、③3つの縦横比に合わせた配置案、④表現チェック表、⑤広告ポリシー確認メモ、⑥テスト計画表、⑦公開前チェック記録の7点です。

付属見本は、架空の「オンライン書道教室」の3案比較図とテスト計画表です。実際の配信結果や広告費の数字はありません。

**完成条件：** 3案の違いが冒頭の1か所だけで、すべての言葉に根拠があり、配信先の広告ポリシーの確認日が記録され、予算と止める条件が決まっている。

## 2｜この講座で使う言葉

- **広告ポリシー**：広告を出す場所（Meta、Google・YouTube、TikTokなど）ごとに決められた、広告で使ってよい・いけない内容のルール。審査で守れていないと配信されません。
- **ABテスト**：1か所だけ違う複数の案を配信して、どちらの反応が良いかを比べる方法。
- **クリエイティブ**：広告で使う動画や画像そのもののこと。
- **リンク先（ランディングページ）**：広告をタップしたときに開くページ。
- **視聴維持（再生の続き具合）**：動画がどこまで見られたか。

## 3｜PR動画と広告動画の違い

031のPR動画は、自分のアカウントで投稿してフォロワーに見てもらうものでした。広告動画は、お金を払って、まだ知らない人の画面に表示するものです。違いは3つあります。

1. **知らない人が見る**：興味のない人にも表示されるので、最初の数秒で関係があると思ってもらう必要がある。
2. **審査がある**：配信先の広告ポリシーに沿っていないと配信されない。何度も違反するとアカウントが制限されることもある。
3. **お金がかかる**：配信するほど費用がかかるので、予算の上限と止める条件を先に決める。

## 4｜表現のルール（031の復習＋広告の注意）

景品表示法とステマ規制は031で学んだとおりです。広告ではさらに、配信先ごとの広告ポリシーに注意します。たとえばMetaの広告規定には、個人の特徴（年齢、健康状態、体型など）を決めつける言い方や、誤解を招く表現について決まりがあります。GoogleやYouTubeにも広告ポリシーがあります。細かい内容は変わるため、作る前と配信前に公式ページを確認し、確認日を記録します。

```text
広告の言葉【】を点検して。最上級、効果の保証、個人の特徴を決めつける言い方（「〇〇なあなたへ」で悩みを断定するなど）、根拠のない比較、期限のあおりに印を付けて、言い換え案を出して。
```

## 5｜冒頭3案を作る

広告動画では、冒頭の切り口を変えた案を作り、どれが届くかを比べるのが基本です。

- **困りごと型**：「字に自信がなくて、のし袋を書くのが苦手」
- **できるようになる型**：「月2回、自宅で筆ペンの練習ができます」
- **意外な事実型**：事実を使う場合は、公式な根拠があるものだけ

```text
商品【】の広告動画の冒頭3秒を、困りごと・できるようになること・意外な事実の3パターンで作って。
意外な事実には根拠の確認が必要なので「要確認」と付けて。誇張表現は使わない。
```

## 6｜共通の後半（4〜15秒）

後半は3案で共通にします。入れるのは、サービスの中身、料金（税込）、申込方法、注意点です。

| 秒数 | 中身 | 見本 |
|---|---|---|
| 4〜8秒 | 何ができるか | 自宅からオンラインで月2回、先生が添削 |
| 8〜12秒 | 料金と条件 | 料金（税込）と、初回体験あり |
| 12〜15秒 | 申込方法 | 「プロフィールのリンクから体験予約」 |

```text
冒頭3案に共通でつなぐ後半（4〜15秒）の構成を作って。サービスの内容、料金（税込）、申込方法、注意点を入れ、字幕は1行16文字以内にして。
```

## 7｜縦横比ごとに作り替える

配信先によって、縦型（9:16）、正方形（1:1）、横型（16:9）を使い分けます。文字や大事な部分が、画面の端やボタンに隠れないように配置を変えます。

```text
広告動画の構成【】を、9:16・1:1・16:9の3つに作り替えたときの配置案を出して。文字と申込の案内が切れない・ボタンに隠れない位置を示して。
```

## 8｜リンク先と食い違わないようにする

広告で言っていることと、タップした先のページの内容が違うと、見た人の信頼を失い、審査でも問題になります。料金、体験の条件、申込方法を、広告とリンク先で一致させます。

```text
リンク先ページ【内容】と広告動画【字幕全文】を比べて、料金・条件・申込方法・言葉の食い違いを表にして。
```

## 9｜テスト計画を立てる（お金を使う前に）

配信は、この講座では行いません。実際に配信するときのために、計画だけ作ります。

- **変えるのは1か所だけ**（今回は冒頭3秒）
- **予算の上限**：1案あたりいくらまで、全体でいくらまで
- **期間**：何日間配信するか
- **比べる指標**：再生の続き具合、クリック、申込
- **止める条件**：予算に達した、審査で否認された、苦情が来た、など

予算や配信の設定は、お金を出す人の承認を必ず取ってから行います。配信の結果は、配信先の仕組みや時期によって変わり、少ない数字で決めつけると判断を誤ります。

## 10｜撮影と編集のコツ（広告向け）

広告動画は、スマホの小さな画面で、音を消した状態で見られることが多い前提で作ります。

- **最初のコマで内容が分かる**：動画が自動再生されたとき、最初の静止画だけで「書道の話だ」と分かるように、筆と半紙を画面いっぱいに映します。
- **字幕は大きく、短く**：1行16文字以内、画面の幅の8割程度に収めます。
- **明るく、背景はすっきり**：生活感のある物が映ると、内容より背景に目がいきます。
- **最後の画面は静止**：料金と申込方法の画面は2秒以上止めて、読める時間をつくります。
- **3案は同じ日に同じ場所で撮る**：冒頭以外の条件をそろえるためです。明るさや服が変わると、比べる意味が薄れます。

```text
広告動画の撮影計画【3案の冒頭と共通の後半】から、撮影の順番、場所、明るさ、服装、小道具をそろえるためのリストを作って。冒頭以外の条件が案ごとに変わらないようにして。
```

## 11｜素材・出演者・音楽の権利

広告は、たくさんの知らない人に表示されるため、権利の問題が起きたときの影響も大きくなります。

- **出演者**：教室の先生や生徒が映る場合、広告に使うこと・配信する期間・場所を伝えて、書面で許可を取ります。投稿用の許可と広告用の許可は別に考えます。
- **音楽**：SNSの投稿で使える音源でも、広告では使えないことがあります。広告に使える条件の音源だけを選びます。
- **生徒の作品**：書道教室なら生徒の書いた作品も、作った人の権利があります。本人（子どもの場合は保護者）の許可を取ります。
- **AIで作った素材**：使ったサービスで、広告に使ってよいか（商用利用）を公式規約で確認します。

```text
広告動画に使う素材【映像・音楽・出演者・作品】について、広告に使うための権利の確認表を作って。投稿用の許可と広告用の許可を分けて書き、確認できない素材の代わりの案も出して。
```

## 12｜結果の読み方（配信したあと）

配信したら、結果の数字を見て次を決めます。ただし、数字の読み方には注意が必要です。

- 表示回数が少ないうちは、たまたまの差が大きく出ます。数字が少なすぎる場合は「まだ判断できない」とします。
- 再生の続き具合が良くても、申込につながらないことがあります。冒頭と後半、リンク先のどこで離れているかを分けて考えます。
- 結果が良かった案も、時期や配信先が変われば同じ結果になるとは限りません。

```text
広告の結果【案ごとの表示回数・再生の続き具合・クリック・申込】を読み、どの案が良かったか、その理由として考えられること、次に1か所だけ変えるならどこかを整理して。数字が少なすぎて判断できない場合はそう書いて。
```

## 13｜見本で通し練習：案Bを作るまで

付属の `032-ad-test-plan.csv` の案B（できるようになる型）を例にします。

1. **冒頭の一言**：「月2回、自宅で筆ペンの練習」。サービスの事実だけで作っています。
2. **後半は共通**：4〜15秒は案A・Cと同じ映像と字幕を使います。
3. **表現の点検**：「必ずきれいな字に」は効果の保証になるため使いません。
4. **縦横比**：縦型を基本にし、正方形版では字幕を中央寄りに移します。
5. **ポリシー確認**：配信予定の場所の広告ポリシーを開き、確認日をメモに書きます。
6. **テスト計画**：案A・Cと同じ予算・期間で比べる計画にします。

## 14｜自動化と収益化（第3段階）

- **固定する作業**：冒頭3案→共通後半→表現点検→縦横比→リンク先照合→テスト計画。Cの8プロンプトをこの順で使います。
- **人がやる作業**：ポリシー確認、予算の承認、結果の判断。
- **仕事にする場合**：広告動画の制作だけを引き受ける形（配信と予算管理は依頼主）にすると、責任の範囲が分かりやすくなります。表現チェック表とポリシー確認メモを納品物に含めます。

広告の成果、売上、依頼数を保証しない教材です。

## 15｜課題（3段階）

1. **練習**：架空のサービスで冒頭3案を作る（合格：切り口が違い、誇張なし）
2. **実用品**：15秒の広告動画を3案書き出す（合格：違いが冒頭だけ、料金と申込方法が字幕にある）
3. **公開想定**：ポリシー確認メモとテスト計画表をそろえる（合格：確認日・予算上限・止める条件がある）

## 16｜よくある失敗と直し方

1. **複数の場所を同時に変える**：変えるのは1か所だけにする。
2. **効果を保証する言葉**：事実の言葉に言い換える。
3. **悩みを決めつける言い方**：一般的な困りごとの言い方に直す。
4. **広告とリンク先の料金が違う**：両方を同じ内容に直す。
5. **税込・税抜があいまい**：税込で表示する。
6. **文字がボタンに隠れる**：配置を縦横比ごとに直す。
7. **音を消すと分からない**：字幕で料金と申込方法を見せる。
8. **ポリシーを確認していない**：配信前に公式ページで確認し、日付を記録する。
9. **予算の上限がない**：上限と止める条件を先に決める。
10. **少ない数字で決めつける**：判断に足りない場合は期間を延ばすか保留する。
11. **他人の写真や声を使う**：本人の許可がある素材だけ使う。
12. **承認なしに配信を始める**：お金を出す人の承認を取る。
