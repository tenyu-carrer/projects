# 069-B｜メルマガ 見本の読み解き

**状態：架空の配信者による見本。実際の配信・開封の数字は未検証**

付属の見本は、架空の料理教室「みどり台キッチン（架空）」の講師・森さん（架空）が、教室の生徒と体験会の参加者に向けて週1回のメルマガを始めたときの設計記録です。

- `069-mail-flow.png`：読者の登録から配信・見直しまでの流れ図
- `069-mail-anatomy.png`：1通の型（件名→書き出し→本文→してほしいこと→署名と配信停止）の図
- `069-editorial-calendar.csv`：4週間の配信計画（テーマ・件名案・してほしいこと・確認日）
- `069-sample-issue.md`：完成見本の1通（第1号）
- `069-legal-footer-check.md`：広告を含むメールの表示チェック（送信者の名前・配信停止の方法など）

見るポイント：

1. **読者は登録した人だけ**：体験会の申込みフォームで「メルマガを受け取る」に自分で印をつけた人だけに送り、いつ・どの画面で同意をもらったかを記録しています。
2. **1通で伝えることは1つ**：第1号は「日曜に30分で3品の段取り」だけ。教室の宣伝は最後の1行にまとめています。
3. **署名と配信停止はいつも同じ場所**：最後に送信者の名前・住所・問い合わせ先・配信停止のURLを毎回入れています。
4. **AIの案から言い切りを消した**：「誰でも料理上手に」「献立の悩みがゼロに」を消した記録があります。

この見本は考え方を示すためのもので、実在の人物・教室・配信実績ではありません。
