# 010-D プロンプト集｜オリジナルキャラクター

## 1. 設定の不足確認
```text
用途：【】見る人：【】役割：【】性格：【】世界観：【】
キャラクター制作に必要な不足事項だけを質問。個人情報や参照画像を要求しない。
既存作品や人物の模倣案を出さず、法的安全性を断定しない。
```

## 2. 方向性案
```text
用途：【】見る人：【】役割：【】印象：【】避ける要素：【】
オリジナルキャラクター案を3方向、輪郭・配色・顔・服・小道具で説明。
固定特徴と可変部分を分け、既存キャラクター・ブランド・実在人物を模倣しない。
```

## 3. 基準キャラクター画像
```text
架空キャラクター設定：【】
正面の全身または上半身、無地背景、見分けやすい輪郭。
固定特徴：【】。入れないもの：【文字、ロゴ、透かし、余分な人物】。
```

## 4. 表情差分
```text
共通設定：【】表情：【喜び／困惑など】動作：【】背景：【】
髪・顔・服・色・模様・持ち物は維持。変えてよいのは表情と動作のみ。
```

## 5. 方向・構図差分
```text
基準設定：【】方向：【正面／斜め／横向き】構図：【】
固定特徴を維持し、見えない側の装飾を勝手に追加しない。
特定作品・作家・人物に似せない。
```

## 6. 一貫性レビュー
```text
基準設定：【】出力画像の観察内容：【】
輪郭・色・顔・服・模様・持ち物を照合し、一致・差異・現物確認に分類。
画像を見ていないなら見たふりをしない。法的類似判断はしない。
```

## 7. 権利台帳
```text
生成サービス・素材・フォント・参照画像：【】利用目的：【】規約URL：【】
出典、作成者、許可、商用利用、AI入力、再配布、確認日を整理。
不明な点を利用可と推測せず、確認先と保留事項を示す。
```
