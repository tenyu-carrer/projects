# 031-C｜商品PR動画 設計シートとプロンプト

**状態：再利用用初稿／AI出力は必ず事実と照合**

## 設計欄

- 商品名・型番・サイズ・素材・価格・販売場所：
- この動画を見てほしい人／見たあとにしてほしいこと：
- 言える事実と、その根拠（実測・説明書・検査結果など）：
- 言えない表現（効果効能・最上級・比較の根拠がないもの）：
- 撮影する場面（使っている手元・全体・細部・できないこと）：
- 人から依頼された場合：依頼主名・広告であることの表示方法：
- 確認者／確認日：

```text
商品情報【】から、PR動画で伝える特徴を5つ選び、「事実」「根拠の種類」「見せ方（映像で何を映すか）」を表にして。
```
```text
特徴の表【】から、30秒・4場面の構成案を作って。1場面目は困りごと、2〜3場面目は使っている様子、4場面目はサイズと注意点にして。
```
```text
動画で使う言葉【】を点検して。最上級（一番・最高）、効果効能、他社比較、「必ず」「絶対」など、根拠がないと言えない表現に印を付けて言い換え案を出して。
```
```text
撮影リスト【場面】を作って。各場面に、カメラの位置、映すもの、手元の動き、必要な秒数、撮り直しの目安を付けて。
```
```text
商品の説明欄に入れる文章を作って。内容【】。サイズ・素材・お手入れ・できないことを箇条書きで入れ、誇張しない言い方で。
```
```text
依頼を受けて作るPR動画【依頼主・商品】について、広告であることの表示方法（動画内・説明文・SNSの機能）を案にして。
```
```text
30秒版の構成【】を、15秒版に縮めて。サイズと注意点の場面は残し、削る場面と理由を書いて。
```
```text
完成した動画の言葉【字幕全文】と、表現チェック表【】を照合して、根拠のない言葉が残っていないか確認して。
```

AIは誇張しがちです。最後は必ず人が、言葉と根拠を1つずつ照らし合わせます。
