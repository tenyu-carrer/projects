```text
歌なし（インスト）で作る前提で、ナレーションの声とぶつからない条件も書いて。
```

完成条件：全項目が埋まり、「使わない音」と「声とぶつからない条件」が書かれていること。

```text
動画の場面表【秒数と内容】から、BGMの流し方（どこで流す・小さくする・止める・切り替える）を表にして。声がある区間は音量を下げる指示を入れて。
```

```text
BGMが主役のじゃまになっていないかを点検する質問を10個作って。声の聞き取り、雰囲気の合い方、繰り返しの不自然さなど。
```

# 037-D｜Suno AIでBGMを作る方法

**状態：初稿／BGM配置図・キューシートCSV付き。Sunoでの実生成・各SNSの実投稿は未検証**  
対象：動画やお店、配信で流すBGMを、自分で用意したい初心者｜所要：約3〜5時間｜更新日：2026-10-31  
前提：036「Suno AIでオリジナル曲を作る方法」（画面の基本操作と、無料/有料プランの権利）。追加課金・有料プランへの登録は、この講座の中では行いません。

## 1｜到達点と完成物

この講座のゴールは、**使う場所に合った歌なしBGMをSunoで作り、動画に合わせて音量と切り替えを整え、使ってよい範囲を記録する**ことです。

完成物は、①使う場所メモ、②Styles（曲調の指示）3案、③BGM音源（長さ違い）、④キューシート（流す区間・音量・切り替え）、⑤BGMを入れた書き出し動画、⑥利用範囲の記録、⑦公開前チェック記録の7点です。

付属見本は、架空の料理動画（1分）のBGM配置図とキューシートです。実際の音源はありません。

**完成条件：** BGMが声のじゃまをせず、急に始まったり切れたりせず、生成時のプランと使い道が記録され、使い道がそのプランの範囲に入っている。

## 2｜この講座で使う言葉

- **BGM**：背景に流す音楽。主役（映像・声・お店の雰囲気）を支える役。
- **インスト（インストゥルメンタル）**：歌のない曲。BGMに向いています。
- **Styles**：Sunoに伝える曲調の指示。ジャンル・雰囲気・楽器・テンポなどの言葉で書きます。
- **キューシート**：どの区間で、どの音楽を、どのくらいの音量で流すかを書いた表。
- **フェードイン・フェードアウト**：音をだんだん大きく・小さくすること。急に始まる・切れるのを防ぎます。
- **ダッキング**：声が入るときにBGMの音量を自動で下げること。編集ソフトの機能にある場合があります。

## 3｜歌のある曲とBGMの違い

036で作った歌のある曲は、それ自体が主役です。BGMは、主役を支える脇役です。違いは次の通りです。

| | 歌のある曲 | BGM |
|---|---|---|
| 主役 | 曲そのもの | 映像・声・お店 |
| 歌 | ある | ない方がよい |
| 目立つ音 | あってよい | 少ない方がよい |
| 長さ | 曲として完結 | 場面に合わせて調整 |
| 繰り返し | あまりしない | ループで流すことも |

## 4｜使う場所を決める

BGMは、使う場所で求められることが変わります。

- **動画（ナレーションあり）**：声とぶつからない、落ち着いた音
- **動画（ナレーションなし）**：テンポで映像のリズムを作る
- **店内**：長く聞いても疲れない、音量の上下が少ない
- **配信・イベント**：場面の切り替わりに合わせて曲を変える

```text
使う場所【】で流すBGMに求められる条件を5つ挙げて。声の有無、長さ、繰り返し、音量の上下、雰囲気について。
```

## 5｜権利とプランを先に確認する

Sunoの公式ヘルプでは、無料プランで作った曲は個人的・非商用の利用に限られ、有料プランに加入中に作った曲は商用で使えると案内されています（2026-10-22確認。条件は変わるため利用直前に再確認）。あとから有料プランに加入しても、無料プランのときに作った曲に遡って商用利用の権利が付くわけではない、という案内もあります。

BGMで迷いやすい使い道：

- 収益化しているYouTubeチャンネルの動画のBGM → 商用にあたる可能性が高い
- お店で流すBGM → 商売の場で使うので、条件を確認する
- 依頼を受けて作った動画のBGM → 依頼主の使い道も含めて確認する

```text
BGMの使い道【】について、Sunoの無料プランと有料プランのどちらの条件で考えるべきか判断するための確認リストを作って。答えは推測せず、確認すべき公式ページを示して。
```

この講座では有料プランへの登録は行いません。商用で使う予定がある場合は、費用を確認してから決めます。

## 6｜Stylesを書く

BGMのStylesには、ジャンル・雰囲気・楽器・テンポの言葉を使います。歌を入れない指定（インスト）も忘れずに。

- 料理動画の例：「インスト、アコースティックギター、やさしい、明るい、ゆっくりめのテンポ」
- 店内の例：「インスト、ピアノ、落ち着いた、静か、一定の音量」

**実在の作曲家名・アーティスト名・曲名は入れません。** 似せる指示は、権利の問題につながるおそれがあります。

```text
使う場所メモ【】から、歌なしBGMのStylesを3案作って。ジャンル・雰囲気・楽器・テンポの言葉だけで、実在の名前は使わないで。
```

## 7｜生成して聞き比べる

036と同じ手順で、Custom画面に歌詞を入れず（インストの設定にして）、Stylesと題名を入れて生成します。聞き比べるときは、BGMとしての基準で選びます。

- 目立つ音（急な大きい音、派手なソロ）がないか
- 同じ雰囲気がずっと続くか
- 始まりと終わりが自然か
- 実際の動画に合わせて流したとき、声が聞き取れるか

**曲だけで聞いて良いと思っても、動画に合わせると合わないことがあります。** 必ず実際の映像と一緒に聞きます。

## 8｜長さを合わせる

生成された曲の長さが、動画の長さとぴったり合うことはほとんどありません。

- **短い場合**：同じ曲をつなげてループする。つなぎ目でリズムがずれないか確認する
- **長い場合**：フェードアウトで終わらせる。きりのよい区切り（小節の終わり）で切る
- **場面ごとに変える**：場面の切り替わりで、別のBGMにクロスフェード（重ねて切り替え）する

```text
動画の長さ【秒】と、BGMの長さ【秒】から、ループ・カット・フェードのどれで合わせるかの案を出して。つなぎ目が自然になる工夫も書いて。
```

## 9｜音量と切り替えを整える（キューシート）

BGMの音量は、声より十分小さくします。声がある区間ではさらに下げます。

```text
動画の場面表【秒数と内容】から、キューシートを作って。各区間に、流すBGM、音量の目安（大・中・小）、入り方（フェードイン・クロスフェード）、終わり方（フェードアウト）を書いて。声がある区間は「小」にして。
```

書き出したら、スマホのスピーカーとイヤホンの両方で聞きます。スピーカーでは小さく聞こえても、イヤホンでは大きすぎることがあります。

## 10｜効果音と組み合わせる

BGMだけでなく、効果音（ジュッと焼ける音、ボタンを押す音など）を少し足すと、映像の動きが伝わりやすくなります。ただし、効果音もBGMと同じく、使ってよい条件の音だけを使います。

- 効果音は、映像の動きとぴったり合わせる（ずれると不自然）
- BGMより一瞬だけ大きくし、すぐ戻す
- 1つの場面で効果音を何回も鳴らさない

```text
動画の場面表【秒数と動き】から、効果音を入れるとよい場所を最大5つ挙げて。効果音の種類、鳴らす秒数、BGMとの音量の関係を書いて。入れすぎになる場所は「入れない」と書いて。
```

## 11｜店内で流す場合

お店で流すBGMは、長時間くり返し聞かれるため、動画のBGMとは別の配慮が必要です。

- 音量の上下が少ない曲を選ぶ
- 1曲だけを何時間もループしない（数曲を順番に）
- お客さんの会話のじゃまにならない音量にする
- 使ってよい条件（商用利用）を必ず確認する

なお、市販の曲（CDや配信の曲）をお店で流す場合は、著作権の管理団体への手続きが必要になることがあります。自分で作ったBGMでも、使ったサービスの規約を守る必要がある点は同じです。

## 12｜見本で通し練習：キューシートを作るまで

付属の `037-bgm-cue-sheet.csv` を例にします。

1. **場面を確認**：0〜10秒は材料の紹介（ナレーションあり）、10〜45秒は調理（ナレーションあり・なしが混ざる）、45〜60秒は完成カット（ナレーションなし）。
2. **BGMを選ぶ**：全体は「やさしいアコースティック」1曲。完成カットだけ少し明るい2曲目にクロスフェードします。
3. **音量**：ナレーションのある区間は「小」、ない区間は「中」。
4. **入り方・終わり方**：最初は1秒のフェードイン、最後は2秒のフェードアウト。
5. **プランの記録**：「記録例（実生成なし）」と書き、実際に作るときは生成時のプランと日付を書きます。
6. **確認**：書き出して、ナレーションが全部聞き取れるかを確かめます。

## 13｜よくある質問

**Q. 無料プランで作ったBGMを、収益化していない趣味の動画に使ってもいいですか？**  
A. 個人的・非商用の範囲かどうかで判断します。迷う場合は、公式ヘルプを読み、確認できるまで使わないのが安全です。

**Q. 動画サイトの無料音源と、自分で作るBGMはどちらがいいですか？**  
A. 動画サイトのオーディオライブラリにも、条件付きで使える音源があります。手軽さなら既存の音源、雰囲気を細かく合わせたいなら自分で作る、という選び方があります。どちらも利用条件を確認します。

## 14｜自動化と収益化（第3段階）

- **固定する作業**：使う場所メモ→Styles3案→生成→聞き比べ→長さ合わせ→キューシート。Cの8プロンプトを順に使います。
- **人がやる作業**：映像と一緒に聞く確認、プランと使い道の確認、依頼主への説明。
- **仕事にする場合**：店舗や動画制作者向けに、雰囲気に合わせたBGMを用意する依頼が考えられます。商用で渡すなら有料プラン加入中に作る必要があり、費用がかかるため、オーナーの承認と見積もりが先です。利用範囲の説明書を必ず添えます。

依頼数や売上を保証しない教材です。

## 15｜課題（3段階）

1. **練習**：付属のキューシートを読み、別の1分動画（架空でよい）のキューシートを作る（合格：声の区間の音量が「小」、入り方と終わり方がある）
2. **実用品**：Stylesを3案作り、1案で生成して動画に合わせる（合格：声が聞き取れ、急に始まる・切れる所がない）
3. **公開想定**：利用範囲の記録と公開前チェックをそろえる（合格：プランと使い道が一致し、全項目に印と確認日）

## 16｜よくある失敗と直し方

1. **歌入りの曲で声が聞き取れない**：インストで作り直す。
2. **BGMが大きすぎる**：声の区間は音量を下げる。
3. **急に始まる・切れる**：フェードイン・フェードアウトを入れる。
4. **ループのつなぎ目でリズムがずれる**：区切りのよい位置で切ってつなぐ。
5. **派手なソロが目立つ**：Stylesから派手な楽器の言葉を外す。
6. **曲だけで選んで動画に合わない**：必ず映像と一緒に聞く。
7. **Stylesに実在の名前を入れる**：ジャンル・雰囲気・楽器の言葉に置き換える。
8. **無料プランの音源を商用で使う**：使い道を確認し、商用なら有料プラン加入中に作り直す。
9. **プランを記録していない**：生成日とプランをキューシートに書く。
10. **店内で1曲だけを長時間ループ**：数曲を順番に流す。
11. **スピーカーでしか確認しない**：イヤホンでも聞く。
12. **依頼主に利用範囲を伝えない**：説明書を添える。
