# 035-D｜AIで動画の台本を作る方法

**状態：初稿／構成図・2列台本CSV付き。実撮影・外部AI・各SNSの実投稿は未検証**  
対象：動画を作るとき、何をどう話すか毎回迷ってしまう初心者｜所要：約3〜5時間｜更新日：2026-10-31  
前提：特になし（021〜034のどの動画講座とも組み合わせて使えます）。追加課金、有料API、素材購入は行いません。

## 1｜到達点と完成物

この講座のゴールは、**AIを使って60秒動画の台本を作り、事実確認と話し言葉の点検をして、撮影にそのまま使える2列台本に仕上げる**ことです。15秒版・3分版への作り替えもできるようにします。

完成物は、①設計シート、②骨組み台本、③つかみ3案、④2列台本（話す言葉と映像）、⑤事実確認リスト、⑥15秒版・3分版、⑦公開前チェック記録の7点です。

付属見本は、架空テーマ「冷蔵庫の残り物で作る朝ごはん」の構成図と2列台本です。実際の動画や再生数はありません。

**完成条件：** 台本が4部分（つかみ・結論・やり方・まとめ）に分かれ、話す言葉と映像が対応し、事実・安全に関わる箇所がすべて確認済みになっている。

## 2｜この講座で使う言葉

- **台本**：動画で話す言葉や、映す映像の順番を書いたもの。
- **骨組み台本**：細かい言葉ではなく、各部分で何を話すかだけを書いた台本。
- **2列台本**：左に話す言葉、右に映す映像を並べた表。撮影や編集のときに迷いにくくなります。
- **つかみ**：動画の最初の数秒。見続けてもらうための入り口。
- **CTA（次の行動のお願い）**：見終わった人にしてほしいこと（保存する、続きを見る、など）。

## 3｜台本がないと何が困るか

台本なしで撮ると、話があちこちに飛ぶ、大事なことを言い忘れる、撮り直しが増える、編集で切る場所が分からない、といったことが起こります。台本は、**撮影と編集の時間を減らすための道具**です。一字一句その通りに話す必要はなく、骨組みがあれば十分なことも多いです。

## 4｜見る人と、してほしいことを決める

台本を書く前に、3つを決めます。

- **見る人**：「朝が忙しい共働きの人」のように、具体的に
- **困りごと**：「朝ごはんを考える時間がない」
- **見終わったあとにしてほしいこと**：「冷蔵庫を開けて、1つ試してみる」

```text
テーマ【】について、見る人の候補を3つ挙げて。それぞれの困りごとと、動画を見終わったあとにしてほしい行動を1つずつ書いて。
```

してほしいことは1つに絞ります。「保存して、フォローして、コメントして」と全部お願いすると、どれもされにくくなります。

## 5｜4部分の骨組みを作る

60秒の動画は、次の4部分にすると作りやすくなります。

| 部分 | 秒数 | 役割 |
|---|---|---|
| つかみ | 0〜5秒 | 見る人の困りごとや疑問を言う |
| 結論 | 5〜15秒 | 答えを先に言う |
| やり方 | 15〜50秒 | 具体的な方法を3つまで |
| まとめ | 50〜60秒 | 結論をくり返し、次の行動を1つ |

```text
テーマ【】、見る人【】、してほしいこと【】で、60秒の骨組み台本を作って。つかみ・結論・やり方3つ・まとめの4部分に分け、各部分に秒数と話すことを2行以内で書いて。
```

結論を最後まで引っぱると、途中で見るのをやめられやすくなります。先に結論を言い、そのあと理由ややり方を話すのが基本です。

## 6｜つかみを3案作る

つかみは、型を変えて3案作り、いちばん自然なものを選びます。

- **疑問形**：「冷蔵庫の残り物、朝ごはんにできるって知ってました？」
- **困りごと**：「朝、何を作るか考える時間がない人へ」
- **意外な事実**：事実を使う場合は、確認できたものだけ

```text
台本【】のつかみを、疑問形・困りごと・意外な事実の3つの型で作って。意外な事実の案には「要確認」と付けて。誇張や「絶対」は使わないで。
```

つかみで約束したことは、動画の中で必ず答えます。答えない約束をつかみに入れるのは、見る人をがっかりさせます。

## 7｜2列台本にする

骨組みができたら、話す言葉と映す映像を並べた2列台本にします。

```text
骨組み台本【】から、2列台本を作って。5〜10秒ごとに区切り、各行に「秒数」「話す言葉」「映す映像」「画面の文字（12文字以内）」を書いて。
```

話す言葉と映像がずれていないかを確認します。「卵を割ります」と言うときに、まだ冷蔵庫を開けている映像だと、見る人は混乱します。

## 8｜事実確認をする

AIは、それらしい数字や情報を作ってしまうことがあります（ハルシネーションと呼ばれます）。特に、**健康・安全・お金・制度**に関わる情報は、間違えると見る人に害が出るおそれがあります。

```text
台本【】の中で、事実・数字・安全・健康・お金・制度に関わる箇所を全部抜き出して。それぞれに確認先の候補（公式サイト、メーカーの説明書、公的機関など）を付けて。
```

見本では「卵の加熱時間」が安全に関わるため、「要確認」になっています。確認できなかった情報は、台本から外すか、「しっかり火を通す」のように確認できる範囲の言い方にします。

## 9｜話し言葉に直して時間を測る

台本は声に出して読みます。書き言葉のままだと、話すと不自然になります。

- 「〜である」「〜することが可能です」→「〜です」「〜できます」
- 長い文は2つに分ける
- 言いにくい言葉（早口言葉のような並び）は言い換える

読む速さは1分あたり300文字前後が目安です。60秒の台本なら、話す言葉は300文字前後に収めます。

```text
台本【】を声に出して読んだときの秒数を、1分300文字の目安で計算して。60秒を超える場合は、削る候補を優先順位つきで出して。書き言葉っぽい表現にも印を付けて。
```

## 10｜他人の台本をまねしすぎない

人気の動画の構成を参考にするのは勉強になりますが、言い回しや具体的な内容をそのまま写すと、著作権の問題や、見る人からの信頼を失うことにつながります。参考にするのは「型」（つかみ→結論→やり方）までにして、中身は自分の経験や確認した情報で作ります。

AIに「〇〇さんの動画みたいに」と頼むのも避けます。特定の人の話し方や決めぜりふをまねした台本は作りません。

## 11｜台本と権利の関係

台本そのものも、書いた人の著作物になりえます。自分で書いた台本は自分のものですが、次の場合は注意します。

- **AIで作った台本**：使ったAIサービスの規約で、作った文章を商用で使えるかを確認します。多くのサービスは利用者が使えるとしていますが、条件はサービスごとに違います。
- **人から依頼されて書いた台本**：納品したあと、台本の権利がどちらにあるかを先に決めておきます。決めていないと、ほかの動画に使い回せるかでもめることがあります。
- **台本に引用を入れる場合**：本や記事の文章を紹介するときは、引用の範囲にとどめ、出典を示します。長く写したり、紹介が主で自分の話が少なかったりすると、引用と認められにくくなります。
- **出演者のセリフ**：ほかの人に話してもらう台本は、その人にも内容を確認してもらい、公開の範囲を伝えます。

```text
台本【】の中で、他人の文章・データ・発言を使っている箇所を抜き出して。引用として扱うか、自分の言葉に直すか、出典をどう示すかの案を付けて。
```

## 12｜よくある質問

**Q. 台本どおりに話すと棒読みになります。**  
A. 一字一句覚えなくて大丈夫です。骨組み台本を見ながら、自分の言葉で話すほうが自然になります。2列台本は、撮り忘れを防ぐための表として使いましょう。

**Q. AIに台本を全部書いてもらってもいいですか？**  
A. たたき台としては便利です。ただし事実確認と、自分の経験や意見を入れる部分は人がやります。AIだけで作った台本は、ほかの人の動画と似た内容になりやすいからです。

## 13｜長さ違いの版を作る

同じテーマで、15秒版と3分版を作っておくと、いろいろな場所で使えます。

- **15秒版**：つかみ（3秒）＋結論（7秒）＋次の行動（5秒）。やり方は1つだけか、省略
- **3分版**：やり方を5つまで増やし、それぞれに理由と例を足す。結論は変えない

```text
60秒の台本【】を、15秒版と3分版に作り替えて。結論は変えないで、削った部分・足した部分と理由を表にして。足す内容に事実が含まれる場合は「要確認」と付けて。
```

## 14｜見本で通し練習：やり方1つ目を書くまで

付属の `035-script-table.csv` の15〜27秒の行を例にします。

1. **骨組み**：「やり方1：卵＋野菜の残り＝炒めもの」
2. **話す言葉**：「1つ目は、卵と残りの野菜を炒めるだけ。」（話し言葉、1文が短い）
3. **映す映像**：冷蔵庫から野菜を出す手元 → フライパンで炒める手元
4. **画面の文字**：「卵＋野菜＝炒めもの」（10文字）
5. **確認**：「卵にはしっかり火を通す」は安全に関わるので、確認できる言い方にして「要確認」を付けておきます。加熱時間の数字は、確認できるまで入れません。
6. **時間**：話す言葉は約30文字で6秒前後。映像と合わせて12秒の枠に入ります。

## 15｜自動化と収益化（第3段階）

- **固定する作業**：見る人の整理→骨組み→つかみ3案→2列台本→事実確認の抜き出し→時間の計算→長さ違いの版。Cの8プロンプトを順に使うと、テーマが変わっても同じ質で台本が作れます。
- **人がやる作業**：事実確認、話し言葉の最終チェック、まねしすぎの点検。
- **仕事にする場合**：撮影はできるが台本づくりが苦手な人（店舗、講師、YouTuber）から、台本だけを請け負う方法があります。事実確認の責任の範囲（依頼主の商品情報は依頼主が確認する、など）を先に決めます。

依頼数や再生数・収益を保証しない教材です。

## 16｜課題（3段階）

1. **練習**：付属の2列台本を読み、別のテーマで骨組み台本を作る（合格：4部分・合計60秒前後）
2. **実用品**：2列台本と事実確認リストを作る（合格：話す言葉と映像が対応し、要確認がすべて解決）
3. **公開想定**：15秒版・3分版と公開前チェックをそろえる（合格：全項目に印と確認日）

## 17｜よくある失敗と直し方

1. **結論が最後まで出てこない**：結論を5〜15秒に移す。
2. **やり方が多すぎる**：60秒なら3つまでに絞る。
3. **してほしいことが多い**：1つに絞る。
4. **つかみで約束したことに答えない**：動画の中で必ず答える。
5. **AIが作った数字をそのまま使う**：確認できるまで入れない。
6. **書き言葉のままで話しにくい**：声に出して読み、言い換える。
7. **話す言葉と映像がずれる**：2列台本で並べて確認する。
8. **長すぎて60秒に入らない**：1分300文字を目安に削る。
9. **人気動画の言い回しをそのまま使う**：型だけ参考にし、中身は自分の言葉にする。
10. **安全に関わる情報があいまい**：確認できる範囲の言い方にする。
11. **画面の文字が多すぎる**：12文字以内に絞る。
12. **台本どおりに話そうとして固くなる**：骨組みだけ見て、自分の言葉で話してもよい。
