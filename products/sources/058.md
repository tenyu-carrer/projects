# 058-A｜10分体験：プロフィール文を「誰に・何を・どうすれば」で書き直す

**状態：初稿／紙上演習。実際のプロフィール変更は未検証**

SNSのプロフィールは、初めて来た人が「この人は誰で、何をしていて、自分に関係あるか」を数秒で決める場所です。今のプロフィール文を、AIで3つの要素に分けて書き直してみます。

```text
SNSのプロフィール文を書き直して。今の文【例：犬と猫が大好き🐶🐱 毎日のんびり更新中】。
本当のこと【例：東京都の〇〇区で出張ペットシッターをしている。犬と猫の両方を預かる。】
①誰に向けたアカウントか ②何が分かる・頼めるか ③次に何をすればいいか（リンク・DMなど）
の3つが入った案を、150文字以内で3つ作って。本当のことに書かれていない実績や数字は入れないで。
```

完成条件：3つの要素が入り、書いてあることがすべて本当で、自分で説明できるプロフィール文が1つできていること。

# 058-D｜AIでSNSプロフィールを改善する方法

**状態：初稿／プロフィールの部品図・変更前後の表CSV付き。実際のプロフィール変更・反応は未検証**  
対象：SNSを始めたが、プロフィールに何を書けばよいか分からない、何となく書いたままにしている初心者｜所要：約2〜4時間（プロフィールの全部品を直すまで）｜更新日：2026-11-01  
前提：041〜047のどれか1つのSNS講座（先に読んでも後でもよい）。追加課金、有料API、フォロワーを増やすサービスの利用は行いません。

## 1｜到達点と完成物

この講座のゴールは、**見てほしい人を1つに決め、その人が知りたいことに答えるプロフィールを、本当のことだけで作り、リンク先と食い違いがない状態にする**ことです。

完成物は、①設計シート、②見てほしい人が知りたいことのリスト、③根拠つきの強みの表、④名前・プロフィール文・リンク・ハイライトの改善案、⑤言い過ぎと個人情報の点検記録、⑥リンク先との食い違いの点検記録、⑦公開前チェック記録の7点です。

付属見本は、架空の「ひだまりペットシッター（出張ペットシッター）」のプロフィールの部品図と、直す前後の表です。実在のアカウントや、変更による数字の変化ではありません。

**完成条件：** プロフィールのすべての部品に役割があり、書かれた事実すべてに根拠があり、確かめられない言葉と個人情報がなく、リンク先と料金・地域・受付時間が一致している。

## 2｜この講座で使う言葉

- **プロフィール**：SNSのアカウントの自己紹介の場所。名前、アイコン、プロフィール文、リンクなどでできています。
- **プロフィール文（自己紹介文）**：アカウントの説明。InstagramやThreadsでは150文字前後が上限の目安です（上限は変わることがあるので画面で確認）。
- **ハイライト／固定投稿**：プロフィールの近くにずっと表示しておける投稿。よくある質問や料金の案内に使えます。
- **プロアカウント**：Instagramでお店や発信者向けの機能（数字の分析など）が使える設定。
- **根拠**：書いたことが本当だと示せるもの（資格証、登録の書類、記録など）。

## 3｜なぜプロフィールが大切か

投稿を見て「いいな」と思った人は、次にプロフィールを見に来ます。そこで数秒のうちに、

- この人（お店）は誰か
- 自分に関係があるか
- 次に何をすればいいか

が分からないと、そのまま離れてしまいます。プロフィールは、投稿とお問い合わせをつなぐ「お店の入口の看板」です。

## 4｜見てほしい人を1つに絞る

```text
アカウントの内容【】と見てほしい人【】から、その人がプロフィールで知りたいことを5つ挙げて。大事な順に並べて。
```

「誰にでも」向けたプロフィールは、誰にも刺さりません。見本では「共働きで、旅行や出張のときに犬や猫を家で見てほしい人」に絞りました。その人が知りたいのは、対応する地域、犬と猫のどちらに対応するか、料金の目安、予約の方法、安心できる理由です。

## 5｜本当の強みを集める

```text
自分についての本当のこと【箇条書き】から、プロフィールに使える強みを3つ選んで。それぞれ、根拠になる書類や記録が必要かどうかも書いて。書かれていない実績は足さないで。
```

AIは、頼んでいないのに「実績多数」「満足度98%」のような言葉を足すことがあります。**自分が示せないことは、すべて消します。**

| 強みの例（架空） | 根拠 |
|---|---|
| 犬と猫の両方に対応 | サービス内容の表 |
| 動物を扱う仕事の登録をしている | 登録の書類（番号を載せる場合は正確に） |
| 初回は無料で顔合わせ | 料金表 |

ペットシッターのように動物を預かる仕事は、第一種動物取扱業の登録や、広告の表示のルールの対象になる場合があります（環境省のページで確認）。自分の仕事に、表示が決められている情報がないかを確かめます。

## 6｜名前の欄を整える

```text
名前の欄【】を、検索されやすく分かりやすい形に3案。「屋号＋何をしているか」の形で、20文字前後で。
```

Instagramでは、ユーザーネーム（@から始まる英数字）とは別に「名前」の欄があり、検索で見つかる手がかりになります。「ひだまり｜出張ペットシッター〇〇区」のように、屋号と何をしているかを入れます。地域名は、活動している範囲だけにします。

## 7｜プロフィール文を書く

```text
プロフィール文の案を3つ作って。誰に・何が分かる/頼めるか・次の行動、の3つを入れて【150】文字以内。本当のこと【】以外は書かないで。
```

書き方のコツ：

- 1行目に「誰に・何を」を書く（ここだけ読まれることが多い）
- 2〜3行目に、知りたいこと（地域・対応・料金の目安）を短く
- 最後の行に、次の行動を1つ（「予約・空き状況はリンクから」）
- 絵文字は、行の目印程度に。多すぎると読みにくい

## 8｜言い過ぎと根拠のない言葉を消す

```text
プロフィール文【】を点検して。確かめられない言葉（No.1・必ず・絶対・業界初など）、根拠のない数字、個人情報（自宅の住所・家族の名前）がないか、直した案と一緒に出して。
```

商品やサービスを実際よりよく見せる表示は、景品表示法で問題になることがあります（消費者庁のページで確認）。プロフィールも広告の一部と考え、次のものは書きません。

- 「地域No.1」「業界初」など、調べた根拠がない一番
- 「必ず」「絶対に安心」など、保証できない言葉
- 実際より多いフォロワー数、お客さまの数、経験年数
- 持っていない資格、受けていない賞

## 9｜アイコンを決める

アイコンは小さな丸で表示されます。

- お店ならロゴ、個人なら顔か、活動が分かる写真
- 小さくしても何か分かる、文字の少ないもの
- 他人の写真や、ほかのお店のロゴに似せたものは使わない（権利の問題）
- 人が写る写真は、写っている人の許可を取る

## 10｜リンクを1つに絞る

プロフィールのリンクは、行ってほしい場所を1つにします。予約ページ、LINE公式アカウント、お店のサイトなど、いくつも並べると迷わせます。

```text
リンク先のページ【内容】とプロフィール文【】で、書いてあることが食い違っている所を探して。料金・地域・受付時間を特に見て。
```

料金や受付時間を変えたら、プロフィールとリンク先の両方を同じ日に直します。

## 11｜ハイライト・固定投稿で質問に先に答える

```text
ハイライト（または固定投稿）に入れる内容を5つ提案して。見てほしい人【】が、問い合わせる前に知りたい順に。
```

見本では「はじめての方へ」「料金」「対応地域」「よくある質問」「お客さまの声」の5つにしました。**お客さまの声を載せるときは、本人の許可を取り、作り話の声は絶対に載せません。** 名前や家の様子が分かる写真も載せません。

## 12｜個人情報とアカウントを守る

- 自宅で仕事をしている場合、住所はプロフィールに書かない（地域名まで）
- 家族や子どもの名前・学校が分かることを書かない
- 電話番号を載せるなら、仕事用のものにする
- 2段階認証を設定し、パスワードを使い回さない
- 複数人で使うなら、パスワードを共有せず、各サービスの管理者の機能を使う

## 13｜プロアカウントの設定と数字の見方

Instagramは、プロアカウントに切り替えると、プロフィールのアクセス数やリンクのクリック数などの数字が見られるようになります（切り替えの手順と条件はInstagramヘルプで確認）。

```text
1か月のプロフィールのアクセスとリンクのクリック【数字】から、次に1つだけ変えることを提案して。数字が少なすぎる場合はそう書いて。
```

変えるのは1つずつにします。一度に全部変えると、何が効いたか分かりません。

## 14｜ほかのSNSのプロフィールと揃える

Threads、Facebook、TikTokなど、複数のSNSを使っている場合は、屋号・アイコン・対応地域・リンク先を揃えます。文の長さや雰囲気は、それぞれのSNSに合わせて変えてかまいません。ただし、事実（料金・地域・資格）はどこでも同じにします。

## 15｜見本で通し練習：プロフィール文を仕上げるまで

付属の `058-profile-before-after.csv` を使います。

1. **直す前**：「犬と猫が大好き🐶🐱 毎日のんびり更新中」（誰に・何を・次の行動がない）。
2. **見てほしい人**：旅行や出張のときに、家で犬や猫を見てほしい人。
3. **強みと根拠**：犬と猫の両方に対応（サービス表）、初回の顔合わせは無料（料金表）。登録番号は書類と1字ずつ照らし合わせる設定です。
4. **案づくり**：Cのプロンプトで3案を作り、「地域で一番」という言葉が入った案は消しました。
5. **食い違いの点検**：リンク先の予約ページと、対応地域・受付時間が同じかを確かめます。
6. **確認**：家族に読んでもらい、「何を頼めるか分かるか」を聞いてから変更します。

## 16｜よくある質問

**Q. 趣味のアカウントでもプロフィールを直したほうがいいですか？**  
A. 見てほしい人がいるなら、直す価値があります。お店ほど細かくなくても、「何について投稿しているか」が1行で分かるだけで違います。

**Q. 実績がまだありません。**  
A. 実績がなくても大丈夫です。「何ができるか」「どんな人に向けているか」を正直に書きます。実績は、本当にできてから足せばよいのです。

**Q. どのくらいの頻度で見直せばいいですか？**  
A. 料金・地域・受付時間が変わったときはすぐに、それ以外は月に1回程度が目安です。

## 17｜自動化と収益化（第3段階）

- **固定する作業**：知りたいこと→強みと根拠→文の案→言い過ぎの点検→名前→ハイライト→食い違いの点検→数字の見直し。Cの8プロンプトを、月に1回の見直しの日に使います。
- **人がやる作業**：根拠の書類を確かめる、最終的な言葉を選ぶ、実際の変更、権限の管理。
- **仕事にする場合**：お店のSNSプロフィールの見直しを手伝う仕事が考えられます。その場合、相手の根拠の書類を見せてもらい、確かめられないことは書かない約束を最初にします。アカウントのパスワードは預からず、変更はお店の人が行うか、管理者の追加で受けます。

フォロワー数・問い合わせ数・売上を保証しない教材です。

## 18｜課題（3段階）

1. **練習**：今のプロフィール文を「誰に・何を・次の行動」に分けて、足りないものを書き出す（合格：3つの要素の有無が書けている）
2. **実用品**：根拠つきの強みの表と、プロフィール文の3案を作る（合格：全部の事実に根拠がある）
3. **公開想定**：名前・文・アイコン・リンク・ハイライトを直し、リンク先との食い違いがない状態にする（合格：全項目に確認者と確認日）

## 19｜よくある失敗と直し方

1. **誰に向けたか分からない**：1行目に「誰に・何を」を書く。
2. **AIが足した実績をそのまま使う**：根拠のないものは消す。
3. **「No.1」「必ず」を書く**：具体的で本当のことに置き換える。
4. **フォロワーや経験年数を多めに書く**：正確な数字か、書かない。
5. **リンクをたくさん並べる**：1つに絞る。
6. **リンク先と料金が違う**：同じ日に両方直す。
7. **自宅の住所を書く**：地域名までにする。
8. **作り話のお客さまの声を載せる**：本人の許可がある本当の声だけ。
9. **他人の写真やロゴに似せたアイコン**：自分の写真やロゴを使う。
10. **絵文字が多すぎて読めない**：行の目印程度にする。
11. **一度に全部変えて効果が分からない**：1つずつ変える。
12. **SNSごとに料金や地域が違う**：事実は全部のSNSで揃える。
13. **登録が必要な仕事なのに表示を確かめない**：自分の仕事のルールを公式ページで確かめる。
14. **作ったまま見直さない**：月に1回見直す。

## 20｜公開前チェック、公式情報、限界

- [ ] 1行目に「誰に・何を」がある
- [ ] 書いた事実すべてに根拠がある
- [ ] 確かめられない言葉（No.1・必ず・絶対）がない
- [ ] フォロワー数・経験年数・資格を正確に書いた
- [ ] 自宅の住所や家族の情報がない
- [ ] 次の行動が1つで、リンクが開ける
- [ ] リンク先と料金・地域・受付時間が一致している
- [ ] お客さまの声は本人の許可がある本当のもの
- [ ] アイコンや写真の権利と、写っている人の許可を確かめた
- [ ] 仕事に決められた表示（登録番号など）を確かめた
- [ ] 2段階認証を設定した

確認した公式情報：[Instagram ヘルプセンター](https://help.instagram.com/)、[Instagramヘルプ「プロアカウントを設定して、ビジネスツールやクリエイターツール、管理機能にアクセスする」](https://help.instagram.com/502981923235522)、[消費者庁「景品表示法」](https://www.caa.go.jp/policies/policy/representation/fair_labeling/)、[消費者庁「ステルスマーケティング」](https://www.caa.go.jp/policies/policy/representation/fair_labeling/stealth_marketing/)、[環境省「第一種動物取扱業者の規制」](https://www.env.go.jp/nature/dobutsu/aigo/1_law/trader.html)（確認日：2026-11-01）。画面や文字数の上限は変わるため、変更する時点で各サービスの画面とヘルプを確認してください。

本教材は架空のアカウントの部品図と表のみで、実際のプロフィール変更や、それによる数字の変化を検証していません。フォロワー数・問い合わせ数・売上を保証しない教材です。表示のルールに迷ったら、専門家や所管の窓口に確認してください。

# 058-D｜SNSプロフィール改善 公開前チェック

- [ ] 1行目に誰に・何を
- [ ] 全部の事実に根拠
- [ ] No.1・必ず・絶対なし
- [ ] 数字・資格が正確
- [ ] 自宅住所・家族の情報なし
- [ ] 次の行動が1つ・リンクが開く
- [ ] リンク先と料金・地域・時間が一致
- [ ] お客さまの声は許可ある本当のもの
- [ ] アイコン・写真の権利と許可
- [ ] 仕事に決められた表示を確認
- [ ] 2段階認証

根拠のない実績、言い過ぎ、個人情報があれば変更を止めて直す。フォロワー・問い合わせを保証しない。
