# 029-A｜10分体験：15秒アニメの「動き表」を作る

**状態：初稿／紙上演習。実アニメーション制作・外部AIは未検証**

アニメーション動画は、いきなり動かすより「何を・いつ・どう動かすか」を表にすると失敗が減ります。架空のお題「朝の水やりを忘れないで」の15秒アニメで練習します。

```text
15秒のアニメーション動画【テーマ：朝の水やりを忘れないで】の動き表を作って。
3場面に分け、各場面に「秒数」「画面に出る物」「動き（入る・揺れる・消えるなど）」「文字」を書いて。
人や動物の顔は使わず、図形とアイコンだけで作れる内容にして。
```

完成条件：3場面の合計が15秒で、各場面に「出る物・動き・文字」がそろっていること。動きは1場面に2つまでにすると見やすくなります。

# 029-B｜15秒アニメ見本の読み解き

**状態：架空テーマの動き設計見本。実アニメーション・音声・外部AIは未使用**

`029-motion-board.png` は、架空の「朝の水やりリマインド」15秒アニメを3場面に分けた絵コンテ兼タイムラインです。`029-motion-sheet.csv` は、各要素が何秒から何秒まで、どんな動きで出入りするかを1行ずつ記録しています。

読むときのポイント：

1. **動きは意味のためにある**：じょうろが傾く動きは「水やり」を伝えるため。意味のない回転や点滅は入れていません。
2. **文字は動きが止まってから読ませる**：文字が動いている間は読みにくいので、入ったら1.5秒以上止めています。
3. **最後の2秒は静止**：最後のメッセージは動かさず、読み終わる時間を確保しています。

この見本は設計の考え方を示すもので、完成アニメーションや視聴データではありません。

# 029-D｜AIでアニメーション動画を作る方法

**状態：初稿／動き設計図・動き表CSV付き。実アニメーション制作・外部AI・各SNSの実投稿は未検証**  
対象：撮影なしで、図形やイラストを動かす短い動画を作りたい初心者｜所要：約4〜6時間｜更新日：2026-10-31  
前提：001のCanva基礎、007のイラスト、021の動画編集基礎。追加課金、有料API、素材購入は行いません。

## 1｜到達点と完成物

この講座のゴールは、**伝えたいこと1つを、15秒のアニメーション動画にして、6秒・30秒の版にも作り替えられるようになる**ことです。

完成物は、①設計シート、②3場面の構成表、③動き表（CSV）、④15秒の書き出し動画、⑤6秒版・30秒版の構成案、⑥公開前チェック記録の6点です。

付属見本は、架空の「朝の水やりリマインド」15秒アニメの絵コンテ兼タイムライン図と動き表です。実際の動画ファイルや再生数はありません。

**完成条件：** 15秒の動画で、文字が読み終わる時間があり、急な点滅がなく、使った素材と音の利用条件が記録されている。

## 2｜この講座で使う言葉

- **キーフレーム**：「この秒数のとき、ここにある」という目印。2つ打つと、その間を自動で動かしてくれます。
- **フェード**：だんだん現れる・消える動き。
- **縦横比**：画面の縦と横の比率。縦型ショートは9:16、横長の動画は16:9。
- **コントラスト**：文字と背景の明るさや色の差。差が大きいほど読みやすくなります。
- **書き出し**：編集中のデータを、MP4などの動画ファイルにすること。

## 3｜アニメーション動画の3つの作り方

初心者が選べる作り方は大きく3つあります。

1. **テンプレートの動きを使う**：Canvaなどのデザインツールで、文字や図形に用意された動き（フェード、スライドなど）を付ける。一番かんたんで、まずはここから始めます。
2. **動画編集ソフトでキーフレームを打つ**：「何秒にどこにあるか」を指定して動かす。細かい動きができますが、操作は少し増えます。
3. **AIで動画を生成する**：文章や画像から動きを作るAIサービス。きれいな映像が出ることもありますが、思い通りにならないこと、文字が崩れること、利用条件がサービスごとに違うことに注意が必要です。

この講座では1を中心に、2を少しだけ使います。3を使う場合は、生成物の商用利用の条件をサービスの公式規約で確認し、確認できなければ販売物には使いません。

## 4｜伝えたいことを1文にする

アニメーションは動きが目立つぶん、伝えたいことがぼやけやすい形式です。最初に1文で決めます。

- よい例：「朝のうちに水やりをすると、植物が元気に育ちます」
- 悪い例：「植物の育て方のいろいろ」（広すぎて15秒に入らない）

```text
テーマ【】から、15秒で伝えられる「伝えたいこと」を1文で3案出して。見る人が見終わったあとにする行動を1つ含めて。
```

## 5｜3場面の構成を作る

15秒なら3場面がちょうどよい長さです。基本の流れは「気づき → 理由・方法 → 行動のひと言」です。

| 場面 | 秒数 | 役割 | 見本での中身 |
|---|---|---|---|
| 1 | 0〜5秒 | 気づき | 朝日と植木鉢。「水やり、忘れてない？」 |
| 2 | 5〜11秒 | 方法 | じょうろが傾き、水が落ちる。「朝のうちに、たっぷり」 |
| 3 | 11〜15秒 | 行動 | 芽が伸びる。「今日の水やり、済ませよう」（最後2秒は静止） |

## 6｜動きを決める（1場面2つまで）

動きが多いと、何を見ればよいか分からなくなります。1場面に2つまでと決めておくと、自然にまとまります。

- **フェード**：ふわっと出る・消える。落ち着いた印象
- **スライド**：横や下から入る。順番を示すのに便利
- **拡大**：大事なものを強調する
- **揺れ**：注意を引く。やりすぎると落ち着かない
- **描画**：線が描かれていく。手順や矢印に向く

```text
構成表【】の各場面に、動きを2つまで選んで。その動きで何が伝わるかを1行で説明し、文字が動いている時間が1.5秒以上続かないようにして。
```

## 7｜文字を読ませる時間を確保する

アニメーションでよくある失敗は、文字が読めないうちに次の場面へ行ってしまうことです。日本語は1秒あたり4〜6文字が目安です。12文字なら2〜3秒は静止させます。

```text
各場面の文字【】について、文字数と、読むのに必要な静止時間を計算して表にして。足りない場面は文字を短くする案も出して。
```

字幕やテロップの色は、背景との差（コントラスト）がはっきりしたものにします。薄い黄色の背景に白文字のような組み合わせは避けます。

## 8｜素材を用意する（権利に注意）

素材は、自分で描いた図形、ツールの素材ライブラリ、フリー素材などを使います。どの場合も「商用で使えるか」「加工してよいか」「クレジット表記が必要か」を確認し、設計シートに書きます。

- 実在のキャラクター、有名なロゴ、他人のイラストに似せたものは作らない
- AIで作った絵も、似せる指示（「〇〇風に」など）は使わない
- 人の顔写真を動かす場合は、本人の同意が必要

```text
テーマ【】を表すアイコンと図形の案を5つ。実在のキャラクター・ロゴ・作家の画風に似せないこと。各案を図形の組み合わせで説明して。
```

## 9｜実際に動かす（Canvaの場合の流れ）

画面の名前は更新で変わることがあるため、ここでは流れで説明します。

1. 動画用のデザイン（縦9:16など）を新しく作る
2. 場面ごとにページを分け、各ページの長さを構成表の秒数に合わせる
3. 図形・アイコン・文字を配置する
4. 動かしたい要素を選び、「アニメーション」の項目から動きを選ぶ
5. 文字の動きは「入る」だけにして、出るときは場面の切り替えにまかせる
6. 全ページを通して再生し、文字が読めるか、動きが多すぎないか確認する
7. MP4で書き出す

完了サイン：書き出した動画をスマホで再生し、音を消しても内容が分かること。

## 10｜音を付ける場合

BGMや効果音は雰囲気を作りますが、利用条件がいちばん問題になりやすい部分です。ツールに入っている音源でも、SNS投稿・広告・販売物で使える範囲が違うことがあります。ナレーションを付ける場合は033で学びます。音がなくても伝わる作りにしておくと、音を消して見る人にも届きます。

## 11｜見やすさと安全の確認

画面全体が速く明滅する表現や、赤と青が激しく入れ替わる表現は、光に敏感な人の体調に影響することがあります。動きは「ゆっくり・少なく」が基本です。

```text
完成アニメの場面説明【】から、点滅、急な拡大、画面全体の明るさの急変、速すぎる動きを点検して。危ない箇所の秒数と、落ち着いた代案を出して。
```

## 12｜見本で通し練習：場面2を作るまで

付属の `029-motion-sheet.csv` の場面2（5〜11秒）を例に、1場面を作る流れを確認します。

1. **役割を確認**：場面2の役割は「方法」です。伝えるのは「朝のうちに、たっぷり」の1点だけにします。
2. **出る物を決める**：じょうろと水滴の2つ。植木鉢は場面1から続けて置いたままにし、新しく出す物を増やしません。
3. **動きを2つ選ぶ**：じょうろは「右からスライド」、水滴は「描画」。6.5秒でじょうろを少し傾けるのは、スライドの続きとして扱い、別の動きを増やしません。
4. **文字の時間を計算**：「朝のうちに、たっぷり」は10文字なので、読むのに約2〜3秒必要です。8.0秒に入れて11.0秒まで静止させ、3秒確保します。
5. **安全の確認**：水滴をキラキラ点滅させたくなりますが、点滅は使わず、描画で落ちる表現にします。
6. **再生して確認**：場面1から通して再生し、場面2に入った瞬間に何を見ればよいか迷わないかを確かめます。迷う場合は、じょうろが入りきってから水滴を出すように時間をずらします。

```text
動き表【029-motion-sheet.csvの内容】を読み、各場面で「新しく出る物」「動きの数」「文字の静止秒数」を数えて。
1場面に動きが3つ以上ある、静止が2秒未満、という箇所があれば直し方を提案して。
```

この順番を場面1・3でも繰り返すと、15秒の動画がそろいます。うまくいかない場面は、動きを1つ減らすところから見直すのが近道です。

## 13｜6秒版と30秒版に作り替える

同じ内容でも、使う場所によって合う長さが違います。広告枠やストーリーズでは6秒前後、説明を入れたいときは30秒前後が使いやすい長さです。15秒版を基準にして、伝えたいこと1文は変えずに作り替えます。

- **6秒版**：場面を2つにします。「気づき」を2秒、「行動のひと言」を4秒。方法の場面は削り、文字は8文字前後まで短くします。動きは全体で2〜3個にします。
- **30秒版**：場面を4〜5つにします。15秒版の「方法」を2場面に分けて、理由（朝は土が乾きにくい、など確認できた事実だけ）を足します。新しい主張は増やしません。

```text
15秒版の構成表【】を、6秒版（2場面）と30秒版（4〜5場面）に作り替えて。
伝えたいこと1文は変えない。削った場面・足した場面と、その理由を表にして。足す内容に事実が含まれる場合は「要確認」と付けて。
```

長さ違いの版も、それぞれ書き出してから全編再生し、文字の静止時間を確認します。6秒版は特に文字が読み切れないことが多いので、文字を減らすのが先です。

## 14｜自動化と収益化（第3段階）

1本作れたら、同じ型を使い回せます。

- **型にする**：3場面・15秒の構成表と動き表をテンプレートとして保存し、文字とアイコンだけ差し替える。
- **プロンプトを固定する**：Cの8本で「伝えたいこと→構成→動き→文字の秒数→安全確認」を毎回同じ順で回す。
- **仕事にする場合**：店舗のお知らせ動画、教室の告知、SNSの季節のあいさつなど、短いアニメ動画の制作を引き受ける方法があります。素材と音の利用条件を依頼主に説明し、納品物に記録を付けます。

売上や依頼数は保証しない教材です。料金は作業時間・修正回数・素材費から考えます。

## 15｜課題（3段階）

1. **練習**：付属の動き表を見ながら、同じ構成で別テーマ（例：「寝る前にスマホを置こう」）の構成表を作る（合格：3場面・合計15秒・文字の静止時間あり）
2. **実用品**：15秒動画を1本書き出す（合格：スマホで音なしでも内容が分かる）
3. **公開想定**：6秒版・30秒版の構成と、投稿文、公開前チェックをそろえる（合格：全項目に印と確認日）

## 16｜よくある失敗と直し方

1. **動きが多くて落ち着かない**：1場面2つまでに減らす。
2. **文字が読めない**：文字を短くし、静止時間を増やす。
3. **最後の一言がすぐ消える**：最後の2秒は静止させる。
4. **伝えたいことがぼやける**：1文に戻り、関係ない場面を削る。
5. **素材の利用条件が不明**：確認できるまで使わない。差し替える。
6. **有名キャラクターに似てしまう**：図形とアイコンの組み合わせで作り直す。
7. **背景と文字の色が近い**：コントラストのはっきりした組み合わせにする。
8. **点滅が強い**：フェードなどゆっくりした動きにする。
9. **縦横比を間違えて端が切れる**：最初に投稿先の比率で作り直す。
10. **音を消すと意味が分からない**：大事な情報は文字でも見せる。
11. **書き出した動画がカクカクする**：素材を減らし、再度書き出して確認する。
12. **AI生成の映像で文字が崩れる**：文字はあとから編集ソフトで載せる。
