# デザイン部（Canva）運用書

天祐自動化の **CCO（コンテンツ担当取締役）配下のデザイン部** です。画像はすべて Canva で作ります。
今の主な依頼元は Instagram部で、将来は WordPress・note のアイキャッチなども担当します。

## Instagram部との連携（1投稿の流れ）

```
Instagram部 課長（企画・文面）
   │  デザイン依頼（ブリーフ）: 画像に入れる文字、雰囲気、使うひな形
   ▼
デザイン部 担当デザイナー（Canva）
   │  ひな形を複製 → 文字を差し替え → はみ出し確認 → 担当フォルダに保存 → JPG 書き出し
   ▼
品質管理部（チェック）
   │  validate.mjs（文字数・画像形式）＋ 見た目の確認（文字切れ・重なり・誤字）
   ▼
Instagram部（投稿）
      指示投稿 or 毎日投稿（GitHub Actions）
```

代行時は、1回の作業の中で Claude が役割を順に切り替えて行う。役割を分けるのは、
「文面の良し悪し」と「見た目の良し悪し」を別々の観点で確認するため。

## Canva のフォルダ（ID は `design/canva.json`）

| フォルダ | 中身 |
| --- | --- |
| 天祐自動化 デザイン部 | すべての親フォルダ |
| └ 00 ひな形（編集禁止・複製して使う） | 各アカウントのひな形（`content/<account>/canva.json` の `master`） |
| └ Instagram 占い / 前向きな言葉 / 心理学の言葉 | 日々の投稿デザイン。複製したらすぐここへ移動する |

## ルール

- **ひな形は編集しない。** 必ず `copy-design` で複製してから編集する。ひな形を変えるときはオーナーの確認をとり、デザイン部長の作業として行う
- 複製したデザインは、担当アカウントのフォルダへ `move-item-to-folder` で移動し、タイトルを `<account> YYYY-MM-DD` にする
- 書き出しは JPG・幅 1080px・品質 90（Instagram の推奨 1080×1350）
- 文字数は各アカウントの `canva.json` の `textFields` に従う。はみ出したら文字枠を広げるか文章を短くする
- 投稿データには `canvaDesignId` を必ず残す（後から Canva で直せるように）

## デザイン依頼（ブリーフ）の書き方

投稿データ（`posts/*.json`）の `brief` に残す。

```json
"brief": {
  "template": "master",
  "texts": { "日付": "9月23日（水）", "星座": "てんびん座", "メッセージ": "…", "ラッキー": "…" },
  "mood": "秋分の日。落ち着いたバランス感",
  "designer": "セイラ"
}
```
