# 運用方針書：@tenyu.worklife（ワークライフ課）

投稿を作る人（Claude を含む）は、毎回この方針書に従います。2026-09-27 オーナー指示で作成。

## コンセプト（オーナー指示）
- **前向きな発信**。1日ひとこと
- 仕事・家事・育児・プライベート全般で、**ちゃんと「ためになる」**内容にする（気休めだけで終わらせない）
- 有名人の言葉も使ってよい。ただし**本人の発言と確認できるものだけ**を、発言者名つきで使う。出典があやしいものは使わず、オリジナルの言葉にする
- 口調: やさしく、具体的。説教くさくしない。「今日ひとつだけ試せること」を必ず添える

## 曜日テーマ

| 曜日 | テーマ | 例 |
| --- | --- | --- |
| 月 | 仕事（始める・段取り） | 朝いちばんに「今日やらないこと」を1つ決める |
| 火 | 家事（ラクにする工夫） | 完璧より「8割でOK」を決める |
| 水 | 育児・家族 | 子どもの話を最後まで聞く日を作る |
| 木 | 人間関係・感謝 | ありがとうを具体的に1つ伝える |
| 金 | 自分をねぎらう | 1週間でできたことを3つ書き出す |
| 土 | 休む・楽しむ | 予定を入れない時間を1時間つくる |
| 日 | 来週への準備と希望 | 来週の楽しみを1つ決める |

## 画像（Canva・1080×1350）
- 1枚目：今日のひとこと（20〜40文字）。有名人の言葉の場合は発言者名を小さく入れる
- 余白を広く、明るく落ち着いた色

## キャプションの型
```
（今日のひとこと）

（なぜ大事か・背景を2〜3行）

▶ 今日ひとつだけ試すなら
（具体的な小さな行動を1つ）

保存して、疲れた日に見返してね🌿
```
- ハッシュタグは5〜10個。固定：前向きな言葉 / ワークライフバランス / 今日のひとこと

## 禁止事項
- 「がんばれ」の押しつけ、弱っている人・親・働き方を否定する表現
- 宗教・政治、医療・投資の助言
- 出典が確認できない名言、発言者の取り違え
- 特定の会社・個人の批判
