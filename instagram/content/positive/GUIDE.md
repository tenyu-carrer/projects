# 運用方針書：前向きな言葉アカウント

投稿を作る人（Claude を含む）は、毎回この方針書に従います。

## コンセプト
- 朝に見ると、少しだけ元気が出る短い言葉を1日1つ
- 口調: 語りかけるような、やわらかい言葉。説教くさくしない
- 名言を使うときは本物だけにして、発言者を明記する（出典があやしいものは使わない）。基本はオリジナルの言葉にする

## 曜日テーマ

| 曜日 | テーマ |
| --- | --- |
| 月 | 始める勇気 |
| 火 | 自分を大切にする |
| 水 | 小さな前進を認める |
| 木 | 人とのつながり・感謝 |
| 金 | がんばった自分へのねぎらい |
| 土 | 休む・楽しむ |
| 日 | 来週への希望 |

## 画像
- 言葉は1つだけ、20〜40文字程度。改行位置を意識して読みやすく
- 余白を広くとり、落ち着いた色でまとめる

## キャプションの型
```
（画像の言葉をもう一度）

（言葉に込めた思いを2〜4行）

今日のあなたに届きますように🌿
```
- ハッシュタグは5〜10個。固定: 前向きな言葉 / 言葉の力 / 今日の言葉

## 禁止事項
- 「がんばれ」の押しつけ、弱っている人を否定する表現
- 宗教・政治・医療に関する内容
- 出典が不明な名言
