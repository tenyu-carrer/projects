# 運用方針書：毎日占いアカウント

投稿を作る人（Claude を含む）は、毎回この方針書に従います。

## コンセプト
- 毎朝ひらくと「今日の自分」がわかる、やさしい星座占い
- 口調: 親しみやすい敬語（「〜してみてね」「〜かも」）。脅したり不安をあおったりしない
- 悪い運勢も「こうすると良くなる」という前向きなアドバイスで締める

## 投稿の型（曜日ローテーション）

| 曜日 | 型 | 内容 |
| --- | --- | --- |
| 月〜土 | **今日の運勢** | 1位の星座と一言メッセージ、ラッキーカラー、ラッキーアイテム |
| 水・土（任意で2枚目以降に追加） | **12星座ランキング** | カルーセルで全星座の順位と一言ずつ |
| 日 | **星座別の傾向と注意** | 「◯◯座の人はこういう傾向があるから気をつけてね」を3〜4星座ずつ |
| 毎月1日 | **今月のいい日** | 新しいことを始める・お金・恋愛・休むのに良い日をカレンダー形式で |

- 1位の星座が同じ週に重ならないようにする（12日で一巡させるのが目安）
- 画像の文字は短く（1枚あたり最大60文字程度）。詳しい説明はキャプションに書く

## キャプションの型
```
【9月24日（木）今日の運勢】
1位は…おひつじ座♈

（2〜4行のメッセージ）

ラッキーカラー：ゴールド
ラッキーアイテム：手帳

保存して、夜に見返してみてね🌙
```
- ハッシュタグは5〜10個。固定: 占い / 今日の運勢 / 星座占い。そのほかは内容に合わせる

## 禁止事項
- 病気・死・事故など、不安をあおる表現
- 特定の星座を強くけなす表現
- 「必ず当たる」「お金が必ず増える」などの断定表現
- 健康や医療、投資についての具体的なアドバイス

## Canva
- ひな形デザイン: `canva.json` の `master` を参照（毎日これを複製し、文字だけ差し替える）
- 書き出しは JPG、1080×1350
