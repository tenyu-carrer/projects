# 天祐AIスキルライブラリ（ローカル試作）

商品マスター180をWebで提供するための、ローカル確認用サイトです。

- `index.html`：商品一覧
- `product.html?id=001`：商品001の教材ページ
- `data/products.json`：商品追加・更新用の共通データ
- `assets/app.js`：一覧、教材表示、プロンプト生成・コピー、学習進捗
- `assets/styles.css`：スマホ・パソコン共通デザイン

## ローカル起動

このフォルダで次を実行します。

```powershell
python -m http.server 4173
```

ブラウザで `http://localhost:4173/` を開きます。

## 現在の範囲

- 商品一覧：固定番号001〜180を表示。未制作は「制作予定」としてロック
- Web教材：001〜005と011。D講座の高密度教材・実ファイルまで制作済みなのは001、002、011。003〜005はWeb試作段階で、D講座は未完成
- 5教材の操作：専用完成見本、入力式プロンプト、ワンクリックコピー、完了チェック、教材別の進捗保存
- 教材の深掘り：対象者、練習課題、完成までの道筋、プロンプト出力例、7工程の判断基準、書き出し条件
- Canva画面案内：商品001は高精細な編集画面例、002〜005は各完成見本を入れた操作画面図を掲載
- 完成見本画像：`assets/examples/` の5点。サイト上でクリック拡大可能
- 表示確認：パソコンとスマホ幅390pxで確認済み
- 商品006〜010：Web化前としてロック表示
- 商品011：高解像度完成見本、A4印刷用PDF、設計シート、プロンプト集、100点検品表を実ファイルで提供
- 商品002：A4ベクターPDF見本、PNG、情報整理シート、6種のプロンプト、100点検品表を提供。架空の開催情報を含む見本のため、実イベントへの配布・印刷には使用不可。QRは非機能の差替え枠
- UTAGE決済・購入者認証：未接続。公開前に別途実装・確認する
