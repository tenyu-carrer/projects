# 068-C｜AIで有料教材を制作する 設計シートとプロンプト

**状態：再利用用初稿／販売の場所の規約・手数料・法令の運用は使う時点で公式ページを確認**

## 設計欄

- 受講者（どんな人が・どんな場面で困っているか）：
- 教材を終えたときにできるようになること（「〜できる」の1文）：
- 受講者がすでに知っていること／知らないこと：
- 形式（PDF・ワークシート・動画・テンプレートなど）と、そう決めた理由：
- 単元の数と、1単元の所要時間：
- 単元ごとの「できるようになること」（1単元に1つ）：
- 単元ごとの演習と合格の目安：
- 見本（架空と明記するか、本人の許可を取った実例か）：
- 教材の中で使う画像・文章・テンプレートの権利：
- AIを使った場所と、自分で確かめた記録：
- 価格と、その価格にした理由：
- 販売の場所（自分のサイト・noteなど）と、規約・手数料を確かめた日：
- 販売ページに書く事業者の表示・返品（キャンセル）の条件：
- 販売後に見直す日と、見る数字（受講者の声・質問・返金の申し出など）：
- 確認者／確認日：

## プロンプト（この順で使います）

```text
私の教材の受講者は【どんな人・どんな場面で困っているか】です。この人が教材を買う前に抱えていそうな悩みを10個、買ったあと「できるようになりたいこと」を10個、分けて出して。想像で数字や統計を作らないで。
```
```text
受講者【】が教材を終えたときに「できるようになること」を、「〜できる」で終わる1文で5案出して。測れない言葉（理解する・意識する・知る）は使わず、本人が見て確かめられる行動にして。
```
```text
教材のゴール【〜できる】から逆算して、単元の並びを作って。1単元には「できるようになること」を1つだけ入れ、前の単元の内容を使って次に進む順にして。単元ごとに所要時間の目安も書いて。全部で【】単元。
```
```text
次の単元【単元名と、できるようになること】について、説明・見本・5〜10分の演習・合格の目安を書いて。見本の人や店は架空にして「架空」と書く。演習は、受講者が自分のことで手を動かせるものにして。
```
```text
次の教材の原稿【原稿】を、受講者の立場で読んで、①分かりにくい言葉、②手順が飛んでいる所、③根拠のない言い切り、④事実を確かめるべき所を、場所を示して表にして。直し方の案も書いて。直すのは私なので、原稿は書き換えないで。
```
```text
次の評価表【068-quality-rubric.csv の項目】で、私の教材【原稿の要約】を採点して。項目ごとに「満たす／足りない／判断できない」と理由を書いて。判断できない所を推測で埋めないで。
```
```text
私の教材【教材名・中身・形式・単元数】の販売ページの見出しと紹介文の案を3つ作って。教材に入っていることだけを書き、効果の約束（必ず・絶対・誰でも・すぐに）、受講者の数や売上の数字、架空の体験談、ほかの人の推薦の言葉は入れないで。
```
```text
次の販売ページの文【文】に、事実と違う・言い過ぎ・根拠を示せない表現がないか点検して。景品表示法の優良誤認・有利誤認に当たりそうな所、「今だけ」「残りわずか」のように事実の確認が要る所に印をつけて、理由を書いて。最終的な判断は私がする。
```
```text
教材を販売して30日たちました。分かっていること【受講者の質問・感想・返金の申し出・つまずいた単元】をもとに、直す単元の順番を決める表を作って。数が少ないときは「まだ判断できない」と書いて。売上の予想はしないで。
```

AIは**案出し・点検・採点の手伝い**に使い、ゴール・中身・価格・販売ページ・公開は自分で決めます。法律や販売の場所の決まりは変わることがあるので、販売の前に公式ページを読みます。
