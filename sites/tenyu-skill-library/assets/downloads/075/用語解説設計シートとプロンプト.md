# 075-C｜AIで専門用語をわかりやすく解説する 設計シートとプロンプト

**状態：再利用用初稿／制度・数字は使う時点で公式ページを確認**

## 設計欄

- 読む人（どんな場面で、その言葉に出会うか）：
- 読む人がすでに知っていること：
- 解説する用語（聞き返された言葉・つまずく言葉から選ぶ）：
- 用語ごとの「ひとこと」：
- 用語ごとの「たとえ」と、その限界：
- 用語ごとの「くわしく」と、確かめた先・日付：
- 解説の中で使わない言葉（さらに難しい言葉）：
- 医療・お金・法律など、資格が要る判断に触れるか：
- 公開する場所（用語集のページ・記事の中・チラシ）：
- 読む人に近い人に読んでもらったか：
- 確認者／確認日：

## プロンプト（この順で使います）

```text
私の仕事は【仕事】で、お客さんは【どんな人】です。お客さんが聞き返しそうな専門用語を20個出して。それぞれに、つまずきそうな理由を1行添えて。
```
```text
次の専門用語【用語】を、【読む人】向けに3段で説明して。①ひとこと（専門用語を使わず1文）、②身近なたとえ（1文）とその限界（1文）、③くわしく（3文まで）。制度や数字の細かい決まりは「公式ページで確認」と書いて、推測で書かないで。
```
```text
次の用語の説明【説明】の中で、さらに難しい言葉（説明の中の専門用語・カタカナ語・漢字の多い言葉）を探して、言いかえの案を出して。
```
```text
次の用語の説明【説明】が、正確さを失っていないか点検して。分かりやすくするために言い過ぎた所、たとえで意味がずれた所、例外を書いていない所を表にして。直し方の案も書いて。
```
```text
次の用語の説明【説明】の中で、事実を確かめた方がよい所（数字・制度の名前・期限・条件）に印をつけて、確かめる先の候補（国や自治体の公式ページなど）を書いて。確かめた結果は書かないで（私が確かめる）。
```
```text
次の用語の一覧【一覧】を、読む人が知っておく順番に並べて、用語集のページの見出しの案を作って。似た言葉の違い（例：AとBの違い）を説明する項目があれば足して。
```
```text
次の用語の説明【説明】を読んだ人が、次に持ちそうな質問を5つ出して。答えは、説明に書いてあることだけで書けるものと、書けないもの（確かめが要るもの）に分けて。
```
```text
次の記事【記事】の中で、専門用語なのに説明がない所を探して、記事の中で短く説明を足す案（かっこ書き・1文の補足）を出して。記事は書き換えないで。
```

AIは**案出しと点検**に使い、説明の正確さと事実は自分で確かめます。
