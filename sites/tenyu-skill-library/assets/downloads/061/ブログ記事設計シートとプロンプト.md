# 061-C｜ChatGPTで作るブログ記事 設計シートとプロンプト

**状態：再利用用初稿／事実と体験は人が確かめてから使う**

## 設計欄

- 読む人（1人に絞る）：
- その人が知りたいこと（検索しそうな言葉も）：
- 書く人と、書ける理由（実際の経験）：
- 記事で言えないこと（やっていない・確かめていない）：
- 事実（数字・値段・日付）の確認先：
- 確認者／確認日：

```text
読者【】が知りたいこと【】について、ブログ記事のテーマを3案出して。それぞれ、読者が検索しそうな言葉と、読み終えたときに分かることを1行で。
```
```text
テーマ【】の見出しを5〜7個作って。本文は書かないで。書く人【】が実際にやっていないことは入れないで。
```
```text
見出し【】のうち【1つ】の本文の下書きを作って。400〜600字。数字や値段は【要確認】と書き、自分で決めないで。最後に、書く人が自分の体験を足すとよい場所を3つ示して。
```
```text
本文【】を読み、事実（数字・値段・日付・言い切り）を全部抜き出して表にして。確認先の欄は空けておいて。
```
```text
本文【】の中で、どこかで見たような言い回し・中身のない言葉・くり返しを指摘して、書き直し案を出して。
```
```text
記事【】のタイトル案を5つ作って。読者【】が検索しそうな言葉を入れ、大げさな言葉（必ず・絶対・一番）は使わないで。
```
```text
記事【】のまとめと、読み終えた人が次にする1つの行動を書いて。売り込みすぎないで。
```
```text
公開した記事【】について、1か月後に見直す点を5つ挙げて。古くなりそうな情報と、足すとよい体験を中心に。
```

AIは「それらしい文章」を作るのが得意ですが、書く人の体験と、事実が正しいかは知りません。体験は人が書き、事実は人が確かめます。
