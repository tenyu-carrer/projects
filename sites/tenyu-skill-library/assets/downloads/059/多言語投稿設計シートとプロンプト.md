# 059-C｜SNS多言語投稿 設計シートとプロンプト

**状態：再利用用初稿／訳文はその言語が分かる人の確認を受けてから使う**

## 設計欄

- 届けたい人（国・地域・旅行者か住んでいる人か）と、使う言語：
- 出し方（1つの投稿に言語を並べる／言語ごとに投稿を分ける／言語ごとのアカウント）：
- 訳さない言葉（屋号・商品名）と、説明を足す言葉：
- 確認してくれる人（その言語が分かる人）と、頼み方・お礼：
- 外国語でのコメントやDMへの返し方（できる範囲）：
- 確認者／確認日：

```text
日本語の投稿【】を、翻訳しやすい日本語に整えて。主語を補い、1文を短くし、「あれ」「それ」を具体的な言葉に。意味は変えないで。
```
```text
整えた投稿【】を【言語】に訳して。【届けたい人】向けに、その言語のSNSで自然な言い方で。屋号【】と商品名【】は訳さず、そのまま書いて。
```
```text
訳文【】を日本語に訳し戻して、元の投稿【】と比べて。時間・数字・値段・条件・否定のずれがある所を表にし、直した訳を付けて。
```
```text
投稿【】の中で、【言語】を使う人に伝わりにくい言葉や習慣を抜き出して。「説明を足す」「言い換える」「そのまま」の案と理由を出して。
```
```text
訳文【】に合うハッシュタグを、その言語で3〜5個提案して。実際に使われているかは自分で検索して確かめる前提で、意味も日本語で添えて。
```
```text
外国語のコメント【】の意味を日本語で教えて。そのあと、短くていねいな返信案を【言語】と日本語の両方で作って。分からないことは約束しないで。
```
```text
確認してくれる人に送る依頼文を作って。訳文【】と元の日本語【】を並べ、「意味が合っているか」「不自然な所はないか」「失礼に聞こえないか」の3点を聞く形で。
```
```text
多言語の投稿の1か月の反応【言語ごとの数字】から、次に1つだけ変えることを提案して。数字が少なすぎる場合はそう書いて。
```

AI翻訳は便利ですが、そのまま出すと、意味のずれや失礼な言い方に気づけません。必ず訳し戻しと、その言語が分かる人の確認を通します。
