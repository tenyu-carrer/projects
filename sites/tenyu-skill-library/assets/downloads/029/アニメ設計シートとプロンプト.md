# 029-C｜アニメーション設計シートとプロンプト

**状態：再利用用初稿／AI出力は必ず再生して確認**

## 設計欄

- 伝えたいこと（1文）／見る人／見る場所（SNS・店頭画面・社内）：
- 長さ・縦横比（例：15秒・9:16、30秒・16:9）：
- 使う素材（自作の図形・アイコン・テンプレート素材）と利用条件：
- 音（BGM・効果音・ナレーション）の有無と利用条件：
- 点滅・急な動きを避ける配慮（光過敏の人への配慮）：
- 確認者／確認日：

```text
伝えたいこと【】を、【15】秒・【3】場面のアニメーションにする構成案を作って。各場面に秒数・出る物・動き・文字を付けて。
```
```text
構成案【】の各場面について、動きの種類（フェード・スライド・拡大・揺れ・描画）を1場面2つまでで提案し、その動きを選ぶ理由を書いて。
```
```text
画面に出す文字【】を、1画面12文字以内に短くして。読むのに必要な秒数（1秒あたり4〜6文字目安）も付けて。
```
```text
アイコンと図形だけで【テーマ】を表す絵の案を5つ。人の顔、実在のキャラクター、ブランドのロゴに似せないこと。
```
```text
動き表【】をCSV（element,start_sec,end_sec,motion_in,motion_out,text,note）にして。重なる時間と、文字が動いている時間を警告して。
```
```text
完成したアニメの説明【】から、点滅・急な拡大・画面全体の明滅など、見る人の負担になりそうな箇所を点検して代案を出して。
```
```text
15秒版の構成【】を、6秒版と30秒版に作り替えて。伝えたいことは変えず、削る・足す場面を示して。
```
```text
アニメ動画【題名・内容】の投稿文を2案。動画の内容を超えることは書かない。
```

AIの提案は設計のたたき台です。実際の動きは必ず再生して、読みやすさと見やすさを人が確認します。
