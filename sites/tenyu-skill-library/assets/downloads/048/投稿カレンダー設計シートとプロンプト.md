# 048-C｜投稿カレンダー 設計シートとプロンプト

**状態：再利用用初稿／日付と事実は必ず自分で確認**

## 設計欄

- 使うSNSと、それぞれの投稿の頻度：
- カレンダーの置き場所（表計算・ノート・カレンダーアプリ）：
- 状態の段階（下書き・確認済み・予約済み・公開済み）：
- 担当者（1人か、複数か）と確認者：
- 季節の行事・お店の予定・休みの入れ方：
- 急なお知らせ用の空きの作り方：

```text
来月【】の季節の行事と話題を15個挙げて。日付が決まっているものは日付を書き、すべて「要確認」と付けて。お店・活動【】に関係が深い順に並べて。
```
```text
話題のリスト【】とお店の予定【】から、1か月の投稿カレンダーを作って。SNS【】ごとの頻度を守り、同じ内容が同じ日に重ならないように。週に1日は空きを残して。
```
```text
投稿カレンダー【】を点検して、同じ種類の投稿が続いている所、お知らせばかりの週、素材（写真）が足りない日を指摘して。
```
```text
投稿カレンダー【】から、今週撮る写真・作る画像のリストを作って。撮る日と担当も入れて。
```
```text
1つの話題【】を、Instagram・Threads・Facebook用に書き分ける方針を作って。同じ文章を使い回さないように、それぞれの役割を書いて。
```
```text
投稿カレンダー【】の状態の欄から、遅れている投稿（下書きのまま・確認待ち）を一覧にして、今週やることの順番を出して。
```
```text
先月のカレンダーと反応【】から、来月のカレンダーで変えることを1つだけ提案して。
```
```text
急なお知らせ【内容】が入ったとき、今週のカレンダー【】のどの投稿を動かすかの案を出して。
```

カレンダーは「計画」です。日付や行事の情報は、AIの答えをそのまま使わず、必ず自分で確かめます。
