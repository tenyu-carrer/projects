# 052-C｜SNS分析レポート 設計シートとプロンプト

**状態：再利用用初稿／数字の書き写しと計算は必ず人が確かめる**

## 設計欄

- 分析するSNSと期間（例：Instagram・先月1か月）：
- 見る数字（見た人の数・保存・コメント・プロフィールを見た数など）：
- 数字をどこから写すか（各SNSの分析画面）：
- 数字をためる表の置き場所：
- レポートを読む人（自分・店長・お客さま）：
- 来月変えることを決める日：

```text
次の投稿の数字の表【】を読みやすく整えて、投稿の種類ごとに、見た人の数と保存の数の平均を出して。計算のしかたも書いて。数字が足りない欄は空のままにして。
```
```text
投稿の数字の表【】から、よかった投稿を3本、伸びなかった投稿を3本選んで、それぞれ考えられる理由を1行で書いて。理由は「かもしれない」の言い方にして。
```
```text
投稿の数字の表【】を見て、気づきを3つ書いて。投稿の数が少ない場合は、言い切らずに「来月も同じか見る」と書いて。
```
```text
気づき【】から、来月変えることを1つだけ提案して。変えたかどうかが来月の数字で分かる形にして。
```
```text
次の材料【今月のまとめ・よかった投稿・伸びなかった投稿・気づき・来月変えること】から、1枚のSNS分析レポートを作って。読む人は【】。専門用語には短い説明を付けて。
```
```text
先月のレポート【】と今月の数字【】を比べて、先月決めた「変えること」をやってどうだったかを書いて。ほかの理由も考えられる場合はそれも書いて。
```
```text
SNS分析レポート【】を点検して、言い切りすぎている所、計算の間違いがありそうな所、数字と合わない文を指摘して。
```
```text
SNS分析レポート【】を、店長に3行で伝えるメッセージにして。数字は2つまで、来月変えることを最後に書いて。
```

AIは計算や書き写しを間違えることがあります。合計や平均は、表計算や電卓でも確かめます。
