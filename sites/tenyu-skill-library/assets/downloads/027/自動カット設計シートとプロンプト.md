# 027-C｜自動カット設計シートとプロンプト

**状態：再利用用初稿／AI出力は要検証**

## 設計欄

- 視聴者／目的／完成尺の上限ではなく必要条件：
- 必ず残す事実・否定・注意・感情・実演：
- カット候補の種類／最短保持時間／前後余白：
- 元素材・プロジェクト・粗編集・確定版の保存先：
- 人物・顧客情報・AI送信条件：
- 確認者／承認者／確認日：

```text
文字起こし【】を残す・短縮候補・削除候補・聞き直しに分類。元時刻、理由、失う情報、確認者を付ける。
```
```text
無音区間一覧【】から、呼吸、場面転換、操作待ち、感情、音楽、同期に必要な可能性を質問化。秒数だけで削除判定しない。
```
```text
フィラー候補【】について、意味なし／強調／話者らしさ／考える間／言い直しの一部に分類し、削除時のつながりを示す。
```
```text
粗編集EDL【】を元素材と照合し、否定、数字、条件、注意、原因結果が欠ける区間を抽出する。
```
```text
カット前後の字幕【】から、文法、主語、時制、指示語、話者交代の破綻を検査する。
```
```text
粗編集メモ【】から映像・音声のジャンプ、口の動き、環境音、Bロール、音楽拍の不連続を検品する表を作る。
```
```text
完成尺【】と残す条件【】から、条件を守る短縮案を3つ。削除で意味が変わる場合は尺延長を提案する。
```
```text
修正前EDL【】と修正後EDL【】を比較し、追加・削除・移動、根拠、影響する字幕・音声を差分表にする。
```

AI案は非破壊編集と人の全編確認を代替しません。
