# 067-D｜Kindle出版 公開前チェック

- [ ] タイトル・サブタイトル・著者名が表紙と一致
- [ ] タイトルに検索の言葉・宣伝の言葉・ほかの本の名前なし
- [ ] 内容紹介は本に書いてあることだけ（URL・レビュー・値段の話なし）
- [ ] 検索の言葉とジャンルが本の中心の話題に合う
- [ ] 表紙の画像・フォントの権利を確認
- [ ] 表紙は縮小してもタイトルが読める
- [ ] プレビューで全ページを確認
- [ ] AI生成の文章・画像・翻訳の申告を公式の区分で判断
- [ ] KDPセレクトの独占の条件を理解して選んだ
- [ ] 価格とロイヤリティの計算を自分で確認
- [ ] 税・口座の情報は自分の画面だけで入力
- [ ] 出版後の見直しの日と見る数字を決めた

表紙と本の詳細が一致しない、権利の分からない画像がある、AI生成の申告を判断していない場合は出版に進まない。売上・ランキングを保証しない。
