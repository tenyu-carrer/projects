# 067-C｜AIでKindle出版を進める 設計シートとプロンプト

**状態：再利用用初稿／KDPの規約・価格の条件・画面は使う時点で公式ページを確認**

## 設計欄

- 本のタイトル（表紙と同じ表記）：
- サブタイトル：
- 著者名（ペンネームの場合も表紙と同じ）：
- 内容紹介（本に書いてあることだけ）：
- 検索の言葉（2〜3語の言葉をいくつか）：
- ジャンル（カテゴリー）の候補：
- 表紙（作った方法・画像の権利・AI生成かどうか）：
- 原稿ファイルの形式（Word・EPUBなど）とプレビューの確認日：
- AI生成の申告（本文・画像・翻訳のどこにあるか）：
- KDPセレクトに登録するか（理由）：
- 価格とロイヤリティの選び方（理由）：
- 出版後に見直す日と、見る数字：
- 確認者／確認日：

## プロンプト（この順で使います）

```text
私のKindle本のテーマは【】、読者は【】、目次は【】です。タイトルはそのままで、サブタイトルの案を5つ出して。本の中身が分かる言葉にして、「ベストセラー」「無料」などの宣伝の言葉や、ほかの本・著者の名前は入れないで。
```
```text
私の本の目次と各章の要点【】をもとに、内容紹介の文の案を3つ作って。本に書いてあることだけを使い、結果の約束（必ず・絶対・誰でも）、レビューの言葉、URL、値段の話は入れないで。
```
```text
私の本の内容【】について、読者がAmazonで検索しそうな2〜3語の言葉を10個出して。本の中心の話題に合うものだけにして、ほかの著者名・作品名・宣伝の言葉は入れないで。合わない言葉は理由をつけて外して。
```
```text
私の本の内容【】に合いそうな本のジャンルを3つまで、理由をつけて挙げて。実際に選べるジャンルの名前は、私がKDPの画面で確かめるので、案として出して。
```
```text
私の本の表紙を作るための、表紙の組み立ての案を3つ出して。タイトル【】、読者【】、本の雰囲気【】。スマートフォンの小さな表示でもタイトルが読めるように、文字の大きさと配置も書いて。実在の本の表紙に似せないで。
```
```text
私の本の「AIの使い方の記録」【章ごとの記録】を読んで、KDPのAIコンテンツの区分（AI生成／AIアシスト）にどう当てはまりそうか、章ごとに表にして。最終的な判断は私が公式ページを読んでするので、迷う所には「要確認」と書いて。
```
```text
次のKindle本の価格の条件【価格・ロイヤリティの率・ファイルの大きさ】で、1冊売れたときに受け取る金額の目安を計算して。計算の式も書いて。消費税の扱いなど分からない所は「要確認」と書き、数字を作らないで。
```
```text
私の本のプレビューで見つけた点【気づいたこと】を、直す順に並べて表にして。原稿ファイルで直す所・本の詳細で直す所・表紙で直す所に分けて。
```
```text
出版してから30日たちました。分かっている数字【販売数・読まれたページ数・レビューの数など】をもとに、次に試せることを3つ挙げて。数字が少ないときは「まだ判断できない」と書いて。売上の予想はしないで。
```

AIは**案出し・計算の手伝い・点検**に使い、本の詳細・申告・価格・出版は自分で決めます。KDPの決まりは変わることがあるので、手続きの前に公式ページを読みます。
