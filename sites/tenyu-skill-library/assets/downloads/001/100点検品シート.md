# 001｜SNS投稿画像 100点検品シート

- [ ] 3秒で投稿テーマが分かる（10点）
- [ ] 対象者が自分向けと判断できる（10点）
- [ ] 最初に主見出しが読める（10点）
- [ ] 25％表示・スマホ幅で読める（10点）
- [ ] 文章3段・色3色・フォント2種類以内（10点）
- [ ] 左右端、行間、文字位置がそろう（10点）
- [ ] 誤字・固有名詞・数字を元原稿と照合した（10点）
- [ ] 写真・イラスト・フォントの利用条件を確認した（10点）
- [ ] PNGを書き出し、Canvaの外で開いた（10点）
- [ ] 投稿先の公開前プレビューを確認した（10点）

合計：　／100点　判定：合格／再修正

## 点数に関係なく不合格

- [ ] 権利不明の素材、ロゴ、人物写真がある。
- [ ] 元情報にない数字・効果・実績がある。
- [ ] 重要な文字が切れている、またはPNGが開けない。
- [ ] 個人情報・機密情報が含まれる。
