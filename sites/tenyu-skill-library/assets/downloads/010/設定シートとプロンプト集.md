## プロンプト1｜方向性
```text
用途：【】見る人：【】役割：【】性格3語：【】世界観：【】
避ける要素：【】
模倣なしのオリジナルキャラクター方向性を3案。輪郭、色、顔、服、固定特徴と可変部分を整理。
非類似性・権利安全性・商標登録可能性を断定しない。
```

## プロンプト2｜キャラクターシート
```text
架空キャラクター設定：【固定設定】
正面・斜め・横向きの全身と、喜・悲・驚・困・集中・安心の表情差分。
輪郭・配色・服・模様・持ち物を全体で統一。文字、ロゴ、透かし、余分な小物なし。
既存作品、作家、ブランド、実在人物を模倣しない。
```

## プロンプト3｜一場面
```text
共通キャラクター設定：【】場面：【】動作：【】表情：【】視点：【】背景：【】
固定する特徴：【】変えてよい要素：【】
固定特徴を保ち、不要な服・小物を追加しない。
```

## プロンプト4｜差分点検
```text
基準設定：【】出力の実際の特徴：【】
輪郭、色、顔、髪・耳、服、模様、持ち物を一致／差異／現物要確認に分ける。
画像を見ていない場合は見たふりをしない。権利判断を断定しない。
```

## プロンプト5｜利用条件台帳
```text
素材・フォント・生成サービス：【】公式条件URL：【】利用目的：【】
出典、作成者、許可範囲、商用利用、AI入力、再配布、確認日を表に整理。
不明な条件は未確認のまま残し、利用可と推測しない。
```
