# 024-C｜TikTok投稿設計シートとプロンプト

**状態：再利用用初稿／AI出力は要検証**

## 設計欄

- 視聴者／一つの主題／見た後の変化：
- 冒頭3秒／本編での回収：
- 実演・根拠／使わない主張：
- 人物・素材・音源・商用利用の権利：
- AI生成・大幅編集の有無／表示判断：
- 自社・他社商品の宣伝有無／商用開示判断：
- 公開範囲・コメント・Duet・Stitch等の判断：
- 公式URL／確認日／確認者：

```text
主題【】と実演【】から、結果先出し・質問・途中開始の冒頭を各3案。字幕、画面、音、本編での回収、誤解リスクを付ける。
```
```text
素材台帳【】から、人物同意、音源、画像、ロゴ、商用利用、AI送信条件の未確認項目だけ抽出。推測で埋めない。
```
```text
台本【】を15秒／30秒／60秒の3版にする。重要な条件・否定・安全手順は削らず、削除理由を示す。
```
```text
字幕【】の数字、否定、固有名詞、改行、表示時間を点検する表を作る。原音確認欄を付ける。
```
```text
投稿内容【】について、AI生成表示、商用コンテンツ開示、音楽の商用条件、公開範囲で確認すべき事項を列挙。最新公式画面で人が確定する。
```
```text
公開後データ【期間・再生・視聴・反応・流入】から仮説を3つ。断定せず、次回に一要素だけ変える試験を作る。
```

出力は投稿可否の助言ではなく確認表です。審査、配信、再生、収益を保証しません。
