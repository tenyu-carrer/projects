## プロンプト1｜場面候補
```text
利用者：【】会話関係：【】セット数：【】
挨拶・返事・感謝・依頼・確認・保留・労い・別れから重複しない場面案。
各案に短い文言、ポーズ、表情、会話例を付ける。
広告、URL、他者のキャラクター、メッセンジャーサービス名を含めない。
```

## プロンプト2｜固定キャラクター
```text
オリジナルキャラクター案を3つ。利用場面：【】印象：【】避ける要素：【】
輪郭、配色、目、服、持ち物、縮小表示の識別点を整理。
既存作品・商標・人物を模倣せず、類似性や権利安全を断定しない。
```

## プロンプト3｜文言点検
```text
各番号の文言とポーズ：【】
意味の重複、誤字、会話での使いやすさ、審査上確認すべき広告・URL・個人情報等を列挙。
審査通過は予測・保証せず、公式ガイドで確認すべき点を分ける。
```

## プロンプト4｜公開前校閲
```text
セット一覧：【】素材・フォント台帳：【】公式仕様URL・確認日：【】
個数、メイン・タブ画像、権利、視認性、文字、ファイル構成の人手確認表を作る。
入力にない審査結果やライセンスを推測しない。
```

実際の寸法・形式・文字数は申請前にLINE公式ガイドで再確認してください。
