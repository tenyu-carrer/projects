# 035-C｜動画台本 設計シートとプロンプト

**状態：再利用用初稿／AI出力は必ず事実と照合**

## 設計欄

- テーマ／見る人／その人の困りごと：
- 動画の長さ・縦横比・公開場所：
- 見終わったあとにしてほしいこと（1つ）：
- 話し手（自分・アバター・ナレーションのみ）：
- 事実確認が必要な情報と確認先：
- 参考にした情報源（他人の動画や記事の文章を写さない）：
- 確認者／確認日：

```text
テーマ【】、見る人【】、長さ【60秒】で、骨組み台本を作って。つかみ・結論・やり方3つ・まとめの4部分に分け、各部分に秒数と話すことを書いて。
```
```text
骨組み台本【】から、話す言葉と映す映像を並べた2列台本を作って。5〜10秒ごとに区切り、画面の文字（12文字以内）も付けて。
```
```text
台本【】の最初の5秒（つかみ）を3案作って。疑問形・意外な事実・見る人の困りごと、の3つの型で。誇張や「絶対」は使わないで。
```
```text
台本【】の中で、事実・数字・安全・健康・お金に関わる箇所を全部抜き出して、確認先（公式サイトなど）の候補を付けて。
```
```text
台本【】を声に出して読んだときの秒数を、1分300文字の目安で計算して。長すぎる場合は、削る候補を優先順位つきで出して。
```
```text
60秒の台本【】を、15秒版と3分版に作り替えて。結論は変えないで、削る・足す部分を示して。
```
```text
台本【】を、話し言葉として自然かどうか点検して。書き言葉っぽい表現、長すぎる文、言いにくい言葉に印を付けて言い換え案を出して。
```
```text
完成した台本【】が、参考にした動画や記事【内容の要約】の構成や言い回しをまねしすぎていないか点検して。似ている部分と、自分の言葉に直す案を出して。
```

AIが作った台本には、もっともらしい間違いが入ることがあります。事実の部分は必ず確認してから撮影します。
