# 005-C 表紙設計シート＆プロンプト

## 設計シート
- 想定読者：
- 読者が抱える悩み：
- 目次・本文の要約：
- 本文で実際に提供する技能：
- 本文で扱わない内容：
- 書名／副題／著者名：
- 表紙で示したい印象：
- 販売・配布先：
- 公式仕様URL／確認日：
- 必要寸法・形式・容量：
- 未確認事項：

## プロンプト1｜内容から約束を整理
```text
本の要約：【】 目次：【】 対象読者：【】
本文で教えること：【】扱わないこと：【】
本文が裏づけられる読者への約束を3案。各案について根拠となる章と誤解リスクを示す。
入力にない実績、数字、収益、ランキング、受賞、資格を作らない。
```

## プロンプト2｜書名・副題
```text
読者：【】 悩み：【】 本文内容：【】得られる技能：【】
書名と副題を各8案。短く内容を正確にし、根拠のない数字・No.1・必ず成功は禁止。
各案に「本文で裏づける箇所」「誤認リスク」「類似調査が必要な語」を添える。
```

## プロンプト3｜レイアウト案
```text
書名：【】副題：【】著者：【】読者：【】ジャンル：【】
販売先の公式仕様：【URL・確認日、なければ未確認】
縦長表紙のレイアウトを3案。文字の優先順位、余白、色の役割、画像の目的を説明。
他作品や著名な作家の作風を模倣しない。仕様を推測しない。
```

## プロンプト4｜校閲
```text
表紙文言：【】 本の内容：【】 根拠資料：【】
書名・副題が内容を誇張していないか、未確認の数字・資格・受賞・推薦・実績がないか点検。
「表示／裏づけ／リスク／確認方法」を表で出し、事実を創作しない。
```

AIの案は決定ではありません。書名の類似・商標、素材ライセンス、販売先仕様、著者名は人が確認します。原稿や個人情報を不用意に入力しません。
