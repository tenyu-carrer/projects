# 023-C｜YouTube動画設計シートとプロンプト

**状態：再利用用初稿／AI出力は要検証**

## 設計シート

- 視聴者／検索・閲覧状況：
- 困りごと／既に知っていること：
- 見終えた後の変化：
- 動画内で示せる根拠：
- 示せないこと／保証しないこと：
- 想定尺／章数：
- 人物・場所・素材・音源の権利：
- 公開先公式URL／確認日：
- 公開後に見る指標／判断期間：

## 8つのプロンプト

```text
視聴者【】、困りごと【】、実演できる根拠【】から、動画の約束を3案。誇張、恐怖、未確認の数字、成果保証を避ける。
```

```text
動画の約束【】を、冒頭30秒、前提、実演、検品、まとめに分ける。各章の目的、必要素材、証拠、離脱要因を表にする。
```

```text
構成【】から撮影リストを作る。ショット、音声、画面収録、権利、失敗時の代替、確認者を含める。
```

```text
台本【】を事実、意見、推測、行動指示に分類。一次資料が必要な箇所と、断定を弱める箇所を示す。
```

```text
原稿【】から字幕案。数字、否定、固有名詞を抽出し、原音・一次資料で人が確認する欄を付ける。
```

```text
動画の約束【】と実演【】からタイトル10案、サムネイル文言5案。互いに補完し、釣り・成果保証・根拠のない数字を避ける。
```

```text
章名と開始時刻【】からチャプター案と概要欄の骨子を作る。リンク、広告、提携、引用、更新日を人が確認する欄を付ける。
```

```text
公開後データ【期間・表示・クリック・視聴・コメント】から仮説を3つ。断定せず、次回に一要素だけ変える試験を提案する。
```

AIに個人情報、秘密、未公開素材を無条件で送らないでください。タイトルや分析案は審査・再生・収益を保証しません。
