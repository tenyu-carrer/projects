# 037-C｜BGM 設計シートとプロンプト

**状態：再利用用初稿／生成した音は必ず動画に合わせて聞く**

## 設計欄

- 流す場所（動画・店内・イベント・配信）／長さ／繰り返し再生の有無：
- 声（ナレーション・会話）の有無と、声が入る区間：
- 雰囲気3語／テンポ／使う楽器・使わない音：
- 生成するときのプラン（無料＝個人的・非商用）と確認日：
- 使い道が収益化・依頼・販売にあたるか：
- 確認者／確認日：

```text
使う場所メモ【】から、Sunoで歌なしBGMを作るためのStyles（曲調の指示）を3案作って。ジャンル・雰囲気・楽器・テンポの言葉だけで、実在の作曲家名・曲名・アーティスト名は使わないで。
```
```text
動画の場面表【秒数と内容】から、BGMの流し方（どこで流す・小さくする・止める・切り替える）を表にして。声がある区間は音量を下げる指示を入れて。
```
```text
BGMが主役のじゃまになっていないかを点検する質問を10個作って。声の聞き取り、雰囲気の合い方、繰り返しの不自然さなど。
```
```text
店内で繰り返し流すBGMの条件【店の雰囲気・営業時間】から、聞き疲れしにくい曲調の条件を出して。
```
```text
同じ雰囲気で長さの違うBGM（15秒・30秒・60秒）を作るためのStyles案と、つなぎ目が自然になる工夫を出して。
```
```text
BGMの使い道【】が、無料プランの「個人的・非商用」の範囲に入るかを判断するための確認リストを作って。答えは推測せず、確認する公式ページを示して。
```
```text
キューシート【】を読み、音量の差が大きすぎる場所、急に始まる・急に切れる場所を指摘して、直し方を出して。
```
```text
依頼主に渡すBGMの利用範囲の説明文を作って。使ってよい場所、使えない場所、生成したサービスとプラン、確認日を入れて。
```

BGMの使い道によって、必要なプランが変わります。商用で使う場合は、有料プラン加入中に作った音源だけを使います。
