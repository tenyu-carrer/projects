# 002 チラシ 100点検品シート

各項目を「満点／半分／0点」で採点。重大項目に一つでも不合格があれば公開不可。80点以上かつ重大項目すべて合格で完成。

## 伝達（各10点）
- [ ] 何のイベントかが見出しから分かる（重大）
- [ ] 誰向けかが明示され、対象と内容が一致
- [ ] 日時・曜日・受付時間が正しい（重大）
- [ ] 会場名・住所・階または参加URLが正しい（重大）
- [ ] 料金、税込／税別、追加費用の説明が正しい（重大）
- [ ] 申込方法と締切が一目で分かる
- [ ] 申込URLが有効で必要情報を閲覧できる（重大）
- [ ] QRが実機で正しいページへ遷移する（使用時は重大）

## 読みやすさ（各5点）
- [ ] 見出し・本文の大きさに明確な差がある
- [ ] 小さなスマホ表示でも主要情報が読める
- [ ] 文字と背景のコントラストが十分
- [ ] 余白が保たれ、端に重要情報が寄っていない
- [ ] 写真が文字や申込導線を邪魔していない
- [ ] 文章が短く、誤解を招く曖昧語が少ない

## 権利・書き出し（各5点）
- [ ] 画像・ロゴ・フォントの利用条件を確認（重大）
- [ ] 誇大表現や根拠のない成果保証がない
- [ ] PNGを別アプリで開いて確認した
- [ ] PDFのページサイズ・向き・文字・端を確認（重大）
- [ ] 印刷所の塗り足し・色・トンボ仕様を確認
- [ ] 編集共有権限を必要な人に限定した
- [ ] 架空見本・仮QR・要確認欄が残っていない（重大）

得点：＿＿／100　重大項目：合格・不合格　修正者：＿＿　確認日：＿＿
