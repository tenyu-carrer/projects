# 050-C｜投稿文 設計シートとプロンプト

**状態：再利用用初稿／事実と言い回しは必ず人が確認**

## 設計欄

- お店・活動の名前と、ふだんの話し方（です・ます／くだけた言い方）：
- 読んでほしい人：
- 使うSNSと、それぞれの文の長さの目安：
- 絵文字の数（例：3〜6個）と、使わない絵文字：
- 使わない言葉（言い過ぎ・ほかを悪く言う言葉）：
- 確認する人：

```text
お店・活動【】の「話し方の見本」を作って。ふだんの話し方【】、読んでほしい人【】。使う言葉の例・使わない言葉の例を5つずつ書いて。
```
```text
ネタ【】から、SNS【】の投稿文を作って。話し方の見本【】に合わせ、書き出し・中身・締めの3つに分けて。本当のこと【】だけを使い、絵文字は3〜6個。言い過ぎは使わないで。
```
```text
投稿文【】の書き出しを、問いかけ・様子・気持ち・数字・お知らせの5つの型で書き直して、5案出して。
```
```text
投稿文【】の締めを、毎回同じにならないように4案出して。押しつけない言い方にして。
```
```text
投稿文【】を点検して、事実を確かめるべき所（値段・日付・在庫・効果）、言い過ぎ、読みにくい所を指摘して。直した文も出して。
```
```text
最近の投稿文【5本】を見比べて、書き出し・締め・絵文字の使い方が同じになっている所を指摘して。
```
```text
1つのネタ【】を、Instagram用とThreads用に書き分けて。同じ文章を使い回さず、それぞれの長さと役割に合わせて。
```
```text
投稿文【】を、声に出して読んだときに引っかかる所を直して。意味は変えないで。
```

AIの文は下書きです。本当のことか、お店らしい言葉かを、必ず人が読んで決めます。
