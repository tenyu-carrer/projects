# 003｜名刺設計プロンプト集

氏名、個人電話、住所、顧客情報、非公開URLはAIへ入力しない。出力は原稿と照合。

### 仕事説明
```text
相手：[相手]、公開できる事実：[仕事内容]。名刺用の15〜28字を5案。誇張・成果保証・事実追加を避け、不明は質問してください。
```

### 情報を分類
```text
目的：[相手にしてほしい行動]、相手：[相手]、候補：[個人情報を除く項目]。必須/補助/今回は載せないに分け、理由を説明。連絡先を創作しない。
```

### 表裏構成
```text
表は氏名・屋号・仕事説明、裏は[予約/アクセス/サービス]の1項目を主役に。読み順、削る情報、QRの横に置く説明を提案。実URLや実績は作らない。
```

### 5秒テスト
```text
カード文面：[個人情報を除いた文章]。誰のカードか、何を依頼できるか、次の行動を測る誘導のない質問と合格条件を作ってください。
```

### 校正
```text
原稿：[必要最小限]。表記ミス候補、原本照合項目、目視項目に分類。氏名・住所・連絡先を推測で変更せず、不明を質問してください。
```

### 情報削減
```text
目的：[目的]、相手：[相手]、項目：[個人情報除く]。5項目以内に絞り、残す/裏面へ/削除に分け、理由を示す。連絡先を作らない。
```
