# 003-B｜名刺・ショップカード完成見本の読み方

## この段階で受け取るもの

`sites/tenyu-skill-library/assets/examples/003-business-card.png` に、表裏の雰囲気見本があります。表は名前と仕事、裏は次の行動と連絡導線を主役にしたレイアウト例です。見た目をそのまま使うための印刷原稿ではありません。

## 架空情報の注意

氏名「山田花子」、仕事説明、`hello@example.jp` は教材用の架空例です。QR風の模様は遷移先・有効性・読み取りを検証していません。個人の実連絡先でも、本番の予約QRでもありません。この見本をそのまま印刷、配布、顧客納品しないでください。

## 3分の観察

1. 画像を小さく表示し、最初に目に入る要素を一つ言う。
2. 表面を見て「誰か」「何をしているか」を答える。
3. 裏面を見て「次に何をすればよいか」を答える。
4. 背景・文字・飾りのうち、なくしても伝わる要素を一つ選ぶ。
5. 自分のカードで変えるべき点を3つ記録する。

## 判定

名前と仕事が数秒で伝わり、連絡手段が一つ明確で、仮情報を仮と認識できれば見本の読み取り完了です。実際の完成品にするには、本人確認済みの原稿、権利確認、印刷会社仕様、QR実機テストが別途必要です。
