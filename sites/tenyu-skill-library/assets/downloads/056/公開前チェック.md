# 056-D｜SNSキャンペーン 公開前チェック

- [ ] 種類（総付・一般懸賞・オープン懸賞）を判定
- [ ] 景品の上限を消費者庁の最新の表で計算
- [ ] 業種ごとの別ルールを確認
- [ ] 使うSNSのプロモーションのルールと確認日
- [ ] シェア・タグ付けなどの禁止条件がない
- [ ] 応募要項（主催者・期間・条件・人数・発表・連絡）
- [ ] 運営会社が主催しないことを明記
- [ ] 個人情報の利用目的と消す時期
- [ ] 偽アカウントへの注意書き
- [ ] 告知文と応募要項の人数・景品が一致
- [ ] 感想投稿をお願いするなら広告表示

上限の未確認、SNSのルールの未確認、連絡方法の不記載があれば実施を止めて直す。応募数・売上を保証しない。
