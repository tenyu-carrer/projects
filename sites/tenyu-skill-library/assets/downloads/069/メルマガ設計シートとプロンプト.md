# 069-C｜AIでメールマガジンを作る 設計シートとプロンプト

**状態：再利用用初稿／配信サービスの料金・機能、法律の運用は使う時点で公式ページを確認**

## 設計欄

- 読者（どんな人が・どんな場面で困っているか）：
- 読者がメルマガを読むと得られること（1文）：
- 配信の頻度と曜日・時間：
- 1通の長さの目安：
- 読者の登録方法（どの画面で、何に同意してもらうか）：
- 同意をもらった記録の残し方：
- 配信サービス（名前・プラン・確認日）：
- 4週間のテーマ（1通1テーマ）：
- 毎回のしてほしいこと（返信・記事を読む・申込みなど）：
- 署名に入れる送信者の名前・住所・問い合わせ先：
- 配信停止の方法（URL）と、その案内の文：
- 広告や宣伝を入れるときのルール：
- 見直す日と見る数字（返信・配信停止・クリックなど）：
- 確認者／確認日：

## プロンプト（この順で使います）

```text
私のメルマガの読者は【どんな人・どんな場面で困っているか】です。この人が知りたがっていそうなテーマを20個、「すぐ役立つ」「考え方」「お知らせ」の3つに分けて出して。調べていない数字や統計は作らないで。
```
```text
次のテーマ【テーマ一覧】から、4週間分（週1通）の配信計画を作って。1通1テーマにして、件名案・最初に伝える結論・読者にしてほしいこと（1つ）を表にして。宣伝の回は4通のうち1通までにして。
```
```text
次の1通【テーマ・結論・読者・してほしいこと】の件名を10案出して。30文字以内、読者の困りごとか、読むと分かることを入れる。「必ず」「絶対」「今だけ」「損する」などの言葉は使わないで。
```
```text
次の1通の本文を下書きして。【テーマ・結論・読者・自分の経験のメモ】。最初の3行で結論を書き、本文は見出しなしで800〜1200字、最後にしてほしいことを1つだけ。自分の経験のメモにないことを体験談として書かないで。
```
```text
次のメルマガ本文【本文】を、読者の立場で読んで、①分かりにくい言葉、②長すぎる段落、③根拠のない言い切り、④事実を確かめるべき所を、場所を示して表にして。直し方の案も書いて。本文は書き換えないで。
```
```text
次のメルマガの署名と配信停止の文【文】に、送信者の名前、配信停止の連絡先（URLかメールアドレス）とその案内、住所、問い合わせ先が入っているか点検して。足りない項目を表にして。最終的な判断は私がする。
```
```text
次の宣伝の回の文【文】を点検して。教材や商品にないこと、効果の約束、根拠のない数字、事実の確認が要る「残りわずか」「今だけ」などに印をつけて理由を書いて。
```
```text
メルマガを4週間配信しました。分かっていること【返信の内容・配信停止の数・クリックされたリンク】をもとに、続けるテーマ・やめるテーマ・直す点を表にして。数が少ないときは「まだ判断できない」と書いて。
```

AIは**案出しと点検**に使い、テーマ・本文・送る相手・送るかどうかは自分で決めます。法律や配信サービスの決まりは変わることがあるので、配信の前に公式ページを読みます。
