## 再利用プロンプト

### 事実に沿う冒頭
```text
対象者【】、実際に見せる内容【】から冒頭2秒の案を5つ。恐怖、不安、根拠のない数字、成果保証を使わず、本編で回収できる約束と確認質問を添える。
```
### 3区間構成
```text
内容【】を、導入0〜2秒、実演2〜【】秒、結果【】〜【】秒に分ける。各区間の画面、音声、字幕、残す事実、完了サインを表にする。
```
### ショット表
```text
台本【】を一工程一ショットへ分け、shot_id、開始、終了、画面、動き、字幕、音声、権利、撮影状況を表にする。未撮影を完成扱いしない。
```
### 字幕短文化
```text
校正済み台本【】を短い字幕へ。音声にない主張を足さず、意味の切れ目、読み時間、改行、UI重なりの確認欄を付ける。
```
### 縦型再構成
```text
横長素材【】を縦型へ再構成する確認表。主役、顔、手、商品、文字、背景を切らず、無理なAI拡張を避ける。生成補完箇所は人が確認する。
```
### ループ設計
```text
冒頭【】と終端【】を比較し、自然に戻るための構図・動き・音の案を3つ。内容を歪めたり不自然な繰り返しを作らず、終端を確認できる時間も残す。
```
### 媒体別書き出し
```text
公開先【】の最新公式仕様【URL・確認日】と書き出し情報【】を、比率、解像度、尺、形式、容量、字幕、UIで照合。不明を推測しない。
```
### 公開後レビュー
```text
公開記録【】と分析値【】を、冒頭離脱、完了、再視聴、反応、誤解で整理。小さい標本から成功を断定せず、次回変える項目を一つにする。
```
