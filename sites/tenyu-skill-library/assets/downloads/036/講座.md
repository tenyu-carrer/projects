# 036-D 実践講座｜Suno AIでオリジナル曲を作る方法

商品ID：036-D（釣り竿の作り方）｜天祐 AI ビジネス  
版：試作 v0.1｜確認日：2026-10-22

## この講座のゴール

音楽経験がない人でも、受講後に次のことができる状態を目指します。

- 作りたい曲の目的を1枚の企画メモにまとめる
- オリジナル歌詞と曲調の指示を用意する
- SunoのCustom画面へ順番どおり入力し、オリジナル曲を生成する
- 2つの候補を比べ、1か所ずつ直して完成版を選ぶ
- 無料プランと有料プランの利用範囲を区別する
- 販売・収益化する前に、権利と販売先の条件を確認する

完成物は「曲1本」「使用した歌詞」「スタイル指示」「権利確認メモ」の4点です。

## 対象者

- Sunoを初めて使う人
- 楽器や楽譜は苦手だが、自分の曲を作りたい人
- 誕生日、記念日、動画、店内などに合う曲を作りたい人
- 将来は楽曲制作サービスや音源販売を試したい人

## 所要時間

- 初回：60〜90分
- 2曲目以降：30〜60分が目安

生成結果を聞き比べる時間によって変わります。

# 1. 準備

## 必要なもの

1. パソコンまたはスマートフォン
2. インターネット接続
3. Sunoアカウント
4. 歌詞づくりを手伝わせる場合はChatGPTまたはClaude
5. この講座に付属する `実践テンプレート.md`
6. 販売・収益化を考える場合は `販売・権利チェックシート.md`

## 費用

Sunoは無料で試せます。公式ヘルプでは、無料プランに毎日更新される50クレジットがあると案内されています。ただし、無料プランで作った曲は個人的・非商用の利用に限られます。

販売、広告収益のある動画、ストリーミング配信などに使う曲は、原則として**有料プランに加入中に作成し、Sunoが用意した正規の方法でダウンロードする**必要があります。無料プランで作った曲に、あとから加入して自動的に商用利用権が付くわけではありません。

2026-10-22に公式料金ページで確認した年払い表示は、Proが月額換算8米ドル、Premierが月額換算24米ドルです。税、月払い価格、機能、ダウンロード数は変わることがあるため、申込み直前に公式画面で確認してください。

## 始める前の3つの約束

- 実在の歌手名や既存曲名を「そっくりにする指示」として使わない
- 他人の歌詞、録音、声を、許可なく入力・アップロードしない
- 販売予定なら、無料プランで本番曲を作らない

# 2. まず曲の設計図を作る

Sunoを開く前に、次の5項目を決めます。付属テンプレートの「曲の設計シート」に書いてください。

1. **用途**：誰が、どこで聞くか
2. **テーマ**：何を伝える曲か
3. **雰囲気**：明るい、落ち着く、切ないなど
4. **音の特徴**：ジャンル、楽器、速さ、声
5. **完成条件**：何を満たせば採用するか

### 記入例

- 用途：友人の30歳の誕生日に、動画と一緒に贈る
- テーマ：長い付き合いへの感謝と、これからの応援
- 雰囲気：明るいが、最後は少し感動する
- 音：アコースティックポップ、ギター、ピアノ、女性ボーカル、108 BPM前後
- 完成条件：名前が1回だけ自然に入り、サビを一度聞いて覚えられる

**注意**：最初から「明るい・暗い・激しい・静か」のような反対の条件を詰め込むと、修正点が分からなくなります。最初は雰囲気を1〜2個に絞ります。

# 3. 歌詞を用意する

歌入りの曲は、次のどちらかで歌詞を用意します。

## 方法A：自分で書く

次の順番にするとまとまりやすくなります。

1. 伝えたい出来事を3つ書く
2. 一番伝えたい短い言葉をサビにする
3. `[Verse]`、`[Chorus]` などの目印を付ける
4. 1行を短くする
5. 声に出して読み、言いにくい所を直す

## 方法B：文章AIに下書きを作らせる

付属テンプレートの「歌詞作成プロンプト」を使います。AIが作った文は、そのまま確定せず、自分の体験や言葉に直してください。

### 基本の構成

```text
[Verse]
Aメロ。出来事や場面を描く

[Pre-Chorus]
サビへ向かう気持ちの変化

[Chorus]
一番伝えたい、短く覚えやすい部分

[Verse]
別の出来事や変化

[Chorus]
サビを繰り返す

[Bridge]
最後のサビ前に視点を変える

[Outro]
短く終わる
```

### 歌詞の確認

- 自分または依頼者が権利を持つ内容か
- 実在する歌詞の写しになっていないか
- 人名、会社名、住所など、公開して困る情報がないか
- 読み間違えそうな漢字をひらがなにできないか
- 1行が長すぎないか

歌なしのBGMを作る場合、この章は飛ばして構いません。

# 4. Sunoで1曲目を作る

画面名は更新で変わる場合があります。公式ヘルプで確認できる基本順序は、**Create → Custom → Lyrics／Instrumental → Styles・Advanced options → Title → Create** です。

## 手順1｜作成画面を開く

1. [Suno](https://suno.com/)へログインする
2. `Create` を開く
3. 詳細に指定できる `Custom` を選ぶ

自分の歌詞を使わず、まず早く試したい場合はSimpleでも作れます。この講座では再現しやすく直しやすいCustomを使います。

## 手順2｜歌詞または歌なしを決める

- 歌入り：`Lyrics`欄に、作った歌詞を貼る
- 歌なし：`Instrumental`を有効にする

**つまずき注意**：歌なしにしたのに歌声が入る場合、歌詞欄を空にし、Stylesから `vocal`、`choir` など声を表す語を外します。

## 手順3｜Stylesへ曲調を入れる

最初は次の5要素で十分です。

```text
ジャンル, 雰囲気, 主な楽器, テンポ, 声
```

例：

```text
acoustic pop, warm and hopeful, acoustic guitar and piano, 108 BPM, female vocal
```

歌なしの例：

```text
lo-fi hip hop, calm and focused, mellow piano and soft drums, 78 BPM, instrumental
```

一度に多くの条件を入れず、5〜8個程度の特徴から始めます。

## 手順4｜タイトルを入れる

仮タイトルで構いません。後から探しやすい名前にします。

悪い例：`test1`  
よい例：`誕生日_アコースティック_初稿`

## 手順5｜Advanced optionsを確認する

画面に表示される場合のみ使います。初回は設定を増やしすぎず、既定値で問題ありません。使った項目はテンプレートの生成記録へ残します。

## 手順6｜Createを押す

生成された候補を最後まで聞きます。すぐ再生成せず、まず次の3点だけ採点します。

- サビは覚えやすいか：5点満点
- 声と雰囲気は合っているか：5点満点
- 歌詞が聞き取れるか：5点満点

合計点だけでなく、「残したい部分」を一言書いてください。

---

# 5. 1か所ずつ直す

最初の生成で完成しなくても失敗ではありません。次の順で、一度に1項目だけ変えます。

1. 歌詞の長さ
2. 雰囲気
3. テンポ
4. 楽器
5. 声

複数を同時に変えると、何が効いたか分からなくなります。

## よくある修正例

| 状態 | 最初に直す所 |
|---|---|
| 歌詞が早口で詰まる | 1行を短くし、不要な言葉を削る |
| サビが弱い | `[Pre-Chorus]`を追加し、サビの中心語を繰り返す |
| 明るすぎる | `bright`を外し、`gentle`や`nostalgic`へ替える |
| 曲が重すぎる | 楽器を減らし、`light percussion`を指定する |
| 発音がおかしい | 難しい漢字、固有名詞、数字を読みどおりに書く |
| 終わり方が不自然 | `[Outro]`と短い1〜2行を加える |
| 毎回違いすぎる | 採用候補の歌詞とStylesを保存し、1項目だけ変更する |

# 6. 完成版を選び、記録する

次の条件を満たしたものを完成版にします。

- 最後まで聞いて不自然な途切れがない
- 歌詞に誤り、個人情報、他作品の引用がない
- 使用目的に合う
- 生成時のプラン、日付、入力内容が記録されている
- 商用利用する場合、利用条件を満たしている

付属テンプレートへ、曲のURL、生成日、プラン、歌詞、Styles、修正履歴を記録します。販売や納品では、この記録が権利確認の手がかりになります。

## ダウンロード前の注意

2026-09-03以降、Sunoはプラン別のダウンロード数を案内しています。公式ヘルプではProは月20曲、Premierは月60曲です。無料利用者の試用ダウンロードは非商用です。ダウンロード数、購入できる追加枠、対象機能は変更される可能性があります。

商用利用する曲は、加入中に作るだけでなく、Sunoの正規のダウンロード操作を使います。画面録画やストリームの抜き取りは使いません。

# 7. 作った曲の使い方

## 非商用で楽しむ

無料プランの曲は、個人的・非商用の範囲で使います。Suno上の共有リンクで家族や友人に聞いてもらう方法があります。

## 商用で使う

有料プランに加入中に作成し、正規にダウンロードした曲は、Sunoの規約上、条件を満たせば販売、動画、ゲーム、ストリーミング配信などに使えます。ただし、次の点を別に確認します。

- 歌詞、アップロード音声、画像など、入力素材を使う権利
- 販売先、動画サイト、配信代行会社の規約
- 日本や利用地域で著作権保護の対象になるか
- 顧客へどこまで利用を許可するか

Sunoが商用利用を認めることと、各国で著作権が必ず認められることは同じではありません。

# 8. 売り方を設計する

最初は「曲を作って置くだけ」ではなく、誰の何を解決するかで商品を決めます。

## 売り方1｜依頼を受けて作る

例：誕生日、記念日、店舗ジングル、動画用テーマ曲。

受付時に決めるもの：

- 用途と公開先
- 希望する雰囲気、長さ、歌の有無
- 入れたい言葉と入れたくない言葉
- 納品形式
- 納期
- 修正回数
- 顧客に認める利用範囲
- AI生成を使うことへの同意

価格は、Suno代だけでなく、聞き取り、歌詞、生成、選定、修正、納品、問い合わせ対応の時間を含めて考えます。

```text
価格の下限 ＝ 外部費用 ＋（作業時間 × 自分の時間単価）＋ 販売手数料 ＋ 修正予備
```

## 売り方2｜完成した音源を販売する

用途別BGM、ジングル、効果音集などにまとめます。販売先を決める前に、AI生成物を扱えるか、販売手数料、禁止項目、購入者に与える利用範囲を公式規約で確認します。

## 売り方3｜配信サービスへ出す

有料プランで作った曲は、Suno公式ヘルプ上、SpotifyやApple Musicなどへの配信が可能です。ただし、実際の登録は配信代行会社を通すことが一般的で、AI音楽の審査、本人確認、料金、Content IDの扱いは会社ごとに異なります。申込み当日に各社の公式規約を確認してください。

## 初回商品の価格を決める質問

1. 顧客専用の歌詞を書くか
2. 曲の候補を何本作るか
3. 修正を何回受けるか
4. 商用利用を認めるか
5. 急ぎ納品か

値段だけを先に決めず、含める作業と含めない作業を先に書きます。

# 9. 困ったとき

## Createが押せない

- ログイン状態を確認する
- 必須欄と残りクレジットを確認する
- ページを再読み込みする
- 別ブラウザまたは最新版のブラウザを試す

## 生成に時間がかかる

共有キューや混雑の可能性があります。連打せず、Libraryに生成結果が追加されていないか確認します。

## 日本語の歌詞が不自然

- 漢字をひらがなにする
- 1行を短くする
- 英数字を読み方で書く
- 助詞が続く行を言い換える

## 思った曲にならない

条件を増やす前に、反対の言葉を削ります。その後、ジャンル、雰囲気、楽器、テンポ、声の順で1項目ずつ直します。

## 販売してよいか分からない

販売しないで止めます。`販売・権利チェックシート.md`を埋め、Sunoと販売先の最新公式規約を確認します。判断できない場合は、各サービスのサポートまたは法律の専門家へ確認してください。

## 無料プランで良い曲ができた

あとから有料プランへ加入しても、その曲へ自動的に遡って商用利用権が付くわけではありません。販売用は有料プラン加入中に新しく作るのが安全です。
