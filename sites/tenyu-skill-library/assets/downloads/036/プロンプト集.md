# Suno AI オリジナル曲づくり プロンプト集
商品ID：036-C（釣り竿）｜天祐 AI ビジネス

コピーして、言葉を入れかえるだけ。「どう指示すれば思った曲になるの？」を、型とお手本で解決するプロンプト集です。

---

## はじめに

### この集でできること
- 思い浮かべた雰囲気どおりの曲を、Suno で作れるようになる
- 歌詞づくりを ChatGPT や Claude に手伝ってもらえる
- 誕生日・お店の BGM・動画のオープニングなど、使う場面に合わせた曲がすぐ作れる

### 用意するもの
- Suno のアカウント（無料でも試せます）
- 歌詞を作るなら ChatGPT か Claude（無料版で大丈夫です）

### 先に知っておいてほしいこと（大事）
Suno で作った曲を「売る」「収益化した動画で使う」など、お金にからむ使い方をするなら **有料プラン** が必要です。くわしくは最後の「利用条件」を読んでください。

---

## 使い方（3ステップ）

1. Suno の作成画面で **Custom（カスタム）** をオンにする
   → 「歌詞」「スタイル」「タイトル」を別々に入れられるようになります
2. この集の型をコピーして、**【 】の中だけ** 自分の言葉に入れかえる
3. 2曲ずつできるので、聞きくらべて好きな方を残す。違ったら「うまくいかないとき」を見て1か所だけ直す

※ Suno の画面の表示や名前は、更新で変わることがあります。

## 型1｜スタイル（曲の雰囲気）の書き方

スタイル欄には、**ジャンル・雰囲気・楽器・テンポ・声** の5つを、カンマで区切って英語で入れるのがコツです。日本語でも動きますが、英語の方が安定しやすいです。

```
【ジャンル】, 【雰囲気】, 【目立たせたい楽器】, 【テンポ】bpm, 【声の種類】
```

| 入れるもの | 例 |
|---|---|
| ジャンル | J-pop / city pop / lo-fi hip hop / acoustic ballad / EDM / jazz |
| 雰囲気 | warm, nostalgic / bright, energetic / calm, dreamy |
| 楽器 | piano / acoustic guitar / synth / strings / koto（琴） |
| テンポ | ゆったり 70〜80 / ふつう 100〜110 / 元気 120〜130 |
| 声 | female vocal / male vocal / soft whisper vocal / instrumental（歌なし） |

### すぐ使えるスタイル例 10
1. `J-pop, bright and hopeful, piano and acoustic guitar, 110bpm, female vocal`
2. `city pop, nostalgic 80s vibe, funky bass, synth, 105bpm, male vocal`
3. `lo-fi hip hop, calm and cozy, soft piano, vinyl crackle, 80bpm, instrumental`
4. `acoustic ballad, gentle and heartfelt, acoustic guitar, strings, 72bpm, soft female vocal`
5. `EDM, energetic festival, big synth drop, 128bpm, male vocal`
6. `jazz cafe, relaxing, upright bass, brushed drums, piano, 90bpm, instrumental`
7. `Japanese traditional fusion, elegant, koto, shakuhachi, light drums, 95bpm, female vocal`
8. `children's song, cheerful and simple, ukulele, glockenspiel, 115bpm, kids choir`
9. `rock anthem, powerful, electric guitar, drums, 140bpm, male vocal`
10. `ambient, peaceful morning, soft pads, birds, 60bpm, instrumental`

**ポイント**：言葉は5〜8個まで。「明るい」と「切ない」のような反対の言葉を一緒に入れると、どっちつかずの曲になります。

## 型2｜歌詞を AI に作ってもらうプロンプト

ChatGPT か Claude に、そのまま貼り付けて使います。

### 2-1 基本（どんな曲でも）
```
Suno で使う歌詞を作ってください。
・テーマ：【例：がんばっている友だちへの応援】
・聞く人：【例：20代の社会人】
・雰囲気：【例：明るいけど少し泣ける】
・構成：[Verse] [Pre-Chorus] [Chorus] [Verse] [Chorus] [Bridge] [Chorus] [Outro]
・1行は短め（15文字くらいまで）。歌いやすい言葉で
・サビには、覚えやすいくり返しのフレーズを入れる
・実在の曲の歌詞や、有名なフレーズは使わない
```

### 2-2 名前やエピソードを入れる（プレゼント用）
```
【名前】さんへ贈る歌の歌詞を作ってください。
・きっかけ：【例：30歳の誕生日】
・入れたい思い出：【例：大学の文化祭で一緒にカレーを作った】
・伝えたいこと：【例：いつも笑わせてくれてありがとう】
・名前はサビに1回だけ入れる。思い出は1番の歌詞に入れる
・構成は [Verse] [Chorus] [Verse] [Chorus] [Outro]
```

### 2-3 今ある歌詞を歌いやすく直す
```
次の歌詞を、メロディにのせやすく直してください。
・意味は変えない
・1行の長さをそろえる
・同じ行の終わりの音（「〜て」「〜た」など）を少しそろえる
・直した所に印をつける

【ここに歌詞を貼る】
```

### 2-4 英語の歌詞にする
```
次の日本語の歌詞を、英語の歌詞にしてください。
・直訳ではなく、英語として自然で歌いやすく
・サビは短く、くり返しやすく
・最後に、日本語でどんな意味か一行ずつ添える

【ここに歌詞を貼る】
```

### 2-5 タイトルを10個考える
```
次の歌詞の曲名を10個考えてください。
短いもの・英語・日本語をまぜて。それぞれ、なぜその名前かを一言で。

【ここに歌詞を貼る】
```

## 型3｜構成タグ（歌詞欄に入れる目印）

歌詞の行の前に入れると、Suno が「ここは1番」「ここはサビ」とわかりやすくなります。

| タグ | 意味 |
|---|---|
| `[Intro]` | 前奏 |
| `[Verse]` | Aメロ（1番・2番の始まり） |
| `[Pre-Chorus]` | Bメロ（サビ前の盛り上げ） |
| `[Chorus]` | サビ |
| `[Bridge]` | Cメロ（最後のサビ前の変化） |
| `[Instrumental]` | 歌なしの間奏 |
| `[Outro]` | 後奏・終わり |

**ポイント**：曲の最後が途中で切れたり、だらだら続いたりするときは、最後に `[Outro]` を入れて短い歌詞で終わらせると落ち着きやすいです。

## お手本｜1曲できあがるまで

**タイトル**：はじまりの坂道

**スタイル**：
```

**歌詞**（2-1 のプロンプトで作り、2-3 で整えたもの）：
```

## うまくいかないとき

| こまったこと | 直し方 |
|---|---|
| 思った雰囲気にならない | スタイルの言葉を5個までに減らす。反対の言葉を一緒に入れていないか見る |
| 歌がほしいのに歌が入らない | スタイルに `female vocal` などの声を入れる。`instrumental` が入っていたら消す |
| 歌なしにしたいのに歌う | スタイルに `instrumental` を入れ、歌詞欄は空にする（画面に歌なしの切りかえがあればオンにする） |
| 歌詞が早口で詰まる | 1行を短くする（2-3 のプロンプトを使う）。テンポを少し下げる |
| サビが盛り上がらない | サビの前に `[Pre-Chorus]` を入れる。サビの言葉をくり返す |
| 曲が途中で切れる・終わらない | 最後に `[Outro]` と短い1行を入れる |
| 日本語の発音がおかしい | 読み間違えやすい漢字をひらがなにする |
| 毎回ちがいすぎる | 気に入った曲のスタイル欄をメモして、1か所ずつだけ変える |
