## 2. 歌詞作成プロンプト

```text
Sunoで使う、完全オリジナルの日本語歌詞の下書きを作ってください。

用途：【 】

テーマ：【 】
入れたい出来事：【 】
伝えたい中心の言葉：【 】

条件：
- 構成は [Verse] [Pre-Chorus] [Chorus] [Verse] [Chorus] [Bridge] [Outro]
- 1行を短くし、声に出して読みやすくする
- サビには短く覚えやすい言葉を入れる
- 実在する曲の歌詞、決まり文句、歌手名、曲名をまねしない
- 分からない事実は作らない
- 最後に「本人が書き直すとよい箇所」を3つ示す
```

## 3. 歌いやすく直すプロンプト

```text
次のオリジナル歌詞を、意味を変えずに歌いやすく整えてください。

- 1行を短くする
- 長さが極端に違う行をそろえる
- 固有名詞や漢字に読み間違いが起きそうなら指摘する
- サビの中心語を覚えやすくする
- 変更前と変更後を表で示す
- 新しい出来事や事実を勝手に足さない

【ここに歌詞を貼る】
```
