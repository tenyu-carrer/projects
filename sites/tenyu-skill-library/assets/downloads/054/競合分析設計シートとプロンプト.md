# 054-C｜競合SNS分析 設計シートとプロンプト

**状態：再利用用初稿／分析は公開情報だけ・自分の手で写した数字だけを使う**

## 設計欄

- 自分の分野と、見てほしい人：
- 分析するアカウント（3〜5つ）と選んだ理由：
- 見る項目（プロフィール・投稿の種類・間隔・反応が多い型・お知らせの仕方）：
- 見る期間（例：最近30日、最近9投稿）：
- 記録の置き場所（表計算・ノート）：
- 取り入れない（真似しない）ものの決まり：
- 分析を見直す時期（例：3か月ごと）：

```text
私の分野【】と見てほしい人【】から、分析するアカウントの探し方を教えて。検索の言葉の例・ハッシュタグの例・「近すぎる／遠すぎる」アカウントの見分け方を出して。実在のアカウント名は挙げないで。
```
```text
アカウントの観察メモ【自分で書いたメモ】を、表にまとめて。列は「見てほしい人・投稿の種類・投稿の間隔・反応が集まっている型・お知らせの仕方」。メモにないことは推測で埋めず「不明」と書いて。
```
```text
観察の表【】から、3つに共通していること・それぞれの特徴・どれもやっていないことを出して。どれもやっていないことは「なぜやっていないと考えられるか」も書いて。
```
```text
観察の表【】と私の強み【】から、私が違いを出せる方針を3案作って。それぞれ「誰に・何を・どんな形で」を1行で。他のアカウントの文章や企画をそのまま使う案は出さないで。
```
```text
方針の案【】から、最初の2週間の投稿の種類を6本分決めて。観察で見つけた「型」は参考にしてよいが、内容と言葉は自分のものにして。
```
```text
自分の投稿案【】と、参考にしたアカウントの観察メモ【】を比べて、似すぎている所（言い回し・構成・画像の見た目）がないか指摘して。
```
```text
3か月前の観察の表【】と今の表【】を比べて、分野の中で変わったこと・変わらないことを3つずつ出して。
```
```text
自分のアカウントの最近の数字【自分で写したもの】と観察の表【】から、来月1つだけ変えることを提案して。他のアカウントの数字は目安にとどめ、自分の数字の変化を中心に考えて。
```

AIは実際のアカウントを見ていません。観察とメモは自分で行い、AIには整理と考えの手伝いだけを頼みます。
