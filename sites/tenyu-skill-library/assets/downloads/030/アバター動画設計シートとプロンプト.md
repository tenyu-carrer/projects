# 030-C｜AIアバター動画 設計シートとプロンプト

**状態：再利用用初稿／AI出力は必ず再生して確認**

## 設計欄

- 使うアバターの種類：ツールの汎用アバター／本人の分身（本人の同意書あり）
- 声の種類：ツールの汎用音声／本人の声（本人の同意あり）
- 使うツール名・プラン・商用利用の条件・確認日：
- AIであることの表示方法（画面表示・説明文・最後のひと言）：
- 話す内容の事実確認の担当者：
- 公開先とその場所のAI表示ルール：

```text
テーマ【】で、AIアバターが話す【30】秒の原稿を作って。話し言葉、1文30文字以内、最初に誰向けかを言い、最後にAIアバターであることを伝える一文を入れて。
```
```text
原稿【】を5秒ごとに区切り、各区切りに「話す文」「画面の補足文字（12文字以内）」「表示する図やアイコン」を付けた表にして。
```
```text
原稿【】の中で、事実・数字・制度・料金など、公開前に公式情報で確認が必要な箇所を全部抜き出して。確認先の候補も書いて。
```
```text
原稿【】を音声合成で読ませたとき、読み間違いやすい言葉（固有名詞・数字・英語・同じ漢字で読みが違う言葉）を挙げて、ふりがなや言い換え案を出して。
```
```text
アバター動画の説明文を作って。内容【】。AIアバターと合成音声を使っていることを1文で明記し、誇張しない言い方で。
```
```text
このアバター動画の企画【】について、実在の人物・有名人・特定の職業の人に見えて誤解される危険がないか点検して。危ない点と直し方を出して。
```
```text
30秒の原稿【】を、60秒版に広げて。例を1つ足すだけにして、主張は増やさないで。
```
```text
完成した動画の確認表を作って。項目：口の動きと音のずれ、読み間違い、字幕の位置、AI表示、事実確認、音量。
```

アバターや声を作るときは、他人の顔・声を使わないこと。本人の分身を作る場合も、本人の書面の同意と使う範囲の取り決めを残します。
