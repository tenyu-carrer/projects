# 053-D｜SNS運用代行 公開前チェック

- [ ] 作業範囲（やらないこと含む）を文章で確認
- [ ] パスワード共有なし・管理画面で権限
- [ ] 権限は必要な分だけ・依頼主に管理者が残る
- [ ] 自分のアカウントに2段階認証
- [ ] 事実は依頼主に確認済み
- [ ] 効果の断定・根拠のない一番がない
- [ ] 広告表示の要否を確認
- [ ] 写真・お客さまの声の許可
- [ ] 全投稿に承認の記録
- [ ] 結果を約束していない
- [ ] 終了時に権限を外す手順

承認のない投稿、パスワードの共有、結果の約束があれば運用を止めて直す。依頼数・収入を保証しない。
