# 053-C｜SNS運用代行 設計シートとプロンプト

**状態：再利用用初稿／契約・料金・規約は必ず自分で確認**

## 設計欄

- 依頼主の業種と、SNSを使う目的（予約・来店・認知など）：
- 対象のSNSと、月の投稿本数：
- 私がやること／依頼主がやること／やらないこと：
- アカウントへの入り方（管理画面の人の追加・役割）：
- 投稿前の承認の方法（誰が・いつまでに・どこで）：
- 写真・素材の出どころと、写っている人の許可：
- 報告の頻度と、見る数字：
- 料金の考え方（作業時間の見積もり）と、支払いの時期：
- 解約・終了のときの手順（権限を外す・データを渡す）：

```text
依頼主【業種・目的】のSNS運用代行について、最初の打ち合わせで聞く質問を15個作って。目的・対象のお客さま・やってはいけない表現・写真の出どころ・承認する人を必ず含めて。
```
```text
打ち合わせのメモ【】から、作業範囲の表を作って。列は「作業・担当（私／依頼主）・回数・締め切り・承認の要否」。あいまいな所には「要相談」と書いて。
```
```text
依頼主【業種】の1か月の投稿案を8本作って。各案に「狙い・画像の案・本文の下書き・確認してほしい事実」を付けて。効果や結果を約束する言い方は使わないで。
```
```text
投稿案【】を、依頼主が承認しやすい形にまとめて。1本ごとに「公開予定日・本文・画像・確認してほしい点・OK／修正の欄」を付けて。
```
```text
投稿案【】を点検して。業種【】で気をつけるべき表現（効果の断定、比べて一番と言う、体験談の作りごと）、広告であることを示す必要があるか、写真の許可を指摘して。
```
```text
作業範囲の表【】をもとに、作業時間の見積もりを作って。作業ごとの時間・月の合計時間を出し、料金は「時間×自分で決めた単価」で計算する欄だけ作って。相場の金額は書かないで。
```
```text
1か月の数字【投稿ごとの保存・プロフィールへのアクセス・問い合わせの数】から、依頼主向けの月次報告を作って。良かった点1つ・来月変えること1つ・数字が少なくて判断できない所を分けて書いて。
```
```text
運用代行を終了するときの手順を作って。権限を外す・作ったデータを渡す・予約中の投稿の扱い・最後の報告を、順番に並べて。
```

料金や契約の条件は、AIの答えをそのまま使わず、自分で決めて依頼主と書面（メールでも可）で確かめます。
