# 025-C｜Instagramリール設計シートとプロンプト

**状態：再利用用初稿／AI出力は要検証**

## 設計欄

- 視聴者／一投稿の主題／見た後の変化：
- 冒頭3秒／本編の根拠／まとめ：
- カバー見出し／リール面・プロフィール面の確認：
- 人物・場所・素材・音源・フォントの権利：
- AI生成・大幅編集の工程と表示判断：
- 報酬・提供・貸与・アフィリエイトとPaid partnership判断：
- 共同投稿者／タグ／公開範囲／コメント等：
- 公式URL／確認日／確認者：

```text
主題【】と実演【】から、冒頭・本題・証拠・まとめのリール構成を3案。各案に必要素材、字幕、音、回収、誤解リスクを付ける。
```
```text
本編の約束【】からカバー見出し5案。短く具体的にし、リール面とプロフィール一覧で残す要素を示す。固定の切り抜き寸法は断定しない。
```
```text
素材一覧【】から人物同意、画像、音源、ロゴ、フォント、商用利用、加工、期限の未確認項目を抽出。推測で許可済みにしない。
```
```text
制作工程【】からAI生成・大幅編集・軽微補正を記録し、透明性表示について最新Meta/Instagram画面で確認する質問を作る。
```
```text
ブランド関係【報酬・提供・貸与・アフィリエイト】を整理し、Paid partnership label、契約、適用法令を確認する表を作る。
```
```text
公開後データ【期間・再生・視聴時間・反応・保存・共有】から仮説を3つ。断定せず、次回に一要素だけ変える。
```

出力は審査・推薦・再生・収益を保証しません。
