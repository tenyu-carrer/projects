# 026-C｜字幕校正シートとプロンプト

**状態：再利用用初稿／AI出力は要検証**

## 台帳項目

キュー番号／開始／終了／話者／原音／自動案／確定文／根拠／数字／否定／固有名詞／単位／重要音／改行／表示位置／確認者／状態

```text
原文【】と自動字幕【】を比較し、欠落、追加、置換、数字、否定、固有名詞、単位、話者をキューごとに表にする。
```
```text
字幕【】を意味単位で分割。語句の途中で切らず、各キューに開始・終了候補と分割理由を付ける。最終同期は実音声で人が確定する。
```
```text
会話【】の話者交代を抽出。不明な話者は名前を推測せず「話者不明」とする。
```
```text
音声メモ【】から、理解に必要な非発話音だけを候補化。音の種類、開始・終了、必要理由を示す。
```
```text
SRT本文【】の連番、時刻形式、開始終了、順序、空行、重複を検査する。内容の正しさとは分けて報告。
```
```text
WebVTT本文【】のWEBVTTヘッダー、タイムスタンプ、キュー順序、設定、マークアップを検査。プレイヤー実読込は別確認とする。
```
```text
字幕と画面メモ【】から、重要な顔・手元・文字と競合するキューを抽出し、位置変更または文短縮案を出す。
```
```text
確定字幕【】から逐語トランスクリプトを作り、理解に必要な視覚情報の説明候補を別欄にする。
```

自動結果は原音を聞いた校正の代替ではありません。
