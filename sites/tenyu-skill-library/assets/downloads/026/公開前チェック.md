# 026-D｜字幕・テロップ公開前チェック

- [ ] 原音と字幕をキューごとに照合
- [ ] 数字・日付・時刻・単位を確認
- [ ] 否定・条件・注意の欠落がない
- [ ] 固有名詞・専門語を一次資料で確認
- [ ] 話者交代と話者名を確認
- [ ] 理解に必要な重要音を記載
- [ ] 開始・終了・重複・無字幕区間を実再生確認
- [ ] 改行が語句・意味を不自然に分断しない
- [ ] 顔・口元・手元・画面文字を隠さない
- [ ] SRT/WebVTTを対象プレイヤーで読み込み
- [ ] 字幕とトランスクリプトの役割を確認
- [ ] 版・言語・確認者・確認日・未検証を記録

音声未確認、重大な意味反転、形式エラー、同期ずれがあれば公開保留。完全な認識精度を保証しない。
