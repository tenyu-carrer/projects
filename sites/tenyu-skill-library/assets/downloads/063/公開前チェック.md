# 063-D｜noteの有料記事 公開前チェック

- [ ] 経験からしか書けないテーマ
- [ ] 無料部分に役立つことが1つ以上
- [ ] 有料部分の中身を目次で見せた
- [ ] 体験を自分で書いた
- [ ] すべての事実に確認先
- [ ] 効果・結果を言い切らない
- [ ] 紹介文に必ず・誰でも・稼げるなし
- [ ] noteの規約・手数料・値段の範囲を確認
- [ ] 他人の文章・写真を無断で使わない
- [ ] 広告の表示が必要なら付けた
- [ ] プレビューで有料ラインを確認

中身を隠した有料部分、確かめていない効果、規約の未確認があれば公開しない。売上を保証しない。
