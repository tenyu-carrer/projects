# 046-C｜YouTubeチャンネル運用 設計シートとプロンプト

**状態：再利用用初稿／AIの案は必ず自分の経験と事実で直す**

## 設計欄

- チャンネルのテーマ／見てほしい人／その人の疑問：
- 動画の長さと頻度（無理のない数）：
- 視聴者層の設定（子ども向けかどうか）：
- 使う映像・音楽・画像の権利：
- 顔を出すか（出さない場合の見せ方）：
- 振り返りの見方（見てもらえた長さ・コメント）と確認者：

```text
テーマ【】と見てほしい人【】から、その人が検索しそうな疑問を20個挙げて。初心者がつまずく順に並べて。
```
```text
疑問【】に答える動画の題名を3案。検索されそうな言葉を入れ、動画の中で答えられないことは約束しないで。
```
```text
動画の内容【】から、サムネイルに入れる文字を3案（各12文字以内）。題名と同じ文字を繰り返さず、内容を大げさにしないで。
```
```text
動画の説明文を作って。内容【】。最初の2行で何が分かる動画かを書き、話題ごとの時刻（チャプター）、関連する動画の案内、使った音楽の表記を入れて。
```
```text
動画の台本【】の中で、事実・数字・安全に関わる部分を抜き出して、確認先の候補を付けて。
```
```text
もらったコメント【】への返事を2案。お礼と、質問への答えを入れて。答えが分からない質問は、分からないと正直に書いて。
```
```text
1本の動画の振り返り【見てもらえた長さのグラフの特徴・コメント】から、次の動画で直すことを1つだけ提案して。
```
```text
これまでの動画一覧【題名と内容】から、次の10本の題名案を出して。同じ内容のくり返しにならないように。
```

チャンネルの中身の責任は自分にあります。AIの案はたたき台にして、自分の経験と確かめた事実で仕上げます。
