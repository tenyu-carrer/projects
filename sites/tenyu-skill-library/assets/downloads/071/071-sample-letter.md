# 親子で失敗しない焼き菓子4回コース（見本・架空）

**状態：架空の焼き菓子教室「くるみ堂」の販売ページの見本。実在の講座ではありません**

## 子どもと作ったクッキー、焦がしてしまったことはありませんか？

一緒に作りたいのに、失敗が続くと、だんだん誘わなくなってしまう。
このコースは、そんな親子のための、家で作る焼き菓子のオンライン講座です。

## このコースでできるようになること

- 4回で、基本の3種類（クッキー・マフィン・パウンドケーキ）を作れる
- 焼き上がりを見て、失敗の原因を見分けられる
- 子どもに任せる所と、大人がやる所を分けて進められる

## 中身

| 回 | 内容 |
|---|---|
| 第1回 | 型抜きクッキー |
| 第2回 | マフィン |
| 第3回 | パウンドケーキ |
| 第4回 | 失敗の見分け方（焦げ・ふくらまない・かたい） |

各回：動画（約15分）・材料と道具の一覧PDF・手順カード

## 作った人

くるみ堂（架空）の小川です。自分の子どもと初めて作ったクッキーは、オーブンの温度をまちがえて真っ黒になりました（架空の設定）。その失敗から、子どもと作るときの手順を作り直したのがこのコースです。

## 向かない人

- 本格的なケーキの技術を学びたい人
- 家にオーブンがない人
