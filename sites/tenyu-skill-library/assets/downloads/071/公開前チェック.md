# 071-D｜セールスレター 公開前チェック

- [ ] すべての主張に根拠
- [ ] 商品にないことを約束していない
- [ ] 効果の約束・根拠のない数字・事実でない期限なし
- [ ] 売ったことのない価格と比べていない
- [ ] 向かない人を書いた
- [ ] 経歴は事実だけ
- [ ] お客さんの声は許可あり・依頼の有無を記載
- [ ] 条件が1か所にまとまっている
- [ ] 事業者の表示を確認
- [ ] よくある質問に「確認中」なし
- [ ] 1人に読んでもらった
- [ ] 見直す日と数字を決めた

根拠のない主張が残る、条件や事業者の表示がない場合は公開しない。売上を保証しない。
